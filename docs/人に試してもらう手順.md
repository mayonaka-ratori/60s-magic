# 人に試してもらう手順

目的は「自分が描いて唱えた魔法を放った」「自分の魔法で敵の一撃を止めた」と感じられるかの確認です。まず5人で試します。初見の人による確認はまだ実施していません（2026年9月23日時点）。

今遊べるのは90秒です。標準の「順番に」は0〜26秒が声だけ、26〜50秒が手だけ、50〜90秒が手のあと声です。90秒で結果画面（魔導書）が出ます。QRの先の持ち帰りページはまだありません。下に書いた秒数は `src/game/rounds.ts` の表から出したもので、秒ごとの流れは [動きの詳細](動きの詳細.md) にあります。

## 準備

1. Chromeで起動し、同じPCのカメラとヘッドセットの口元のマイクを選ぶ。
2. `localhost:5173/?dev=1` で開き、「接続の確認」で「このPCで音声を認識できます」と出ることを確認する。準備していなければ `npm run setup:speech` を実行し、起動し直す。Googleの設定は不要。Jevが未設定なら、魔法の内容をPC内の規則で決めた回として記録する。
3. 「手で描く」「マイクで唱える」を選び、機器の許可と準備が終わった後に「まもなく始まる。手を画面の前に」の3秒の合図が出て、そのあと90秒が始まることを確認する。合図の間に手の位置を決められる。
4. カメラの前には一人で座る。片手を動かせば線が現れる位置にする。

## 一人につき試すこと

一人につき3回ずつ、90秒を通して遊んでもらいます。

**一回目の魔法（0〜26秒）で見ること。手は描きません。**

| 回 | 操作 | 見ること |
| --- | --- | --- |
| 1 | 好きな言葉を唱える | 説明を加えなくても一回の魔法を見届けられるか |
| 2 | 同じ言葉を繰り返し、途中で別の言葉へ言い直す | 同じ部品が重ならず、言い直した部品が薄くなり、14秒で受付が終わるか |
| 3 | 「氷よ、壁となれ」「雷よ、七つに分かれろ」「顕現、螺旋」を別々に唱える | 言葉による色・形・動き・光の違いが分かるか |

**防御の回（26〜50秒）で見ること。** 26秒になると画面の左寄り（横27%、高さの真ん中）に赤い輪が出ます。ここが一番確かめたいところです。

| 回 | 操作 | 見ること |
| --- | --- | --- |
| 1 | 何も教えずに任せる | 左の赤い輪に気づくか。囲おうとするか |
| 2 | 印を囲むように描いてもらう | 線が掛かると印が赤から別の色へ変わり、囲えると内側が満ちる。それに気づくか。囲いやすい大きさと位置か |
| 3 | わざと印から離れた場所に描いてもらう | 締め切りのあと、線が印の前へ動くのが分かるか。置いていかれた感じがしないか |
| どれか | 囲まず、線を輪に掛ける | 囲うと弾き返し、掛かると受け止め、離れるとかき消す違いが見えるか |

42.4秒に騎士の一撃が盾へ当たります。そこで手応えがあるか、47秒から胸当てが外れて弱点が出るのが分かるかも見てください。

**とどめの回（50〜90秒）で見ること。** 50秒で「第三幕　魔法陣を描こう！」が出て、前の二回の光点が中央へ寄ってきます。62秒で「手を止めて、詠唱を始めよう！」に変わります。72秒まで声を受け付け、76秒に発動します。

| 回 | 操作 | 見ること |
| --- | --- | --- |
| 1 | 何も教えずに任せる | 最後の回だと分かるか。前の二回の光が戻ってきたことに気づくか |
| 2 | 合図までは描き、合図のあと手を止めて唱える | 75.6秒の止まる間と76秒の発動で、十分にためてから放ったと感じるか |
| 3 | 何も描かず、唱えるだけにする | 置いていかれた感じがしないか。最後まで見届けられるか |

78.6秒に騎士の核へ一撃が入り、そこから倒れます。90秒で結果画面が出ます。三つの魔法名と自分の術式が並んでいるか、確認番号が読めるかも見てください。

声を出しにくい人は、「マイクで唱える」を外して「同時に」で試せます。その場合も別に記録し、言葉を認識した成功例へ数えません。

## 同時にでも確かめる

`?flow=together`で開き、三回とも描きながら唱えます。0〜30秒、30〜56秒、56〜90秒の順です。防御は「弾き返せ」「かき消せ」で止め方が変わります。開始画面で遊び方を変え、読み込み直した後も選んだ方で遊べることを見ます。

両方の遊び方で、唱えている最中に足踏みと盾打ちが聞こえること、輪を囲えた音が鳴ることを確かめます。声の受付中だけ音が少し小さくなり、「順番に」の手だけの間は元の音量のままであることも見ます。スピーカーの音が聞き取りに混ざらないか、実際の会場の音量で確かめてください。

## 終わったら聞くこと

- 自分の描いた形が残っていましたか。
- 自分の言葉が魔法に入っていましたか。
- 光が集まり、完成し、放たれたことが分かりましたか。
- 左の赤い輪は何のためのものだと思いましたか。囲おうと思いましたか。
- 敵の一撃を、自分の魔法で止めたと感じましたか。
- 急かされたところ、分かりにくいところはありましたか。
- もう一度つくってみたいですか。

`?dev=1` で開いていれば、結果画面に「自分の魔法を放ったと感じましたか」の回答欄が出ます。回答後に「記録を保存する」でその回のデータを保存できます。本人の詠唱の文字も含まれるので、保存してよいか本人に伝えてください。

遊んだ記録（描いた線と唱えた言葉）は、そのPCのブラウザーの中に残ります。カメラの映像と声そのものは残しません。タイトル画面の案内にも同じことが書いてあります。

| 人 | 遊び方・入力方法 | 形が残った | 言葉が反映された | 自分で放った実感 | 印に気づいた | 囲えた | 止めた実感 | 急かされた箇所・気づき |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | | | | | | | | |
| 2 | | | | | | | | |
| 3 | | | | | | | | |
| 4 | | | | | | | | |
| 5 | | | | | | | | |

「囲えた」は記録でも確かめられます。`?dev=1` の「記録を保存する」で落ちるJSONの `rounds[1].guard.enclosed` です。囲えなかった人が多ければ、印の大きさか位置を見直します。[記録の見方](確認用の記録の見方.md)

## まだ合格といえない項目

- 実際の手から光までの遅れ。目標は95％が80ms以内、99％が120ms以内。手と画面を一緒に映して測る。
- カメラとマイクを同時に使ったときの表示の滑らかさ。記録には表示間隔を入れるが、実機の測定と合わせて判断する。
- 音声の最終結果が締め切りの2秒後までに届く割合と、Jevが確定に間に合う割合。「順番に」では一回目（16秒・17秒）ととどめ（74秒・75秒）、「同時に」では三回それぞれで見る。音声認識の方法と、Jevの代わりにPC内の規則を使った回を記録する。記録の `server.speechSessions` の `finalDelivered` と、`rounds[i].recipe.source` で分かる。
- とどめの回で声を拾えているか。「順番に」では防御の回は声につながず、とどめで59.5秒から接続を準備し、62秒から録音する。「同時に」では防御ととどめの始まりの2.5秒前につなぎ直す。記録の `flow` を確かめ、声を使う回の `rounds[i].state.speech.rawTranscript` が空でないかを見る。
- 難しい言葉、言い直し、小さい声、周囲の声への対応。
- 「自分の魔法」という実感。コードの試験や見本の再生だけでは判断しない。

人の確認で線の追従・完成・放出が伝わっていなければ、この90秒を直してから次へ進みます。
