# 人に試してもらう手順

目的は「自分が描いて唱えた魔法を放った」「自分の魔法で敵の一撃を止めた」と感じられるかの確認です。まず5人で試します。人による確認はまだ実施していません。

今遊べるのは90秒です。0〜30秒が一回目の魔法、30〜56秒が防御の回、56〜90秒がとどめの回です。90秒で結果画面（魔導書）が出ます。QRの先の持ち帰りページはまだありません。

## 準備

1. Chromeで起動し、同じPCのカメラと口元のマイクを選ぶ。
2. `localhost:5173/?dev=1` で開き、「接続の確認」で「このPCで音声を認識できます」と出ることを確認する。準備していなければ `npm run setup:speech` を実行し、起動し直す。Googleの設定は不要。Jevが未設定なら、魔法の内容をPC内の規則で決めた回として記録する。
3. 「手で描く」「マイクで唱える」を選び、機器の許可と準備が終わった後に「詠唱の準備を始めよ」の3秒の合図が出て、そのあと90秒が始まることを確認する。合図の間に手の位置を決められる。
4. カメラの前には一人で座る。片手を動かせば線が現れる位置にする。

## 一人につき試すこと

一人につき3回ずつ、90秒を通して遊んでもらいます。

**一回目の魔法（0〜30秒）で見ること。**

| 回 | 操作 | 見ること |
| --- | --- | --- |
| 1 | 好きな線を自由に描き、好きな言葉を唱える | 説明を加えなくても一回の魔法を見届けられるか |
| 2 | 途中で1〜2秒止まり、詠唱しながら最後にも描き足す | 最初の線も最後の線も残るか。止まっても18秒まで受け付けるか |
| 3 | 小さく片手を動かす。「氷よ、壁となれ」か「雷よ、七つに分かれろ」 | 大きく振らずに形と言葉の違いが分かるか |

**防御の回（30〜56秒）で見ること。** 30秒になると画面の左寄り（横27%、高さの真ん中）に赤い輪が出ます。ここが一番確かめたいところです。

| 回 | 操作 | 見ること |
| --- | --- | --- |
| 1 | 何も教えずに任せる | 左の赤い輪に気づくか。囲おうとするか |
| 2 | 印を囲むように描いてもらう | 囲えた瞬間に印の色が変わるのに気づくか。囲いやすい大きさと位置か |
| 3 | わざと印から離れた場所に描いてもらう | 締め切りのあと、線が印の前へ動くのが分かるか。置いていかれた感じがしないか |
| どれか | 「弾き返せ」または「かき消せ」と唱える | 止め方が変わったことが見て分かるか |

50.4秒に騎士の一撃が盾へ当たります。そこで手応えがあるか、55秒に胸当てが外れて弱点が出るのが分かるかも見てください。

**とどめの回（56〜90秒）で見ること。** 56秒で「第三幕　とどめ」が出て、前の二回の光点が中央へ寄ってきます。64秒から8秒ほど唱え、76秒に発動します。

| 回 | 操作 | 見ること |
| --- | --- | --- |
| 1 | 何も教えずに任せる | 最後の回だと分かるか。前の二回の光が戻ってきたことに気づくか |
| 2 | 大きく描いて、強い言葉で唱える | 75.6秒の止まる間と76秒の発動で、ためが効いているか |
| 3 | 何も描かず、唱えるだけにする | 置いていかれた感じがしないか。最後まで見届けられるか |

78.6秒に騎士の核へ一撃が入り、そこから倒れます。90秒で結果画面が出ます。三つの魔法名と自分の術式が並んでいるか、確認番号が読めるかも見てください。

声を出しにくい人は、声なしで試せます。その場合も別に記録し、言葉を認識した成功例へ数えません。

## 終わったら聞くこと

- 自分の描いた形が残っていましたか。
- 自分の言葉が魔法に入っていましたか。
- 光が集まり、完成し、放たれたことが分かりましたか。
- 左の赤い輪は何のためのものだと思いましたか。囲おうと思いましたか。
- 敵の一撃を、自分の魔法で止めたと感じましたか。
- 急かされたところ、分かりにくいところはありましたか。
- もう一度つくってみたいですか。

画面にも「自分の魔法を放ったと感じましたか」の回答欄があります。回答後に「記録を保存する」でその回のデータを保存できます。本人の詠唱も含まれるので、保存してよいか本人に伝えてください。

遊んだ記録（描いた線と唱えた言葉）は、そのPCのブラウザーの中に残ります。カメラの映像と声そのものは残しません。タイトル画面の案内にも同じことが書いてあります。

| 人 | 入力方法 | 形が残った | 言葉が反映された | 自分で放った実感 | 印に気づいた | 囲えた | 止めた実感 | 急かされた箇所・気づき |

| 1 | | | | | | | | |

| 3 | | | | | | | | |

## まだ合格といえない項目

- 実際の手から光までの遅れ。目標は95％が80ms以内、99％が120ms以内。手と画面を一緒に映して測る。
- カメラとマイクを同時に使ったときの表示の滑らかさ。記録には表示間隔を入れるが、実機の測定と合わせて判断する。
- 音声の最終結果が締め切りの2秒後までに届く割合と、Jevが確定に間に合う割合。一回目（20秒・21秒）と防御の回（47秒・48秒）の両方で見る。音声認識の方法と、Jevの代わりにPC内の規則を使った回を記録する。
- 防御の回で声を拾えているか。一回目の確定でいったん接続を閉じ、27.5秒からつなぎ直しています。記録の `rounds[1].state.speech.rawTranscript` が空でないかを見る。
- 難しい言葉、言い直し、小さい声、周囲の声への対応。
- 「自分の魔法」という実感。コードの試験や見本の再生だけでは判断しない。

人の確認で線の追従・完成・放出が伝わっていなければ、この90秒を直してから次へ進みます。
