# 詠唱の言葉と読み方

2026年9月20日。110語の表記・読み方・ゲームでの扱いを `src/game/chant-dictionary.json` にまとめました。開始画面の「詠唱の言葉を見る」で読み方と独自の詠唱例を見られます。

## 参考にしたもの

- [BLEACH 千年血戦篇の公式用語集](https://bleach-anime.com/keyword/)：黒棺の項にある難しい漢字、呼び掛け、命令の言葉を参考にしました。単語を登録し、原作の詠唱全文は収録していません。
- [呪術廻戦 第56話の公式あらすじ](https://jujutsukaisen.jp/episodes/56.php)：領域展開、誅伏賜死、式神の表記を確認しました。術式という言葉は[公式の人物紹介](https://jujutsukaisen.jp/character/)にもあります。
- [faster-whisperの実装](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/transcribe.py)：認識へ単語を渡す方法と長さの制限を確認しました。

一般語はこのゲーム向けに選んでいます。「深淵を闇として扱う」などの対応は作品の公式設定ではなく、この試作で決めた使い方です。作品の技そのものを再現する機能はありません。

## 試す詠唱

以下はこのゲーム用に作った例です。声でも、画面の文字入力でも試せます。

- 紅蓮よ、我が前に集え。七つの魔弾となり、敵を穿て。
- 常闇よ、結界となれ。我を守れ。
- 雷霆よ、螺旋を描き、敵を貫け。
- 氷晶よ、障壁となれ。攻撃しないで、我を守れ。
- 深淵より顕現せよ。鎖となり、敵を封印せよ。
- 久遠の盟約に応えよ。烈風の奔流で、敵を押し流せ。

## 文字の扱い

認識した元の文字は `rawTranscript` に残します。「らいてい」を「雷霆」、「黒ひつぎ」を「黒棺」にした表記は `normalizedTranscript` に分けます。かなの読みと登録した表記を使います。

これに加えて、**書き方の揺れだけ**は辞書の言葉へ寄せます。伸ばす音（「らいてー」と「らいてい」、「ひょうしょお」と「ひょうしょう」）と、濁点の抜け（「くれん」と「ぐれん」）が対象です。寄せる条件は次の三つを全部満たすときだけです。

- 元がかなで書かれている（漢字で書かれた言葉は動かしません。「効果がある」が「業火がある」になることはありません）
- 文字数が変わらない（「ふんかれろ」を「分かれろ」にはしません）
- 四文字までは書き方の揺れだけ、五文字以上は一文字までの違い

前後の文字も今までどおり見て、普通の言葉の一部を切り取らないようにしています。どこを寄せたかは確認用の記録の `corrections` に残ります。

聞き違いが決まった形で繰り返される場合は、辞書の `spellings` にその表記を足せば、次からは完全一致で拾えます。実際のプレイで出た間違いを見てから足してください。

「せいこう」「かご」など、普通の言葉にもなる短い読みは自動変換しません。「無料」を「無量」、「表彰」を「氷晶」にする置換もありません。否定した属性や言い直しは、変換後にも除いてから魔法を決めます。

Googleを選ぶ場合も同じ辞書から語句を渡します。Googleとの実通信と認識精度は未確認です。

## ローカル音声認識で分かったこと

辞書が110語あっても、110語すべてを認識処理へ渡しているわけではありません。Kotoba-Whisper v2.0では、41語・171トークンを渡したとき、短い声の認識が空欄になりました。20語・80トークンでも、元は読めていた詠唱の一部が欠けました。短い別の単語一覧も試しましたが、難語の聞き取りの改善は確認できませんでした。

実際に認識へ渡す `localHints` は元の14語・55トークンを維持しています。`hint: true` は今後比較する候補で、実行時に自動追加する指定ではありません。110語は読みの変換と魔法の決定に使います。音声モデルへの追加学習ではありません。

14種類の合成音声で、指定語の表記と魔法の指示が両方合ったものは7種類でした。元の4種類、常闇の結界、黒棺の表記、普通の会話の確認は通りました。紅蓮、雷霆、氷晶、霹靂などでは聞き違いが残ります。「領域展開」は読めても、続く「誅伏賜死」は読めませんでした。無音から単語が出ないことは確認しました。

最終設定は認識に渡す語句を変更していないため、音声認識そのものが良くなったとはいえません。文字として正しく届いた難語や、対応するかなの入力を魔法へ使える範囲が広がりました。人の声でも確認が必要です。

```powershell
npm run test:chants
```

比較用の音声はWindowsまたはMacの読み上げ機能でPC内に作ります。結果は `.local-speech/vocabulary-test-report.json` に残します。`none` は手掛かりを渡さずに認識した結果、`hints` は辞書の14語を渡した結果で、両方に現在の辞書を適用して比べます。辞書導入前のゲーム全体の成績ではありません。以前はどちらにも同じ14語を渡していたため結果が必ず同じになっていました（2026年9月20日に直した）。

この試験は元の成功例が悪化した場合か、無音から文字が出た場合に失敗します。難語の未達成例は結果の `ok: false` に残すため、終了時の番号が0でも全語を認識できたという意味ではありません。
