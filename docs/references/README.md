## 素材について決まっていること

- 騎士をもっと精細にする方法として、部位に分けた画像か、外部の立体モデル（GLB）を読み込む案がある。どちらも指示文と要件だけで、素材はまだ無い。GLBを読み込む追加（`@babylonjs/loaders`）も入れていない。手順は[騎士の部位分けと立体化の指示](騎士の部位分けと立体化_生成の指示.md)にある。
- 画像生成による一枚絵を背景や仮の敵に使う場合は、立体の敵と同じように動かせるとは扱わない。見た目の確認用と、実際の戦闘に使う素材を区別する。
- 石の表面の凹凸や光の反射を表す画像、空と遠景の別素材は、まだ用意していない。
