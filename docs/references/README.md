## 使うもの

現在のBabylon.jsを使えば、立体の場面、素材の読み込み、影、発光、粒の表示をまとめられます。Three.jsを追加するだけで画像が精細になるわけではありません。まず現在の仕組みで不足している素材と描画処理を作ります。

- 騎士・剣・盾の3D素材。ゲームへ取り込む形式はGLBを候補にする。選んだ素材の利用条件も記録する。
- GLBの読み込み機能。素材を取り込む段階で、現在のBabylon.jsと版を合わせた `@babylonjs/loaders` を追加する。
- 石の色、表面の凹凸、光の反射を表す画像。背景と鎧を同じ照明で見せる。
- 空と遠景の素材。固定視点なので、遠景は一枚の画像でもよい。
- 発光する線、光点、火花と衝突の処理。現在の平面表示から、背景と光を共有する表示へ移す。

この画像を保存した時点では未実装でした。その後、[一画面の確認用表示と本編への接続](../見た目の確認画面.md)を追加しました。本編の騎士は背景から分けた画像で、待機・ひるみ・構えを戻す動きを表示します。術式は入力点から描画し、蓄積・完成・放出・命中・結果表示まで動作します。[効果音も追加しました](../騎士の動きと効果音.md)。騎士の立体素材への置き換えはまだ残っています。

## 作る順番と確認

1. 最初に、騎士・背景・完成した術式を一枚の画面にそろえる。動かす前に、構図、明るさ、騎士の大きさ、線の細さを基準画像と並べて確認する。
2. 本人の線から、その完成画面へ3秒かけて変わる動きを作る。元の形を既製の魔法陣へ置き換えない。
3. その術式から魔法が飛び、騎士に当たり、光が収まるところまで作る。
4. 最後にカメラと音声認識を同時に動かし、表示の滑らかさと24秒の進行を確認する。

画像生成による一枚絵を背景や仮の敵に使う場合は、立体の敵と同じように動かせるとは扱いません。見た目の確認用と、実際の戦闘に使う素材を区別します。
