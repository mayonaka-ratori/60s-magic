# カットインの立ち絵の生成の指示

> **この素材は使わないことになりました（2026年9月20日）。** このゲームは主観視点で、自分を外から見る絵を入れません。とどめの見せ方は、術式が自分の手前を通り抜ける形に変えました。[防御ととどめの設計](../防御ととどめ_画面と流れの設計.md)を見てください。この文書は、作らないと決めた記録として残しています。

大技の発動のとき、画面に0.3秒だけ差し込む術者（遊ぶ人の分身）の立ち絵です。[大型バトル演出の提案](../大型バトル演出_全面更新の提案.md)の段階5で「素材はこの2点が費用対効果最大」と書いた1点目にあたります。

ユーザーの手元にある画像生成機能で作ります。この文書の指示文をそのまま貼って使えます。まだ読み込む処理はありません。画像を置いたあとに読み込みの実装を作ります。

- 参考にする見た目：`docs/references/魔法ゲーム_見た目の基準.png`、`public/art/ruins-knight-v1.png`
- 置き場所：`public/art/cutin-caster-v1.png`
- 用途：発動の瞬間に0.3秒だけ画面の左右どちらかから差し込む。光や文字はアプリ側で重ねる。

## 作るもの

| 項目 | 決めたこと |
| --- | --- |
| 寸法 | 1200×1600（縦長）。これより大きくても縦横の比を3対4に保つ |
| 背景 | 透過（本当の透明。市松模様の絵を描かない） |
| 向き | 正面か、やや右向き（画面の右側を向く）。上半身が主役で、腰から下は入っても入らなくてもよい |
| 色味 | 冷たい灰青色を基調に、青白い術式の光を顔と手の片側に当てる。鎧の騎士と同じ曇り空の照明 |
| 枚数 | 1枚だけ。属性ごとの描き分けはしない |
| 余白 | 上下左右に4%ほどの透明の余白。角や髪の先が縁で切れないようにする |

属性（炎、氷、雷、風、光、闇）の違いは、アプリ側でこの1枚に色を重ねて出します。素材の時点では青白いままにしておきます。そのため、素材に強い色を焼き付けないことが大事です。

## 避けること

- 文字、記号、透かし、署名、枠線。
- 複数の人物。術者は1人だけ。
- 実在の人物や、既存の作品の登場人物に似せること。
- 背景、地面、接地影。光の効果や魔法陣を絵に焼き付けること。
- 白飛び（顔や鎧の明るい部分が真っ白につぶれること）。

## 指示文（日本語）

```text
用途：ブラウザーの暗い幻想世界の魔法ゲームで、大技の発動時に0.3秒だけ差し込む一枚絵（カットイン）。
出力：縦長1200×1600の透過PNG。背景は本当の透明。市松模様、地面、接地影、背景、枠線を描かない。
描くもの：術者1人だけ。上半身を大きく。石の遺跡に立つ魔法使いで、灰青のフード付き外套、内側に薄い鎧、襟と留め具に鈍い金の細工。顔は見えるが、目元にわずかな影。片手を前に構え、指先の近くに淡い青白い光の気配（線や魔法陣は描かない）。
構図：体は正面からわずかに右へ向く。視線は画面の右奥へ。頭の先を上から6%、腰を下から25%あたり。上下左右に4%の透明な余白を残し、外套や髪の先を縁で切らない。
光と色：曇り空の冷たい光を上から。顔と手の片側にだけ青白い照り返し。全体は灰青と暗い鋼色、差し色に鈍い金。彩度は低め。明るい部分を白でつぶさない。
質感：写実寄りの高精細なゲームの絵。同じ世界に立つ鎧の騎士と同じ質感と照明。漫画調、平板な塗り、低ポリゴンにしない。
禁止：文字、記号、透かし、署名、複数人、武器の派手な発光、実在の人物や既存作品の模倣、体力ゲージなどの表示。
```

## 置き場所と受け入れの確認

できた画像を `public/art/cutin-caster-v1.png` として置きます。作り直したときは `-v2` のように数字を上げ、古いものはすぐ消さずに残しておきます。

確認すること。

1. 透明があるか。ブラウザーでファイルを直接開き（`http://localhost:5173/art/cutin-caster-v1.png`）、背景が白や市松模様ではなく透けて見える。
2. 寸法が1200×1600か。ファイルを右クリックして情報を見るか、ブラウザーの表示で確かめる。
3. 上下左右に透明の余白があり、体の一部が縁で切れていない。
4. 明るい部分が真っ白につぶれていない。特に顔と肩。
5. 人物が1人だけで、文字が入っていない。

`npm run setup:assets` は手の認識に使うファイルを用意するコマンドで、この画像とは関係ありません。画像は `public/art/` に置くだけで、開発用のサーバーからそのまま見えます。音素材のような一覧ファイル（`manifest.json`）はまだ作っていません。

読み込む処理はまだありません。画像を置いたあと、発動の0.3秒だけ表示する処理を作ります。
