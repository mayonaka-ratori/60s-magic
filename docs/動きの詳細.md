# 動きの詳細

90秒の中で何がいつ起きるか、Jevと音声認識がどう動くかをまとめています。起動や試験の手順は [README](../README.md)、どこまで確認できたかは [実装と確認の記録](実装と確認の記録.md) にあります。

## 回ごとの時刻

時刻はすべて `src/game/rounds.ts` の二つの表から作ります。「順番に」は `SEQUENTIAL_ROUNDS`、「同時に」は `TOGETHER_ROUNDS` です。URLに `?flow=together` があれば「同時に」、なければ「順番に」の表をページを開いたときに選び、演出も騎士も音もその表を見ます。下の秒数は表を読み替えたものです。

### 順番に（標準）

| 回 | 描く時間 | 声の受付 | 確定 | 発動 | 命中 | 次へ渡す間 | 終わり |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 一回目 | なし | 0〜14秒 | 17秒 | 18秒 | 19.5秒 | 24秒 | 26秒 |
| 防御 | 26〜38秒 | なし | 40秒 | 41秒 | 42.4秒 | 46秒 | 50秒 |
| とどめ | 50〜62秒 | 62〜72秒 | 75秒 | 76秒 | 77.6秒 | 84秒 | 90秒 |

### 同時に

| 回 | 描く時間と声の受付 | 詠唱の案内 | 確定 | 発動 | 命中 | 次へ渡す間 | 終わり |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 一回目 | 0〜18秒 | 14秒 | 21秒 | 22秒 | 23.5秒 | 29秒 | 30秒 |
| 防御 | 30〜45秒 | 40秒 | 48秒 | 49秒 | 50.4秒 | 55秒 | 56秒 |
| とどめ | 56〜72秒 | 64秒 | 75秒 | 76秒 | 77.6秒 | 84秒 | 90秒 |

「同時に」の一回目だけ、7秒から線に光点が付き始めます。とどめの回はどちらも、命中のあとに核への特大の一撃（表では78.5秒）があります。72秒より後ろは、二つの遊び方で同じ時刻です。

締め切りから確定までの間に、声の最後の文字（締め切りから2秒まで）とJevの返事（確定の0.1秒前まで）を待ちます。声を使わない回（「順番に」の防御）は声を待たず、締め切りの0.1秒後にJevへ送ります。

回の始まりの合図は遊び方で違います。「順番に」は三回とも「第一幕　詠唱を始めよう！」「第二幕　魔法陣を描こう！」「第三幕　魔法陣を描こう！」を1.5秒出して0.5秒で消し、とどめの62秒にも「手を止めて、詠唱を始めよう！」を同じ長さで出します。「同時に」は防御ととどめの始まりに「第二幕　防御」「第三幕　とどめ」を0.8秒出します。どちらも合図の間も入力を受け付けます。

残り時間は、描いて唱えられる締め切りまでを数えます。どの回も、締め切りの残り5秒から画面の縁が光り、残り3秒からは秒が変わるたびに強く光ります。

## 一回目の進行

### 順番に（声だけ）

| 時刻 | 動作 |
| --- | --- |
| 開始前 | 音声認識につないでから、「まもなく始まる。手を画面の前に」と3秒の合図。この3秒は90秒に含めない |
| 0〜14秒 | 声だけを受け付ける。手の位置は光の点で追うが、線は残らない。言葉が届くたびに、画面の下寄りの円へ色・形・動き・指示・呼び掛けの光が部品として積み重なる。3.5秒に騎士が足を踏み替え、9.5秒に盾を打ち鳴らす |
| 14〜16秒 | 録音を締め、文字の最終結果を最大2秒待つ。先に届けばすぐJevへ送る |
| 16.9秒 | Jevの返事を待つのをやめる |
| 17秒 | 魔法の内容を固定。以後の回答は使わない |
| 14〜18秒 | 部品が中心へ集まる。18秒の手前0.08秒は完全に暗くする |
| 18〜24秒 | 決まった魔法の色と形で放ち、19.5秒に騎士へ届く。騎士がひるみ、構えを戻す |
| 24〜26秒 | 戦闘中の光を収める。騎士が剣を引いて構える |

言い直した部品は薄く残り、同じ言葉を繰り返しても部品は増えません。締め切りのあとは増やしません。部品は32個までです。円の縁から、言葉の色を持つ光点を三つまで次の回へ渡します。何も唱えなければ白金色の光点を一つ渡します。

### 同時に（描きながら唱える）

| 時刻 | 動作 |
| --- | --- |
| 開始前 | 音声認識につないでから、「詠唱の準備を始めよ」と3秒の合図。手やマウスの位置を決める。この3秒は90秒に含めない |
| 0〜7秒 | 手に追従する線。声も受け付ける。3.5秒に騎士が足を踏み替える |
| 7〜14秒 | 元の線を保ち、光点と短い接続線を足す。9.5秒に騎士が盾を打ち鳴らす |
| 14〜18秒 | 描きながら詠唱。最後まで線と言葉を受け付ける |
| 18〜20秒 | 描画と録音を締め、文字の最終結果を待つ。先に届けばすぐJevへ送る |
| 20.9秒 | Jevの返事を待つのをやめる |
| 21秒 | 魔法の内容を固定。以後の回答は使わない |
| 18〜22秒 | 線に光が巡り、中心へ集まり、完成する。22秒の手前0.08秒は完全に暗くする |
| 22〜29秒 | 本人の術式から放ち、23.5秒に騎士へ届く。騎士がひるみ、構えを戻す |
| 29〜30秒 | 戦闘中の線と光を収める。騎士が剣を引いて構える |

## 防御の進行

どちらの遊び方でも、防御の回の始まりに騎士の剣先から赤い予告の線が走り、狙いの輪が画面の左寄り（横27%、高さの真ん中）に浮かびます。回の始まりの0.2秒後から、騎士は剣を少しずつ振り上げて溜め、確定の3秒前に上げきります。溜めの間は刃が赤く脈打ち、後ろに黒い光がにじみ、画面が低く震え続けます。

### 順番に（手だけ）

| 時刻 | 動作 |
| --- | --- |
| 26〜38秒 | 輪の中に、または輪を囲むように描く。声の受付はない |
| 38〜39秒 | 描画を締める。輪から離れた線だけ、1秒かけて輪の前へ運ぶ |
| 38.1〜39.9秒 | 描いた線をJevへ送り、39.9秒で待つのをやめる |
| 40秒 | 魔法の内容と盾を固定。描いた形で止め方が決まる。騎士が振り下ろす |

### 同時に（描きながら唱える）

| 時刻 | 動作 |
| --- | --- |
| 30〜45秒 | 輪の中に、または輪を囲むように描く。声も受け付け、40秒から詠唱の案内 |
| 45〜47秒 | 描画と録音を締め、文字の最終結果を待つ。輪から離れた線だけ、1秒かけて輪の前へ運ぶ |
| 47.9秒 | Jevの返事を待つのをやめる |
| 48秒 | 魔法の内容と盾を固定。言葉で止め方が決まる。騎士が振り下ろす |

### 確定のあと（両方同じ流れ）

| 順番に | 同時に | 動作 |
| --- | --- | --- |
| 40.55秒 | 48.55秒 | 剣が床を打つ。画面が下へ大きく揺れ、足元に赤熱した亀裂と塵が出る |
| 41秒 | 49秒 | 盾が輪の前に立つ。手前の0.08秒は完全に暗くする |
| 41.4〜42.4秒 | 49.4〜50.4秒 | 三日月の斬撃が、予告の線の上を進んでくる |
| 42.4秒 | 50.4秒 | 盾に当たる。0.14秒の停止、寄り、奥から手前への揺れ、接触点の火花と輪 |
| 42.4〜44.5秒 | 50.4〜52.5秒 | 止め方ごとの消え方。弾き返したときは、当たった0.8秒後に騎士が自分の一撃を受ける |
| 44.5秒 | 52.5秒 | 兜の角が1本折れ、体力が10減る（満タンは100）。その0.1秒後から騎士がよろめいて構えを戻す |
| 46秒 | 55秒 | 前屈して胸当てが外れ、胸の核が大きくなって明滅する |

止める長さとスローの値は `src/render/effects/screen.ts` の `FINISH_STOPS` と `FINISH_SLOW` にあります。控えめモードでは止めがなく、スローだけが残るので、78.5秒より後ろは上の表より早く進みます。

残り時間の表示、録音の締め切り、Jevの打ち切り、魔法名の表示、90秒の魔導書は時計どおりの時刻で動きます。騎士、術式、魔法、粒、体力、崩れ落ち、崩れ落ちの音は、止めとスローを入れた時刻で動きます。

外部サービスの返事が遅れても演出は延ばしません。自動の再試行もしません。

## 盾の決め方

中身は `src/game/guard.ts` にあります。盾の形の決め方は二つの遊び方で同じで、止め方の決め方だけが違います。

- 印は画面の左寄り（横27%、高さの真ん中）に浮かび、半径は画面の短いほうの辺の1割です（横長の画面では高さと同じ）。縦長の画面で輪や目盛りが画面の外へ出ないようにするためです。騎士と重ならない空いた場所に置いています。
- 囲めたかどうかは「一筆で印のまわりを何度回ったか」で甘く見ます。240度（四分の三）以上回れば、閉じていない輪も囲めたことにします。なぞり返した輪も、逆回りに重ねた輪も囲めたことになります。印から離れたところで折り返しただけの線や、ごく小さい線は数えません。
- 囲えた輪が一つ以上あれば、一番外の輪をそのまま盾の縁にします。囲えていなくても、印の範囲（半径の1.2倍まで）に線が掛かっていれば、その線を描いた場所のまま盾にします。範囲は画面に描いてある輪と同じ形で測るので、横長の画面でも縦長の画面でも、見た目どおりの広さになります。どちらでもなければ、印に一番近い筆を形のまま印の前へ運びます。全く描いていなければ、印の前に小さい光の玉を出します。失敗にはしません。
- 層の数は、詠唱で数を言っていればその数、言っていなければ囲った数です。5枚までです。
- 横長は壁、縦長は柱、小さい動きは玉、それ以外は輪として見せます。

止め方は次のとおりです。

- 順番に：描いた形で決まります。囲えたら弾き返し（内側は膜）、線が輪に掛かっていれば受け止め（内側は格子）、それ以外はかき消します（内側は玉）。線が無いときもかき消します。盾は属性を持ちません。
- 同時に：詠唱で決まります。「返せ」「弾き返せ」「反発」などで跳ね返し、「消せ」「かき消せ」「燃やせ」「浄化」などで消し、それ以外は受け止めます。かなのままの聞き取り（「はじきかえせ」など）も拾います。「弾き返さないで」のように打ち消したときは、その止め方にしません。

## 線の扱い

- 元の点列と表示用の点列を分けています。表示だけ手ごとに256点へ間引き、元の点列は残します。
- 認識が350ms以上途切れたときと大きく位置が飛んだときは筆を分けます。止まったことを受付終了の条件にはしません。
- 小さい動きは、入力を終えた後の完成演出で拡大します。
- 完成した術式は太い主線と外側の帯の二重で描き、暗い背景でもはっきり見えるようにしています。

## 魔法の形

球・光線・壁・結界・波・連弾があります。雷は枝分かれ、氷は結晶など、属性で色と形を変えます。明示した個数は最大8つです。一回目に防御の言葉を唱えると騎士の前へ広がる壁、拘束は騎士を囲む線、強化は力の波として見せます。これは魔法の用途の話で、防御の回の盾とは別です。

属性の言葉は `src/game/recipe.ts` で決めます。「雷」のほか、音声認識が「かみなり」「カメナリ」「亀なり」などと書き起こしても雷として受け付けます。「雷ではなく氷」のような言い直しは後半を使い、「攻撃しないで」のような否定は攻撃に数えません。

## 騎士と効果音

騎士はアプリの中で組み立てた立体で、10の姿勢を混ぜて動かします。作り方、姿勢、命中の反応、体力の表示、効果音は [騎士の動きと効果音](騎士の動きと効果音.md) にあります。とどめの後の崩れ落ちは [とどめと結果の詳細設計](とどめと結果_詳細設計.md) にあります。

効果音はブラウザー内で合成し、`public/audio/` に素材があればその上に重ねます（[音素材の入れ方](音素材の入れ方.md)）。初期音量は25%です。口元のマイクを使う前提なので、録音中も騎士の足踏みと盾打ち、印を囲えた合図を鳴らします。そのかわり、声を受け付けている間だけ曲と効果音を8dB下げます。「順番に」では一回目の0〜14秒ととどめの62〜72秒、「同時に」では三回の受付の間です。マイクを使わないときは下げません。中止すると曲は0.35秒かけて絞ります。音の時刻は `src/audio/cues.ts` が回の表から作ります。

## このPCでの音声認識

Kotoba-Whisper v2.0 を使います。動かし方はPCに合わせて自動で選びます。

| PC | 動かし方 | 初期のモデル |
| --- | --- | --- |
| Apple SiliconのMac | mlx-whisper（MacのGPU） | `kotoba-v2.0-mlx` |
| Windows | faster-whisper（NVIDIAのGPUがあればGPU、なければCPU） | `kotoba-v2.0` |
| それ以外 | faster-whisper（GPUがあればGPU、なければCPU） | `small` |

CPUだけでKotoba-Whisperを動かすと一回に数秒かかり、声の受付に間に合わないので、MacとWindows以外では小さい `small` を初期値にしています。日本語の聞き取りは粗くなります。WindowsでもNVIDIAのGPUが無いPCでは同じく遅くなるので、`.env` の `LOCAL_SPEECH_MODEL_ID` を `small` にしてください。どのモデルが間に合うかは `npm run benchmark:speech` で比べられます。測った値は [確認に使うPC](確認に使うPC.md) にあります。

声を受け付ける回は、「順番に」では一回目ととどめの二回、「同時に」では三回ともです。動き方は次のとおりです。

- 一回目の接続は、開始の合図の前に作ります。二回目からは、前の回でJevへ送るときに接続を閉じ、その回の声の受付開始の2.5秒前からつなぎ直し、受付開始から録音します（「順番に」は59.5秒、「同時に」は27.5秒と53.5秒）。つなぎ直せないときは、その回は文字の欄を出して、描いた線と文字で進みます。
- マイクの音を16kHz・一チャンネルに変え、0.1秒ぶんずつこのPCのサーバーへ送ります。短い無音で受付を終えません。
- 声の時刻は回ごとに、その回の始まりを0として数えます。「順番に」のとどめは、描く時間の12秒ぶん後ろから声が入ります。
- サーバーは約0.65秒ごとに「先頭から今まで」を聞き直します。途中結果でも一続きの文になります。受付の終わりの2秒前（`SPEECH_WAIT_MS` と同じ長さ）からは途中の認識を始めず、終わりの音を含む最後の一回を優先します。
- 締め切りで受付を終え、最後の結果を最大2秒待ちます。届かなければ、それまでの最後の途中結果を使い、結果の画面に「途中の聞き取りを使用」と出します。
- 認識の手掛かりとして辞書の14語を渡します。ただしMacのGPU（mlx）では渡しません。渡すと悪くなったためです（`LOCAL_SPEECH_HINTS` で変えられます）。語を増やしても悪くなったので、14語のままです。
- 聞き取りの書き方の揺れ（伸ばす音、濁点の抜け）は辞書へ寄せます。寄せたものは確認用の記録の各回の `corrections` に残り、元の文字は `rawTranscript` に残ります。
- 声はこのPCから外へ送らず、録音ファイルにも残しません。認識結果の文字は、Jevを設定した場合だけJevへ送ります。
- 同時に音声認識を使える画面は一つです。認識が止まったら起動し直してください。

`npm run setup:speech` はPython 3.12と必要なソフトを `.venv-speech` に、認識用ファイルを `.local-speech/models/<モデル名>` に置きます。PC全体のPythonは変更しません。

## Jev

`JEV_API_KEY` を設定すると、サーバーから `https://api.typesafe.ai/v1/systemone` へ12問を送ります。属性・用途・形・進み方、守る性質・広さ・持続・集中、囲う・分裂・前回との関係・動きと言葉の一致です。同じ入力を独立した12問で評価し、秘密の値はブラウザーに送りません。モデルは `jev-1.13.0` が初期値です。

返された候補の確率、次点との差、数値の範囲を確認し、明示した肯定の言葉を優先します。曖昧な項目はその項目だけPC内の規則で補い、採用した理由を記録します。サーバーは900ms、ブラウザー側は確定の0.1秒前で打ち切ります（「順番に」は16.9秒、39.9秒、74.9秒、「同時に」は20.9秒、47.9秒、74.9秒）。遅い回答、別のプレイ番号、別の入力版は使いません。未設定なら全部PC内の規則で決めます。

## Google Cloud Speech-to-Text V2（普段は使わない）

`SPEECH_PROVIDER=google` にしたときだけ使います。`GOOGLE_CLOUD_PROJECT`（プロジェクトID）、`GOOGLE_CLOUD_LOCATION`（初期値 `us`）、`GOOGLE_APPLICATION_CREDENTIALS`（認証ファイルの絶対パス）を `.env` に置きます。Chirp 3、日本語、辞書から作った語句補助を使います。画面の「接続の確認」は設定の有無を示すだけで、接続の成功ではありません。

## 記録に残るもの

- 遊んだ記録（遊び方、確認番号、三つの魔法の内容、描いた線、詠唱の文字）は、魔法が確定するたびにこのPCのブラウザーの中へ自動で保存します。最新200件までです。
- 確認用の記録（JSON）は、`?dev=1` で「記録を保存する」を押した場合だけファイルになります。詠唱の文字、動き、魔法の内容、Jevの回答、感想と、声が届いた時刻や描画の遅れなどの値が入ります。見方は [確認用の記録の見方](確認用の記録の見方.md)。
- どちらにも音声と映像は入りません。公開ページや自動アップロードはまだありません。

日本語表示にはPCへ同梱したNoto Sans JPとNoto Serif JPを使い、外部のフォント配信に依存しません。
