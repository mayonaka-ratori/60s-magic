# 動きの詳細

90秒の中で何がいつ起きるか、Jevと音声認識がどう動くかをまとめています。起動や試験の手順は [README](../README.md) にあります。

## 回ごとの時刻

時刻は`src/game/rounds.ts`の二つの表で決めます。指定なしは「順番に」、`?flow=together`は「同時に」です。ページを開くときに表を選び、演出・騎士・音も同じ表を読みます。

### 順番に（標準）

| 回 | 描く時間 | 声の受付 | 確定 | 発動 | 命中 | 終わり |
| --- | --- | --- | --- | --- | --- | --- |
| 一回目 | なし | 0〜14秒 | 17秒 | 18秒 | 19.5秒 | 26秒 |
| 防御 | 26〜38秒 | なし | 40秒 | 41秒 | 42.4秒 | 50秒 |
| とどめ | 50〜62秒 | 62〜72秒 | 75秒 | 76秒 | 77.6秒から | 90秒 |

一回目は、下寄りの円に言葉の色・形・動き・指示・呼び掛けの光が積み重なります。言い直した部品は薄く残り、同じ語の繰り返しは増えません。締め切りから確定までに中心へ集まり、発動で決まった魔法の色と形になって放たれます。部品は32個までです。円の縁から言葉の色を持つ光点を三つまで次へ渡します。無言なら白金色を一つ渡します。

防御は手だけで、囲うと弾き返し、線が輪に掛かると受け止め、離れているとかき消します。線が無いときもかき消します。盾の縁は本人の線のまま、内側は膜・格子・玉になり、色は白金色です。声の接続と待ち時間はありません。

とどめは62秒で線が固まり、手の光点が消え、「手を止めて、詠唱を始めよう！」と出ます。その瞬間から声を受け付けます。接続の準備は2.5秒前です。三回の始まりにも2秒の合図を出し、合図の間も入力を受け付けます。72秒より後ろの発動・命中・崩れ落ち・魔導書は両方の遊び方で共通です。

### 同時に

以下の表と「一回目の進行」「防御の進行」は「同時に」の詳細です。

| 回 | 入力の開始 | 詠唱の案内 | 締め切り | 確定 | 発動 | 敵へ届く | 終わり |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 一回目 | 0秒 | 14秒 | 18秒 | 21秒 | 22秒 | 23.5秒 | 30秒 |
| 防御 | 30秒 | 40秒 | 45秒 | 48秒 | 49秒 | 50.4秒 | 56秒 |
| とどめ | 56秒 | 64秒 | 72秒 | 75秒 | 76秒 | 77.6秒 | 90秒 |

とどめの回だけ、敵へ届いたあとに核への特大の一撃（78.5秒）があります。

描いて唱えられるのは、一回目18秒、防御15秒、とどめ16秒です。締め切りから確定までは三回とも3秒で、その間に声の最後（2秒まで）とJevの返事（0.9秒まで）を待ちます。

## 一回目の進行（同時に）

| 時刻 | 動作 |
| --- | --- |
| 開始前 | 機器の準備が終わると「詠唱の準備を始めよ」と3秒の合図。手やマウスの位置を決める。この3秒は90秒に含めない |
| 0〜7秒 | 手に追従する線。声も受け付ける |
| 7〜14秒 | 元の線を保ち、光点と短い接続線を追加 |
| 14〜18秒 | 描きながら詠唱。最後まで線と言葉を受け付ける |
| 18〜20秒 | 描画と録音を締め、文字の最終結果を待つ。先に届けばそこで切り上げる |
| 20〜20.9秒 | 動きと言葉を一回の要求でJevへ送る（文字が届き次第、遅くとも20秒に送り、20.9秒で打ち切る） |
| 21秒 | 魔法の内容を固定。以後の回答は使わない |
| 18〜22秒 | 線に光が巡り、中心へ集まり、完成する |
| 22〜29秒 | 本人の術式から放出し、騎士へ作用して余韻を残す。23.5秒で騎士がひるみ、構えを戻す |
| 29〜30秒 | 戦闘中の線と光を収める。騎士が剣を引いて構える |

## 防御の進行（同時に）

| 時刻 | 動作 |
| --- | --- |
| 30秒 | 「第二幕　防御」を0.8秒。騎士の剣先から赤い線が走り、狙いの輪が画面の左寄り（横27%、高さの真ん中）に浮かぶ |
| 30〜40秒 | 輪の中に、または輪を囲むように描く。輪に線が掛かると赤から属性の色へ変わり、囲えると内側が濃く満ちる。囲った数だけ層になる |
| 40〜45秒 | 描きながら詠唱。騎士は剣を頭上へ上げ、足元に赤いひびが走る |
| 45〜47秒 | 描画と録音を締め、文字の最終結果を待つ。輪から離れた線だけ、1秒かけて輪の前へ運ぶ |
| 47〜47.9秒 | 動きと言葉をJevへ送り、47.9秒で打ち切る |
| 48秒 | 魔法の内容と盾を固定。ここで止め方（受け止める・弾き返す・かき消す）が決まる |
| 49秒 | 盾が輪の前に立つ |
| 49.4〜50.4秒 | 三日月の斬撃が、予告の線の上を進んでくる |
| 48〜49秒 | 騎士が振り下ろす。48.55秒に剣が床を打ち、画面が下へ大きく揺れ、足元に赤熱した亀裂と塵が出る。49秒の手前0.08秒は完全に暗くする |
| 50.4秒 | 盾に当たる。140msの停止、寄り、奥から手前への揺れ、接触点の火花と輪 |
| 50.4〜52.5秒 | 止め方ごとの消え方。弾き返しでは51.2秒に騎士が自分の一撃を受ける |
| 52.5秒 | 兜の角が1本折れ、体力が10%減る。52.6秒から騎士がよろめいて構えを戻す |
| 55〜56秒 | 前屈して胸当てが外れ、胸の核が2倍になって明滅する |

## とどめの進行（72秒までの入力欄は同時に、以降は共通）

とどめの回だけ、途中で時間の進み方を変えます。「実際」は時計どおりの時刻です。77.6秒より前は、見た目の時刻と実際の時刻が同じです。くわしい台本は [とどめと結果の詳細設計](とどめと結果_詳細設計.md) の3章にあります。

| 時刻（実際） | 動作 |
| --- | --- |
| 56秒 | 「第三幕　とどめ」を0.8秒。騎士は前屈のまま、胸の核が明滅する |
| 56〜64秒 | 一回目と防御の光点が左右の端から中央へ寄ってくる。新しい線をそこへ足す。声も受け付ける |
| 64〜72秒 | 「全力で詠唱せよ」。描きながら約8秒唱える。残り5秒からは締め切りの光が脈打つ |
| 72〜74.6秒 | 描画と録音を締める。粒が中心へ吸い込まれ、背景が暗くなって色が抜ける |
| 74.6〜75.6秒 | 術式が騎士の胸の核へ向く。核が最大の明るさになる |
| 75秒 | 魔法の内容を固定。以後の回答は使わない |
| 75.6〜75.92秒 | 0.32秒、見た目が止まる。音も抜く。術式だけが白く息をする |
| 75.92〜76秒 | 0.08秒、完全に暗くして無音にする |
| 76〜76.25秒 | 発動。術式が自分の手前を通り抜け、画面の外へ消える |
| 76.3〜77.5秒 | 輪を5枚くぐって奥へ伸びる。くぐるたびに太く速くなる |
| 77.6秒 | 一発目が当たる。肩の棘が飛び、傷あとが残る。体力が減り始める |
| 77.86／78.02／78.20秒 | 続けて当たる。盾、兜の角、胸当ての破片が飛ぶ |
| 78.20〜78.6秒 | 0.4秒あけて、一度静かにする |
| 78.6〜78.85秒 | 核へ特大の一撃。0.25秒止まり、体力が0になる |
| 78.85〜79.82秒 | 破片が動き出し、核が砕けるところだけゆっくり見せる |
| 79.82〜80.52秒 | 剣を手放す。床で跳ねて止まる |
| 80.52〜81.63秒 | 膝をつく。体力の枠が割れて薄れ、名前ごと消える |
| 81.63〜82.72秒 | 手前へ倒れてくる。床の塵が手前へ広がる |
| 84〜85.5秒 | 余韻。自分の術式だけが目の前に残る。魔法名が画面の下に浮かび、85.5秒で引く |
| 85.5〜90秒 | 術式の光がゆっくり抜ける。90秒でもわずかに残ったまま結果画面へ渡る |

残り時間の表示、録音の締め切り、Jevの打ち切り、魔法名の表示、90秒の魔導書は実際の時刻で動きます。騎士、術式、魔法、粒、体力、崩れ落ちは、途中で進み方を変えた時刻で動きます。

外部サービスの返事が遅れても演出は延ばしません。自動の再試行もしません。

## 盾の決め方（言葉で止め方を選ぶ部分は同時に）

- 印は画面の左寄り（横27%、高さの真ん中）に浮かび、半径は画面の短いほうの辺の1割です（横長の画面では高さと同じ）。縦長の画面で輪や目盛りが画面の外へ出ないようにするためです。騎士と重ならない空いた場所に置いています。
- 印を囲めたかは甘く見ます。開いたままの線も、始点と終点を結んで囲めていれば囲ったことにします。面積がほとんどない線（横に引いただけの線）は数えません。
- 囲えた輪が一つ以上あれば、一番外の輪をそのまま盾の縁にします。囲えていなくても、印の範囲（半径の1.2倍まで）に線が掛かっていれば、その線を描いた場所のまま盾にします。範囲は画面に描いてある輪と同じ形で測るので、横長の画面でも縦長の画面でも、見た目どおりの広さになります。運びません。どちらでもなければ、印に一番近い筆を形のまま印の前へ運びます。全く描いていなければ、印の前に小さい光の玉を出します。失敗にはしません。
- 層の数は、詠唱で数を言っていればその数、言っていなければ囲った数です。5枚までです。
- 横長は壁、縦長は柱、小さい動きは玉、それ以外は輪として見せます。
- 止め方は詠唱で決まります。「返せ」「弾き返せ」「反発」で跳ね返し、「消せ」「かき消せ」「燃やせ」「浄化」で消し、それ以外は受け止めます。かなのままの聞き取り（「はじきかえせ」など）も拾います。「弾き返さないで」のように打ち消したときは、その止め方にしません。
- 囲めたかどうかは「印のまわりを何度回ったか」で見ます。240度（四分の三）以上回れば囲めたことにします。なぞり返した輪も、逆回りに重ねた輪も囲めたことになります。印から離れたところで折り返しただけの線は、囲めたことになりません。

## 線の扱い

- 元の点列と表示用の点列を分けています。表示だけ手ごとに256点へ間引き、元の点列は残します。
- 認識が350ms以上途切れたときと大きく位置が飛んだときは筆を分けます。止まったことを受付終了の条件にはしません。
- 小さい動きは、入力を終えた後の完成演出で拡大します。
- 完成した術式は太い主線と外側の帯の二重で描き、暗い背景でもはっきり見えるようにしています。

## 魔法の形

球・線・壁・結界・波・複数弾があります。雷は枝分かれ、氷は結晶など、属性で色と形を変えます。明示した個数は最大8つです。防御の言葉は騎士の前へ広がる壁、拘束は騎士を囲む線、強化は力の波として見せます。いずれも一回目の魔法の作用で、二回目の防御場面ではありません。

属性の言葉は `src/game/recipe.ts` で決めます。「雷」のほか、音声認識が「かみなり」「カメナリ」「亀なり」などと書き起こしても雷として受け付けます。「雷ではなく氷」のような言い直しは後半を使い、「攻撃しないで」のような否定は攻撃に数えません。

## 騎士と効果音

騎士は角柱・円錐・半球だけで組んだ立体で、部品は40ほど。胴・首・体のひねり・両腕の5か所を動かし、待機・ひるみ・構えを戻す姿勢を混ぜます。待機は剣を振りかぶった構えで、5.6秒に一度ゆっくり剣が上下します。兜の目と胸の核が光り、命中では胸の前から光が広がります。鎧の模様や布の揺れ、倒れる動きは作っていません。

効果音はブラウザー内で合成し、`public/audio/` に素材があればその上に重ねます。初期音量は25%。ヘッドセットを使い、録音中も足踏み・盾打ち・囲えた合図を鳴らします。声の受付中だけ曲と効果音を8dB下げます。「順番に」の手だけの防御と、とどめで描く時間には下げません。線が残る音は`build`、中心へ集まる音は`inputEnd`の時刻に鳴ります。中止すると曲は0.35秒かけて絞ります。詳しくは [騎士の動きと効果音](騎士の動きと効果音.md) と [音素材の入れ方](音素材の入れ方.md)。

## このPCでの音声認識

Kotoba-Whisper v2.0 を使います。動かし方はPCに合わせて自動で選びます。

| PC | 動かし方 | 初期のモデル |
| --- | --- | --- |
| Apple SiliconのMac | mlx-whisper（MacのGPU） | `kotoba-v2.0-mlx` |
| WindowsとNVIDIAのGPU | faster-whisper（GPU） | `kotoba-v2.0` |
| それ以外（CPUだけ） | faster-whisper（CPU） | `small` |

CPUだけでKotoba-Whisperを動かすと一回に数秒かかり18秒の詠唱に間に合わないので、CPUだけのPCでは小さい `small` を初期値にしています。日本語の聞き取りは粗くなります。どのモデルが間に合うかは `npm run benchmark:speech` で比べられます。測った値は [確認に使うPC](確認に使うPC.md) にあります。

動き方は次のとおりです。

- マイクの音を16kHz・一チャンネルに変え、0.1秒ほどずつこのPCのサーバーへ送ります。短い無音で受付を終えません。
- サーバーは約0.65秒ごとに「先頭から今まで」を聞き直します。途中結果でも一続きの文になります。受付の終わりの2秒前からは途中の認識を始めず、終わりの音を含む最後の一回を優先します。一回目（18秒）なら16秒から、防御（15秒）なら13秒からです。
- 声の時刻は回ごとに0から数え直します。防御の回は、一回目の確定で接続を閉じたあと、27.5秒からつなぎ直し、30秒ちょうどから録音を始めます。つなぎ直せないときは、その回は文字の欄を出して、描いた線と文字で進みます。
- 18秒（防御は45秒）で受付を終え、最後の結果を最大2秒待ちます。声が長くなったぶん、待つ時間も1.4秒から広げてあります。届かなければ、それまでの最後の途中結果を使い、結果の画面に「途中の聞き取りを使用」と出します。
- 認識へ渡す手掛かりは辞書の14語です。語を増やすと悪化したので、増やしていません。
- 聞き取りの書き方の揺れ（伸ばす音、濁点の抜け）は辞書へ寄せます。寄せたものは記録の `corrections` に残り、元の文字は `rawTranscript` に残ります。
- 声はこのPCから外へ送らず、録音ファイルにも残しません。認識結果の文字は、Jevを設定した場合だけJevへ送ります。
- 同時に音声認識を使える画面は一つです。認識が止まったら起動し直してください。

`npm run setup:speech` はPython 3.12と必要なソフトを `.venv-speech` に、認識用ファイルを `.local-speech/models/<モデル名>` に置きます。PC全体のPythonは変更しません。

## Jev

`JEV_API_KEY` を設定すると、サーバーから `https://api.typesafe.ai/v1/systemone` へ12問を送ります。属性・用途・形・進み方、守る性質・広さ・持続・集中、囲う・分裂・前回との関係・動きと言葉の一致です。同じ入力を独立した12問で評価し、秘密の値はブラウザーに送りません。モデルは `jev-1.13.0` が初期値です。

返された候補の確率、次点との差、数値の範囲を確認し、明示した肯定の言葉を優先します。曖昧な項目はその項目だけPC内の規則で補い、採用した理由を記録します。サーバーは900ms、ブラウザー側は20.9秒（防御は47.9秒、とどめは74.9秒）で打ち切ります。遅い回答、別のプレイ番号、別の入力版は使いません。未設定なら全部PC内の規則で決めます。

## Google Cloud Speech-to-Text V2（普段は使わない）

`SPEECH_PROVIDER=google` にしたときだけ使います。`GOOGLE_CLOUD_PROJECT`（プロジェクトID）、`GOOGLE_CLOUD_LOCATION`（初期値 `us`）、`GOOGLE_APPLICATION_CREDENTIALS`（認証ファイルの絶対パス）を `.env` に置きます。Chirp 3、日本語、辞書から作った語句補助を使います。画面の「接続の確認」は設定の有無を示すだけで、接続の成功ではありません。

## 記録に残るもの

「記録を保存する」を押した場合だけ、詠唱の文字・動き・魔法の内容・Jevの回答・感想と、声が届いた時刻や描画の遅れなどの確認用の値をJSONへ保存します。音声と映像は入りません。見方は [確認用の記録の見方](確認用の記録の見方.md) にあります。公開ページや自動アップロードはありません。

日本語表示にはPCへ同梱したNoto Sans JPとNoto Serif JPを使い、外部のフォント配信に依存しません。
