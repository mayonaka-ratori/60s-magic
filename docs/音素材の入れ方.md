# 音素材の入れ方

2026年9月20日。効果音と戦闘曲を外部の素材で鳴らせるようにしました。素材ファイル本体はGitに入れません（素材ごとに配布条件が違うため）。このPCの `public/audio/` に置くと鳴ります。

## 仕組み

- `public/audio/manifest.json` に、合図ごとに鳴らすファイルと音量を書いてあります。
- ファイルがあればその音を鳴らし、続けて今までの合成音を重ねます。素材だけにしたい合図は `"synth": false` を足します。
- ファイルが無い合図は合成音だけで鳴ります。一覧そのものが無くてもゲームは止まりません。
- 曲は本編の開始でループ再生し、終了と中止で短く弱めて止めます。マイクを使う回は録音が終わる18.75秒まで8dB下げ、そのあとゆっくり戻します。効果音は今までどおり18.75秒まで鳴らしません。
- 曲と効果音は別の経路にまとめ、どちらも「効果音」のチェックと音量で一緒に制御します。

置いたあと、次で揃っているか確認できます。

```powershell
npm run audio:check
```

一覧の `credit` に書いた文は、結果画面の下に自動で表示されます（例：「音楽：魔王魂」）。

開始画面で「音を試す」を押すと、`complete` の音（素材があれば素材、無ければ合成音）が鳴ります。プレイ後の記録の `audio.samples` に読めたファイルと無かったファイル、`audio.credits` に表記の文が入ります。

## 置くファイル

ファイル名は一覧の名前に合わせて付け直します。形式はOgg（.ogg）がよいです。曲をループさせるとき、MP3は先頭と末尾に無音が入り継ぎ目に隙間が出ます。Oggが無い素材はMP3でも動きます（一覧の拡張子を書き換えてください）。

| 置く場所 | 使う合図 | 欲しい音 | 候補 |
| --- | --- | --- | --- |
| `bgm/battle.ogg` | 本編の曲 | 遺跡で騎士と向き合う戦闘曲。90秒以上でループできるもの | 魔王魂の「戦闘」から1曲 |
| `sfx/ui-tick.ogg` | 7秒・14秒の案内 | 小さい合図音 | Kenney Interface Sounds、効果音ラボの「ボタン・システム音」 |
| `sfx/build-rise.ogg` | 18.75秒の蓄積 | 1〜2秒かけて上がる唸り | Kenney Sci-fi Sounds（force fieldやengine系）、効果音ラボ「魔法をかける」 |
| `sfx/complete-chime.ogg` | 21秒の完成 | 澄んだ短い鐘や光の音 | 効果音ラボ「決定・キラーン」系、Kenney Interface Sounds |
| `sfx/release-whoosh.ogg` | 22秒の放出 | 風を切る音 | Kenney Sci-fi Sounds（laser系は避け、whooshやthruster）、効果音ラボ「風」 |
| `sfx/impact-heavy-1.ogg`、`-2.ogg` | 23.5秒の命中 | 重い衝撃と金属音。2本あると回ごとに変わる | Kenney Impact Sounds（impactMetal_heavy、impactPlate_heavy）、効果音ラボ「打撃・金属」 |
| `sfx/impact-lightning.ogg` | 雷の命中 | 雷撃。共通の命中の代わりに鳴る | 効果音ラボ「雷・電撃」 |
| `sfx/impact-ice.ogg` | 氷の命中 | 氷が砕ける音 | 効果音ラボ「氷」、Kenney Impact Sounds（impactGlass_heavy） |
| `sfx/impact-fire.ogg` | 炎の命中 | 爆発と炎 | 効果音ラボ「爆発・炎」、Kenney Sci-fi Sounds（explosionCrunch） |
| `sfx/settle-soft.ogg` | 27秒の終わり | 静かな余韻 | 効果音ラボ、Kenney Interface Sounds |

属性つきの3本は無くても構いません。無いときは共通の命中音に、今までの雷や氷の合成音が重なります。

Kenneyのzipの中のファイル名は手元で確認してください。上の名前は候補の目安です。

## 素材の入手先と条件

契約や公開の前に、必ず各サイトの規約の原文を確認してください。下の要点は2026年9月時点の調査によるもので、原文を直接開いて確かめたものではありません。

| 入手先 | 条件の要点 | 表記 |
| --- | --- | --- |
| [Kenney](https://kenney.nl/assets?q=audio)（Impact Sounds、Sci-fi Sounds、Interface Sounds） | CC0。商用可、改変可、表記不要 | 不要 |
| [魔王魂](https://maou.audio/) | 個人・商用とも無料。ゲームへの組み込み可 | 「音楽：魔王魂」を結果画面か配布物の説明に入れる |
| [効果音ラボ](https://soundeffect-lab.info/) | 商用可、改変可、表記不要。素材ファイルそのものの再配布は禁止 | 不要 |
| [小森平の使い方](https://taira-komori.jpn.org/) | 商用可、アプリへの組み込み可、表記不要 | 不要 |
| [Springin' Sound Stock](https://www.springin.org/sound-stock/) | 商用可、ゲーム販売も可、原則表記不要 | 不要 |
| [Sonniss GDC Game Audio Bundle](https://gdc.sonniss.com/) | 商用可、表記不要。個々の音の単体再配布は禁止。容量が大きい | 不要 |

このリポジトリを公開する場合、効果音ラボやSonnissの素材はGitに入れないでください（再配布にあたります）。KenneyのCC0素材は入れても構いません。入れるときは `.gitignore` の `public/audio/` の行を外します。

## 音量の合わせ方

`manifest.json` の `gainDb` で調整します。0が元のまま、-6でおよそ半分、-12でおよそ4分の1です。曲は効果音より下げ、-9前後から始めるとよいです。初期音量25%のまま、会場のスピーカーで聞いて決めてください。曲が大きすぎると詠唱がマイクに入りにくくなります。

## 残っていること

- 90秒全体の合図（76秒の発動、78.5秒のとどめの一撃、騎士が崩れる三つの音、直撃直前の減衰、90秒の魔導書の音）は `src/audio/cues.ts` に入りました。上の表にある音の名前はまだ一回目と防御の分だけなので、とどめの回の素材を入れるときは表に行を足してください。
- 曲を場面ごとに厚くする分離トラック（パッド・低音・打楽器・主旋律）は未対応です。今は1本の曲をループします。
- 実際のスピーカーとマイクで、曲を下げた状態の認識精度は未確認です。

## 確認したこと

`npm test` は63件通過。`tests/browser/sample-audio.spec.ts` は、テスト用に作った短いWAVを通信の途中で差し込み、一覧の読み込み、無いファイルの記録、曲が本編開始1秒以内に始まり終了で止まること、`complete` と `impact` が素材で鳴り他は合成音のままであることを見ます。開発に使った環境には音の出力先が無く、音量の計測（開始画面の試聴、曲の音量、終了後の無音）と、終わりの小さい音（当時の22秒、今は27秒）は確認できていません。手元のPCで `npm run test:browser` を回してください。
