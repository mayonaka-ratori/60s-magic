# 音素材の入れ方

効果音と戦闘曲を外部の素材で鳴らす仕組みです（2026年9月20日作成）。素材ファイル本体はGitに入れません（素材ごとに配布条件が違うため）。このPCの `public/audio/` に置くと鳴ります。

## 仕組み

- `public/audio/manifest.json` に、合図ごとに鳴らすファイルと音量を書いてあります。
- ファイルがあればその音を鳴らし、続けて合成音を重ねます。素材だけにしたい合図は `"synth": false` を足します。
- ファイルが無い合図は合成音だけで鳴ります。一覧そのものが無くてもゲームは止まりません。
- 合図の名前は3つの回と二つの遊び方で共通です。たとえば `build`（蓄積）は、どの回でも入力の締め切りに鳴ります。鳴る時刻の一覧は[騎士の動きと効果音](騎士の動きと効果音.md)の「効果音」にあります。
- 命中、放出、とどめの一撃の素材は、属性によって少し低く（炎と闇）、または高く（氷）再生します。
- 曲は本編が始まるとループで鳴り、終了と中止で短く弱めて止めます。
- 口元のマイク（ヘッドセット）で遊ぶ前提なので、録音中も効果音を鳴らします。マイクを使うときは、声を受け付ける間だけ曲と効果音を8dB下げ、受付の締め切りから戻します。最後の認識結果を待つ間は下げません。「同時に」は三回とも声を受け付けるので三回とも下げ、「順番に」は一回目ととどめの回の声の間だけ下げます（防御の回は手だけなので下げません）。
- 曲と効果音は別の経路にまとめ、どちらも「効果音」のチェックと音量で一緒に制御します。

置いたあと、次で揃っているか確認できます。

```
npm run audio:check
```

一覧の `credit` に書いた文は、結果画面の下に自動で表示されます（例：「音楽：魔王魂」）。

開始画面で「音を試す」を押すと、`complete` の音（素材があれば素材、無ければ合成音）が鳴ります。プレイ後の確認用の記録には、`audio.samples` に読めたファイルと無かったファイル、`audio.credits` に表記の文が入ります。

## 置くファイル

ファイル名は一覧の名前に合わせて付け直します。形式はOgg（.ogg）がよいです。曲をループさせるとき、MP3は先頭と末尾に無音が入り、継ぎ目に隙間が出ます。Oggが無い素材はMP3でも動きます（一覧の拡張子を書き換えてください）。

| 置く場所 | 使う合図 | 欲しい音 | 候補 |
| --- | --- | --- | --- |
| `bgm/battle.ogg` | 本編の曲 | 遺跡で騎士と向き合う戦闘曲。90秒以上でループできるもの | 魔王魂の「戦闘」から1曲 |
| `sfx/ui-tick.ogg` | `trace`、`chant`（線が残り始める案内、詠唱の案内） | 小さい合図音 | Kenney Interface Sounds、効果音ラボの「ボタン・システム音」 |
| `sfx/build-rise.ogg` | `build`（入力の締め切りからの蓄積） | 1〜2秒かけて上がる唸り | Kenney Sci-fi Sounds（force fieldやengine系）、効果音ラボ「魔法をかける」 |
| `sfx/complete-chime.ogg` | `complete`（確定） | 澄んだ短い鐘や光の音 | 効果音ラボ「決定・キラーン」系、Kenney Interface Sounds |
| `sfx/release-whoosh.ogg` | `release`（発動） | 風を切る音 | Kenney Sci-fi Sounds（laser系は避け、whooshやthruster）、効果音ラボ「風」 |
| `sfx/impact-heavy-1.ogg`、`-2.ogg` | `impact`（一回目ととどめの回の命中） | 重い衝撃と金属音。2本あると鳴るたびに交互に使う | Kenney Impact Sounds（impactMetal_heavy、impactPlate_heavy）、効果音ラボ「打撃・金属」 |
| `sfx/impact-lightning.ogg` | `impact.lightning`（雷の命中） | 雷撃。共通の命中の代わりに鳴る | 効果音ラボ「雷・電撃」 |
| `sfx/impact-ice.ogg` | `impact.ice`（氷の命中） | 氷が砕ける音 | 効果音ラボ「氷」、Kenney Impact Sounds（impactGlass_heavy） |
| `sfx/impact-fire.ogg` | `impact.fire`（炎の命中） | 爆発と炎 | 効果音ラボ「爆発・炎」、Kenney Sci-fi Sounds（explosionCrunch） |
| `sfx/settle-soft.ogg` | `settle`（回の終わりの静かな音） | 静かな余韻 | 効果音ラボ、Kenney Interface Sounds |

属性つきの3本は無くても構いません。無いときは共通の命中音に、雷や氷の合成音が重なります。

Kenneyのzipの中のファイル名は手元で確認してください。上の名前は候補の目安です。

一覧に行が無く、今は合成音だけで鳴る合図もあります。一覧に同じ名前で行を足せば、素材で鳴らせます。

| 合図の名前 | 鳴る場面 |
| --- | --- |
| `step`、`clang` | 一回目の受付中に騎士が足を踏み替える、盾を打ち鳴らす。録音中でも鳴る |
| `swing`、`slam` | 防御の回で剣を振り下ろす、剣が床を打つ |
| `block` | 防御の回で敵の一撃を受け止める |
| `ring` | 防御の回で狙いの印を囲めた瞬間。時刻ではなく囲めたときに鳴る |
| `finish` | とどめの一撃 |
| `collapse-sword`、`collapse-knee`、`collapse-fall` | 騎士が剣を落とす、膝をつく、倒れる |
| `book` | 魔導書が浮かび始める |

鳴る時刻は `src/audio/cues.ts` が回の表から作っています。

## 素材の入手先と条件

契約や公開の前に、必ず各サイトの規約の原文を確認してください。下の要点は2026年9月時点の調査によるもので、原文を直接開いて確かめたものではありません。

| 入手先 | 条件の要点 | 表記 |
| --- | --- | --- |
| [Kenney](https://kenney.nl/assets?q=audio)（Impact Sounds、Sci-fi Sounds、Interface Sounds） | CC0。商用可、改変可、表記不要 | 不要 |
| [魔王魂](https://maou.audio/) | 個人・商用とも無料。ゲームへの組み込み可 | 「音楽：魔王魂」を結果画面か配布物の説明に入れる |
| [効果音ラボ](https://soundeffect-lab.info/) | 商用可、改変可、表記不要。素材ファイルそのものの再配布は禁止 | 不要 |
| [小森平の使い方](https://taira-komori.jpn.org/) | 商用可、アプリへの組み込み可、表記不要 | 不要 |
| [Springin' Sound Stock](https://www.springin.org/sound-stock/) | 商用可、ゲーム販売も可、原則表記不要 | 不要 |
| [Sonniss GDC Game Audio Bundle](https://gdc.sonniss.com/) | 商用可、表記不要。個々の音の単体再配布は禁止。容量が大きい | 不要 |

このリポジトリを公開する場合、効果音ラボやSonnissの素材はGitに入れないでください（再配布にあたります）。KenneyのCC0素材は入れても構いません。入れるときは、`.gitignore` にある `public/audio/**/*.ogg` などの行を外します。

## 音量の合わせ方

`manifest.json` の `gainDb` で調整します。0が元のまま、-6でおよそ半分、-12でおよそ4分の1です。曲は効果音より下げ、-9前後から始めるとよいです。初期音量25%のまま、会場のスピーカーで聞いて決めてください。曲が大きすぎると、唱えている声の聞き取りに差し支えるおそれがあります。

防御の回の溜めのうなりは、曲の音量の3割まで上がります。曲の素材が無いときは、曲を-9dBとみなして同じ割合で鳴らします。

## 試験

`tests/browser/sample-audio.spec.ts` は、「順番に」の表（URLに何も付けない）で、マイクの聞き取りを試験用の返事に差し替えて、試験用に作った短いWAVを通信の途中で差し込み、一覧の読み込み、無いファイルの記録、曲が本編開始から1秒以内に始まること、`complete` と `impact` が素材で鳴り他は合成音のままであること、中止で曲が止まることを見ます。一回目で鳴る音だけを見るので、防御の回に入ったところで中止します。

## 残っていること

- 曲を場面ごとに厚くする分離トラック（パッド・低音・打楽器・主旋律）は未対応です。今は1本の曲をループします。
- 実際のスピーカーとヘッドセットで、曲と効果音を下げた状態の認識の精度は未確認です。
- 2026年9月20日に作ったときは、開発に使った環境に音の出力先が無く、音量の計測（開始画面の試聴、曲の音量、終了後の無音）は確認できませんでした。手元のPCで `npm run test:browser` を回して確かめてください。
