# 画面全体を使う演出と、敵の圧：実装

2026年9月23日更新。本文の旧来の時刻と同時入力の説明は「同時に」のものです。標準の「順番に」は一回目0〜26秒（声だけ）、防御26〜50秒（手だけ）、とどめ50〜90秒（62秒まで描き、そのあと72秒まで唱える）です。詳しくは[順番に入力する遊び方](順番に入力する遊び方_設計.md)と[動きの詳細](動きの詳細.md)を参照してください。

2026年9月21日。「大型モンスターと戦うゲームとしてエフェクトが足りない」「左右の余白が使えていない。描いた術式が中央に縮められる」という指摘を受けて作った直しです。[大型バトル演出：全面更新の提案](大型バトル演出_全面更新の提案.md)の続きにあたります。

## 何が変わったか

### 術式は描いた場所と大きさのまま

受付が終わったあと（一回目は18秒）、術式を画面の下中央の箱に縮めて収めるのをやめました。描いた形は描いた場所に、描いた大きさのまま残ります。小さく描いたとき（幅が画面幅の28%未満で、高さも18%未満）だけ、どちらかが下限に届くまで広げます（上限2.2倍）。上の体力表示の帯（14%）と下の案内文の帯（12%）と左右の端（2%）にかかるときだけ中へ寄せ、置ける範囲より大きく描いたときだけ収まるぶんだけ縮めます。防御の回も同じ決まりで、盾は描いた線からそのまま作るので、術式と盾が重なります。何も描いていないときは今までどおり下寄りの中央（防御の回は狙いの印の高さ）です。結果画面の縮小図は変えていません。

### 弾は術式の光点から出て、画面の端へ膨らんでから騎士へ寄る

術式には最大12個の光点があり、これを弾の出どころにしました。連弾は光点から均等に選んで1発ずつ別の場所から出ます。放出の破裂、衝撃波の輪、放射状の線、飛び出す粒も出どころごとに（小さめにして）出ます。弾は道のりの6割まで画面の端の方へ膨らみ（出どころが左なら左へ、右なら右へ、上なら上へ。大きさは画面幅の20〜35%）、残りで一気に騎士へ寄ります。到着は必ず騎士の胸の一点です。螺旋、放射、周回、追尾の違いはこの上に載せています。

光線は口の幅を術式の横幅の0.6倍にして、騎士に向かって今までの太さまで絞る台形にしました。収束の言葉が強いほど早く細くなります。壁は描いた線の輪郭そのものを面にし、結界は術式に外接する楕円、波は術式の横幅いっぱいの帯が進みます。二属性を唱えたときは、術式の左半分の光点から主属性、右半分から二つ目の属性が出て、騎士のところで一つになります。

### 蓄積は画面全体から吸い込む

締め切りから発動までの4秒、粒は画面の四辺から生まれて術式の光点と中心へ流れ込みます。術式の下の床全体に属性の色の楕円の明かりが敷かれ、蓄積が進むほど明るくなります（濃さは最大0.35）。地面から昇る光の筋は術式の横幅いっぱいに散り、魔法陣は術式の横幅の半分まで大きくなります（画面の高さの30%が上限）。たくさん描いて唱えた人（入力の量が0.5以上）には、光点ごとの小さな陣も出ます。

### 一撃の手応え

| 項目 | 前 | 今 |
| --- | --- | --- |
| 命中で止める長さ（弱、強） | 0.06秒、0.09秒 | 0.10秒、0.14秒 |
| 単発の命中の止め | 1回 | 3回。命中、命中の0.08秒後（破裂）、0.2秒後（衝撃波が抜ける）。合計の遅れは強で0.21秒 |
| 揺れの基準（派手、最大） | 8画素、18画素 | 14画素、22画素 |
| 命中の寄り | 1.1倍 | 1.18倍 |
| 傾きの最大 | 1度 | 2度 |
| 全画面の白の上限 | 0.7 | 0.85。ふつうの魔法の命中で約0.75 |
| 命中の最初の2コマ | 白 | 画面の色を反転した一枚（アニメの手法）。同じ一回の閃光の一部として数え、明滅の回数は増やさない |

見た目の側も三段に合わせました。単発の攻撃は、命中から0.08秒までは白い芯の小さな破裂だけ、0.08秒で破裂と粒と火花と亀裂、0.2秒で輪と、画面の横幅を超えて抜ける輪が出ます。連弾は今までどおり弾ごとに届きます。

### 命中の跡は回の終わりまで残る

床の跡（焦げ、霜、焼けた筋など）は命中から2秒で消していましたが、その回の受け渡しの1.5秒前まで残るようにしました。とどめの回は今までどおり余韻から2秒です。命中で画面の左右の端の近く（横位置7%と93%）に立つ柱を属性の色で0.25秒照らし、柱の上から石の破片が1.5秒かけて落ちます。破裂の粒の5つに1つは画面の左右の端まで抜けます。とどめの4回の命中は、左、右、上、正面の4方向から騎士へ走り込む光の筋になりました。

### 敵の圧

騎士が自分から動いて画面を揺らす場面を足しました。時刻は `src/game/rounds.ts` の一つの表（`ENEMY_MOVES`、`ENEMY_CHARGE_FROM_MS`、`ENEMY_SLAM_MS`）から取り、画面の揺れ、騎士の動き、音、床の見せ方が同じ時刻を見ます。

| 時刻 | 何が起きるか |
| --- | --- |
| 3.5秒 | 騎士が足を踏み替える。画面が下へ4画素押され、低い足音 |
| 9.5秒 | 剣で盾を打ち鳴らす。画面が横に3画素震え、金属の音 |
| 30.2〜48秒 | 剣を振り上げて溜める。画面が低く震え続け（0.5画素から2画素へ）、じわじわ寄り（1.02倍）、低いうなりが大きくなる。うなりは曲と同じ経路を通るので、録音中は曲と一緒に下がる |
| 48秒 | 振り下ろしの風切り |
| 48.55秒 | 剣が床を打つ。画面が下へ強く押され、傾き1.5度と寄り1.06倍が0.3秒で戻る。足元から赤熱した亀裂が走って回の終わりまで残り、塵が左右の端まで流れる。重い衝撃の音 |

3.5秒と9.5秒の音は、マイクを使う回でも鳴ります。ヘッドセットを使い、声の受付中だけ曲と効果音を8dB下げます。敵の斬撃の三日月は1.4倍にし、近づくほど画面の高さの4分の1まで広がります。閃光はどれも足していません。控えめモードと「動きを減らす」設定では、揺れも反転も出しません。

### 騎士

- **見上げる視点。** 足元は画面の高さの71.4%のまま、視点を高さ0.5m、距離4mに下げて5度ほど上を向かせ、兜の先を画面の上端から2%に置きました（前は真正面で5.2%）。足元と兜の先を両方守るので縦の大きさは1.05倍までで、大きく見えるのは主に低い視点の遠近です。もっと大きくするなら、兜の先を画面の外に出すか足元を下げる判断が要ります。
- **視点そのものが動く。** 命中（23.5秒）で後ろへ0.35m引いて1.5度上を向き0.25秒で戻る、床を打つ一撃（48.55秒）で下へ0.12m沈む、とどめの一撃で後ろへ0.6m引いて2.5度上を向く。控えめモードと「動きを減らす」では動きません。
- **命中の跡が回の終わりまで残る。** 一回目は23.5秒から30秒まで、防御で弾き返したときは51.2秒から56秒まで、胸に属性の跡（炎は焦げ、氷は霜の棘、雷は帯電）が残り、最後の1秒で消えます。とどめの傷あとは今までどおりです。
- **自分から動く。** 3.5秒に盾側の脚を上げて踏み替え、着地で体が沈む。9.5秒に盾を胸の前へ上げて剣で打ち、打った瞬間に盾の面が0.08秒光る。30.2〜48秒の溜めでは、掲げた剣の腕が溜まるほど震える。8つの姿勢の値は変えていません。
- **床を打つ一撃の歪み。** 48.55秒に騎士の足元から衝撃波の歪みが広がります。防御の回の重い後処理は48.45秒から入ります（前は48.9秒）。
- 倒れるときに視点へ近づく距離は、視点が近くなった分だけ縮めました（0.25から0.15）。倒れた騎士は前より大きく画面の中央付近に映るので、実機で見て詰めるかどうかを決めてください。

## 確認したこと

- 単体の試験と型検査、配布用の生成は通っています（件数は[実装と確認の記録](実装と確認の記録.md)）。
- この作業環境（ソフトウェア描画）で、仮の時計で60秒を進めて画面写真を撮り、次を目で確かめました。弾が画面の四隅まで散ってから騎士へ集まること、命中の輪が左右の柱まで届くこと、術式が描いた場所に残ること、防御の回で床に亀裂が走り斬撃が大きくなること、とどめの光線が台形になること。
- 発動の直前の0.08秒の暗転は今までどおり残っています（写真で真っ暗な一枚が出たら、それです）。

## 実機で見てほしいこと（未確認）

- 揺れの大きさ。派手の設定でふつうの魔法の命中は約30画素、最大の設定で8連弾なら約60画素になります。大きすぎれば `presets.ts` の `shake` を下げてください。
- 弾が騎士から離れる向きに200〜400画素ほど動いてから寄る動きが「溜めてから撃つ」ように見えるか。見え方が悪ければ `release.ts` の `SWELL` を小さくしてください。
- 柱を照らす帯の濃さ、破片の量、横幅を超える輪の太さ。
- 溜めのうなりの音量（曲の3割）と床を打つ音の重さ。実際のスピーカーで聞いて調整してください。
- 大きく描いた術式が案内文の枠に重なるとき。重なるなら `spell-layout.ts` の `SPELL_BOUNDS.bottom` を上げれば済みます。
- 命中の反転の一枚と、三段の止めが速い画面で不自然でないか。
- ブラウザーの試験（`npm run test:browser`）は、2026年9月21日にMacで26件すべて通っています。音の並びの期待は足踏みと盾打ちと風切りと床の一撃を含む形に直してあります。
