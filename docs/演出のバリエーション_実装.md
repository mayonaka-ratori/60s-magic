# 演出のバリエーション：実装

2026年9月20日に[調査と検討](演出のバリエーション_調査と検討.md)の案を実装した部分の説明です。派手さと爽快さを優先し、色と派手さを設定として切り出し、段階ごとの部品に分けています。画面全体を使う見せ方（弾が画面の端へ膨らむ、柱が照らされるなど）は[画面全体を使う演出と、敵の圧](画面全体と敵の圧_実装.md)にあります。

## 一回目の締め切りから命中まで

既定の設定は「派手」です。時刻は `src/game/rounds.ts` の表の一回目の行から作ります。

| 場面 | 同時に | 順番に | 見えるもの |
| --- | --- | --- | --- |
| 蓄積と完成 | 18〜22秒 | 14〜18秒 | 画面の四辺から粒が術式の光点と中心へ吸い込まれる。術式の下の床が属性の色で明るくなる。魔法陣が回り、終わりに向けて速くなる。中心が脈打ち、背景が少し暗くなる。地面から細い光が昇る |
| 放出 | 22秒 | 18秒 | 直前の0.08秒の暗転から閃光。術式の光点ごとに衝撃波の輪が時間差で広がり、放射状の線が出る。粒が飛び散る。画面が小さく揺れる |
| 飛翔 | 22〜23.5秒 | 18〜19.5秒 | 本体が光点から出て、画面の端へ膨らんでから騎士へ寄る。光線は術式の横幅から絞る台形。壁は描いた形、結界は外接する楕円、波は横幅いっぱいの帯。拘束は輪が締まる |
| 命中 | 23.5秒 | 19.5秒 | 停止（控えめの設定では止めない。派手と最大は0.10〜0.2秒で、単発の攻撃は止め直しを含む三段）。反転の一枚から閃光。破裂の光、火花、輪、亀裂。画面が大きく揺れ、色が左右にずれる。左右の柱が照らされ、横幅を超える輪が抜ける |
| 余韻 | 23.5〜29.5秒 | 19.5〜25.5秒 | 属性ごとの作用（下記）と、ゆっくり落ちる粒。床の跡は回の終わりまで残る。暗くした背景が戻る |

「順番に」の一回目は声だけの回なので、線の術式の代わりに、言葉ごとに部品が積み重なる「声で育つ術式」が下寄りの中央に出ます。発動でその形が決まった魔法の形になって放たれます（[順番に入力する遊び方](順番に入力する遊び方_設計.md)の6章）。とどめの回でも声の受付の間は同じように育ちます。防御の回は手だけなので出ません。

属性ごとの違いは色だけではありません。

| 属性 | 色（主色、縁、芯、火花） | 形と動き |
| --- | --- | --- |
| 炎 | 橙、暗い赤、淡い黄、黄 | 粒が上へ昇る。命中後も炎が立ち上る |
| 氷 | 水色、紺、白、淡い水色 | 結晶の形。命中で六方向に枝分かれした線、かけらが落ちる |
| 雷 | 黄、紫、白、淡い黄 | 折れ線が毎コマ変わる。命中後0.6秒、枝分かれが点滅する |
| 風 | 薄緑、深緑、白、淡い緑 | 流れる弧。命中で渦を巻く弧が広がる |
| 光 | 淡い黄、橙、白、白 | 円と十字の光条。命中で回る光条 |
| 闇 | 紫、ほぼ黒、淡い紫、紫 | 明るくせず、暗い穴を先に描いてから縁を光らせる |
| 無属性 | 青白、紺、白、淡い青 | 円 |

用途でも変わります。攻撃は破裂、亀裂、揺れ。防御は波紋を重ね、揺れは小さい。拘束は輪と包む格子。強化は昇る粒だけで、揺れも閃光も使いません。

防御の回は盾と敵の一撃の見せ方（`src/render/effects/guard.ts`）、とどめの回は多段命中ととどめの一撃の見せ方（`src/render/effects/finish.ts`）が受け持ちます。とどめの回でも、属性ごとの命中の作用は単発として一度だけ出します。

## 設定（派手さの段階）

`src/render/effects/presets.ts` に3つの設定があります。本編は `?preset=calm|vivid|max` で選べます。指定がなければ `vivid` です。控えめモード（画面のボタンや `?calm=1`）とは別のものです。

| 設定 | 特徴 |
| --- | --- |
| calm（控えめ） | 魔法陣なし、閃光と揺れは小さく、命中で止めない。粒の上限250 |
| vivid（派手、既定） | 魔法陣、閃光、揺れ14画素、輪3本、亀裂6本。粒の上限900 |
| max（最大） | 閃光と暗転が強く、揺れ22画素、輪5本、亀裂10本、色のずれ6画素。粒の上限1500 |

設定の数値は「派手さ0」の基準です。派手さは0〜3の一つの数値で、レシピの個数、範囲、収束、用途から出した値に設定ごとの倍率を掛け、設定ごとの底上げと入力の量を足して決めます（`intensityOf`）。派手（既定）でふつうの魔法は1.9になります。粒の数、輪の本数、揺れの幅はこの数値で増えます。

命中で止める長さは設定の数値ではなく、派手さで決まります（弱0.10秒、強0.14秒、派手さが上限の3のときだけ0.2秒。防御の回はいつも強。`src/render/effects/screen.ts` の `HIT_STOPS`）。控えめの設定だけは止めません。

音も同じ派手さを受け取り、派手なときは放出と命中で低い音と高い金属音を足します。音の時刻は変わりません。

## 見比べ画面

[http://localhost:5173/?view=effects](http://localhost:5173/?view=effects) で、本編を遊ばずに一回目の締め切りの0.5秒前から余韻までを繰り返し見られます。カメラ、マイク、通信は使いません。

時刻は開いたURLの遊び方の表から作ります。何も付けなければ「順番に」の表（締め切り14秒、発動18秒、命中19.5秒）、`?view=effects&flow=together` なら「同時に」の表（締め切り18秒、発動22秒、命中23.5秒）です。

- 左右で設定を変えて見比べる。URLでは `preset=` と `preset2=`。
- 属性、形、用途、軌道、個数、範囲、収束を下の欄で選ぶ。URLでも `element=fire&form=orb&purpose=attack&count=3` のように指定できる。
- 時刻のつまみで止めて見る。先へ飛ばすと途中のコマを速く描いて粒の動きを追いつかせる。つまみを戻したときの描き直しは120コマまでで、それより離れていれば粗く飛ばす。
- 「放出だけ繰り返す」で発動の0.2秒前から繰り返す。「一画面にする」で大きく見る。
- 左下に設定名、生きている粒の数、fpsを表示。
- 閃光、縁の暗さ、ざらつき、暗転は本編と同じHTMLの層で左右それぞれに出す。合成の後処理（光のにじみ、色収差、歪み）はこの画面には無い。
- 「言葉」の欄と「確定前の状態にする」の印で、描いている最中の反応も見られる。URLでは `?words=炎よ&unlocked=1&amount=1` のように指定できる。`amount` は入力の量（0〜1）。

## 描いている最中の反応

魔法の内容が決まる確定（一回目は「同時に」で21秒、「順番に」で17秒）より前から、言葉と動きにその場で演出が応えます。言葉への反応は声を受け付けている間、描く動きへの反応は線を描ける間に出ます。「順番に」では一回目が声だけ、防御の回が手だけなので、それぞれ片方だけが出ます。

- **言葉への即時反応**（`src/game/live-words.ts`、`src/render/effects/words.ts`）。音声の途中結果も含めて言葉を種類分けし、属性の言葉が出た瞬間にその色の粒が手元と線から噴き出します。確定前は、確定と同じ選び方の属性（最初に言った属性語）を「候補の色」として線や中心の光に薄く混ぜます。「炎ではなく氷」のように言い直せば色が変わります。個数の言葉が出ると、その数だけ光点が中心の周りに並びます。形と用途の言葉にも小さな反応があります（壁なら手前に薄い面、守れなら閉じる輪など）。語彙は `src/game/spell-words.ts` の一つの表を、即時反応と確定の両方が読みます。
- **描く動きへの反応**（`src/render/effects/strokes.ts`、`strokes-math.ts`）。筆を置いた瞬間に輪が広がり、速く引くと筆先から火花が飛び、線が始点へ戻って形を囲むと輪郭を光が一周して中心が灯ります。線を引いて戻すだけでは囲んだことになりません。「同時に」では、声が大きいほど節の光が速く脈打ちます。「順番に」では声の大きさを使いません。
- **重ねるほど溜まる**（`src/game/input-amount.ts`）。線の長さ、筆の数、言葉の量から0〜1の「入力の量」を出し、蓄積の粒の数、魔法陣の枚数（1〜3枚）、昇る光の本数、床の明かり、全体の派手さ（最大+0.6）が増えます。派手さを通して、暗さや揺れも強くなります。何もしなければ増えません。
- **二つ目の属性の重ね**（`src/game/recipe.ts`、`release.ts`、`impact.ts`）。「炎よ、雷と共に撃て」のように属性語が2つあると、先に言った方が主属性、二つ目が飾り色になります。連弾は一つおきに二色、単発は尾が二色目、光線は縁が二色目、命中の粒と火花も半々になります。属性ごとの作用（雷の枝分かれなど）と魔法の名前は主属性のままです。

## ファイル

- `src/render/effects/presets.ts`：色の組、設定、派手さの計算。
- `src/render/effects/sprites.ts`：光の粒を一度だけ小さな画像に描いて使い回す。毎コマの放射状グラデーションと `shadowBlur` は使わない。
- `src/render/effects/particles.ts`：粒の置き場。配列を使い回し、上限を超えない。
- `src/render/effects/screen.ts`：揺れ、閃光、暗転、色のずれ、停止を時刻から決める純粋な計算。
- `src/render/effects/frame.ts`：部品が受け取る道具と、共通の描き方。
- `src/render/effects/charge.ts`、`release.ts`、`impact.ts`：蓄積、放出と飛翔、命中と余韻の部品。
- `src/render/effects/words.ts`、`strokes.ts`、`strokes-math.ts`：言葉と描く動きへの即時反応。
- `src/render/effects/voice-growth.ts`：「順番に」の声で育つ術式。
- `src/render/effects/guard.ts`、`finish.ts`：防御の回ととどめの回の部品。
- `src/render/magic.ts`：差配役。時刻を配り、粒を進め、画面全体の効果を重ねる。外から使うのは `renderEffects` と `thumbnail`。
- `src/render/cast-scene.ts`：揺れを背景、騎士、術式の層にも伝える。
- `src/effects-lab.ts`、`src/effects-lab.css`、`src/entry.ts`：見比べ画面。
- `tests/effects.test.ts`：設定、派手さ、画面全体の効果、粒の置き場の試験。

## 確認したこと（2026年9月20日）

作ったときの記録です。そのときは60秒の流れで「同時に」だけでした。試験の件数もそのときのもので、今の件数は[実装と確認の記録](実装と確認の記録.md)にあります。

- そのときの `npm test`（第一段で65件、第二段で108件）と `npm run build` が通りました。
- ブラウザーで、炎の球、雷の7連弾、氷の壁（防御）、闇の光線、光の結界（拘束）、風の波、無属性の強化、氷の螺旋4連を、蓄積、放出、飛翔、命中、余韻の各時刻で撮って確認しました。
- 本編でマウスの線と「炎よ、雷と共に七つに分かれて撃て」を通し、線を描いている間に炎色の粒、詠唱の途中で炎と雷の混色、発動で7つの光点と二色の放出が出て、結果が「7つの炎の連弾」になることを確認しました。
- 開発用の環境は描画が遅く（ソフトウェア描画で20fps前後）、fpsの目安になりません。

## 残っていること

- 実際のPCでのfpsの測定。設定の粒の上限は、会場のPCで測ってから決め直してください。重ければ `?preset=calm` で落とせます。
- 0.5秒以内の短い反応（筆を置いた輪、火花）の実機での見え方と、粒の量や候補の色の濃さの調整。
- 色のずれは、合成の後処理が動いている間は後処理の色収差（色を分けて端ほど強くずらす）で出します。合成を使えないPCや見比べ画面では、自分の絵を左右にずらして重ねる簡易な方法に戻ります。どちらも実機での見え方は未確認です。
- 音の派手さの段階は、実際のスピーカーで音量を聞いて合わせる必要があります。
- 「順番に」の時刻での見比べ画面と本編の見え方は、まだ目で確かめていません。
