# 演出のバリエーション：実装

2026年9月20日。[調査と検討](演出のバリエーション_調査と検討.md)の案を実装しました。派手さと爽快さを優先し、色と派手さを設定として切り出し、段階ごとの部品に分けました。

## 何が変わったか

放出から命中までの一回を、次の流れで見せます。既定の設定は「派手」です。

| 時刻 | 見えるもの |
| --- | --- |
| 14〜17秒 | 周りの粒が渦を巻いて中心へ吸い込まれる。魔法陣が回り、終わりに向けて速くなる。中心が脈打ち、背景が少し暗くなる。地面から細い光が昇る |
| 17秒 | 閃光。衝撃波の輪が時間差で広がり、放射状の線が出る。粒が飛び散る。画面が小さく揺れる |
| 17〜18.5秒 | 本体が尾を引いて飛ぶ。光線は太さが脈打つ帯。壁と結界は面の中を格子が流れる。拘束は輪が締まる |
| 18.5秒 | 一瞬の停止（設定により0〜0.14秒）。閃光。破裂の光、火花、輪、亀裂。画面が大きく揺れ、色が左右にずれる |
| 18.5〜23秒 | 属性ごとの作用（下記）と、ゆっくり落ちる粒。床の跡が薄れ、暗くした背景が戻る |

属性ごとの違いは色だけではありません。

| 属性 | 色（主色、縁、芯、火花） | 形と動き |
| --- | --- | --- |
| 炎 | 橙、暗い赤、淡い黄、黄 | 粒が上へ昇る。命中後も炎が立ち上る |
| 氷 | 水色、紺、白、淡い水色 | 結晶の形。命中で六方向に枝分かれした線、かけらが落ちる |
| 雷 | 黄、紫、白、淡い黄 | 折れ線が毎コマ変わる。命中後0.6秒、枝分かれが点滅する |
| 風 | 薄緑、深緑、白、淡い緑 | 流れる弧。命中で渦を巻く弧が広がる |
| 光 | 淡い黄、橙、白、白 | 円と十字の光条。命中で回る光条 |
| 闇 | 紫、ほぼ黒、淡い紫、紫 | 明るくせず、暗い穴を先に描いてから縁を光らせる |
| 無属性 | 青白、紺、白、淡い青 | 円 |

用途でも変わります。攻撃は破裂、亀裂、揺れ。防御は波紋を重ね、揺れは小さい。拘束は輪と包む格子。強化は昇る粒だけで、揺れも閃光も使いません。

## 設定（派手さの段階）

`src/render/effects/presets.ts` に3つの設定があります。本編は `?preset=calm|vivid|max` で選べます。指定がなければ `vivid` です。

| 設定 | 特徴 |
| --- | --- |
| calm（控えめ） | 魔法陣なし、閃光と揺れは小さく、停止なし。粒の上限250 |
| vivid（派手、既定） | 魔法陣、閃光、揺れ8px、停止0.07秒、輪3本、亀裂6本。粒の上限700 |
| max（最大） | 閃光と暗転が強く、揺れ18px、停止0.14秒、輪5本、亀裂10本、色のずれ6px。粒の上限1100 |

設定の数値は「派手さ0」の基準です。派手さは0〜3の一つの数値で、レシピの個数、範囲、収束と設定の下駄から決めます（`intensityOf`）。粒の数、輪の本数、揺れの幅はこの数値で増えます。音も同じ派手さを受け取り、放出と命中で低い音と高い金属音を足します。音の時刻は変えていません。

## 見比べ画面

[http://localhost:5173/?view=effects](http://localhost:5173/?view=effects) で、本編を遊ばずに放出から命中までを繰り返し見られます。カメラ、マイク、通信は使いません。

- 左右で設定を変えて見比べる。URLでは `preset=` と `preset2=`。
- 属性、形、用途、軌道、個数、範囲、収束を下の欄で選ぶ。URLでも `element=fire&form=orb&purpose=attack&count=3` のように指定できる。
- 時刻のつまみで止めて見る。先へ飛ばすと途中のコマを速く描いて粒の動きを追いつかせる。
- 「放出だけ繰り返す」で16.8秒から繰り返す。「一画面にする」で大きく見る。
- 左下に設定名、生きている粒の数、fpsを表示。
- 閃光、縁の暗さ、ざらつき、暗転は本編と同じHTMLの層で左右それぞれに出す。合成（後処理）だけはこの画面にない。時刻のつまみを戻したときの描き直しは120コマまでで、それより離れていれば粗く飛ばす。

## ファイル

- `src/render/effects/presets.ts`：色の組、設定、派手さの計算。
- `src/render/effects/sprites.ts`：光の粒を一度だけ小さな画像に描いて使い回す。毎コマの放射状グラデーションと `shadowBlur` をやめた。
- `src/render/effects/particles.ts`：粒の置き場。配列を使い回し、上限を超えない。
- `src/render/effects/screen.ts`：揺れ、閃光、暗転、色のずれ、停止を時刻から決める純粋な計算。
- `src/render/effects/frame.ts`：部品が受け取る道具と、共通の描き方。
- `src/render/effects/charge.ts`、`release.ts`、`impact.ts`：蓄積、放出と飛翔、命中と余韻の部品。
- `src/render/magic.ts`：差配役。時刻を配り、粒を進め、画面全体の効果を重ねる。使い方（`renderEffects`、`thumbnail`）は前と同じ。
- `src/render/cast-scene.ts`：揺れを背景、騎士、術式の層にも伝える。
- `src/effects-lab.ts`、`src/effects-lab.css`、`src/entry.ts`：見比べ画面。
- `tests/effects.test.ts`：設定、派手さ、画面全体の効果、粒の置き場の8件。

## 描いている最中の反応（第二段）

魔法が確定する16秒より前から、言葉と動きにその場で演出が応えます。

- **言葉への即時反応**（`src/game/live-words.ts`、`src/render/effects/words.ts`）。音声の途中結果も含めて言葉を種類分けし、属性の言葉が出た瞬間にその色の粒が手元と線から噴き出します。確定前は直近の属性語の色を「候補の色」として線や中心の光に薄く混ぜ、言い直せば色が変わります。個数の言葉が出ると、その数だけ光点が中心の周りに並びます。形と用途の言葉にも小さな反応があります（壁なら手前に薄い面、守れなら閉じる輪など）。
- **描く動きへの反応**（`src/render/effects/strokes.ts`、`strokes-math.ts`）。筆を置いた瞬間に輪が広がり、速く引くと筆先から火花が飛び、線が始点へ戻って閉じると輪郭を光が一周して中心が灯ります。声が大きいほど節の光が速く脈打ちます。
- **重ねるほど溜まる**（`src/game/input-amount.ts`）。線の長さ、筆の数、言葉の量から0〜1の「入力の量」を出し、蓄積の粒の数、魔法陣の枚数（1〜3枚）、昇る光の本数、暗転の深さ、放出の揺れ、全体の派手さ（最大+0.6）が増えます。何もしなければ今までどおりです。
- **二つ目の属性の重ね**（`src/game/recipe.ts`、`release.ts`、`impact.ts`）。「炎よ、雷と共に撃て」のように属性語が2つあると、先に言った方が主属性、二つ目が飾り色になります（以前は無属性に落ちていました）。連弾は一つおきに二色、単発は尾が二色目、光線は縁が二色目、命中の粒と火花も半々になります。属性ごとの作用（雷の枝分かれなど）と魔法の名前は主属性のままです。

見比べ画面には「言葉」の欄と「確定前にする」の印が増え、`?words=炎よ&unlocked=1&amount=1` のようにURLでも指定できます。

確認：単体テスト108件（新規43件）、型検査、ビルド。本編でマウスの線と「炎よ、雷と共に七つに分かれて撃て」を通し、線を描いている間に炎色の粒、13秒で炎と雷の混色、17秒で7つの光点と二色の放出、結果が「7つの炎の連弾」になることを確認しました。この環境は描画が遅いため、0.5秒以内の短い反応（筆を置いた輪、火花）の実機での見え方と、粒の量や候補の色の濃さは会場のPCで調整が必要です。

## 残っていること

- 実際のPCでのfpsの測定。この環境はソフトウェア描画で20fps前後にしかならず、目安になりません。設定の粒の上限は、会場のPCで測ってから決め直してください。重ければ `?preset=calm` で落とせます。
- 色のずれは自分の絵を左右にずらして重ねる簡易な方法です。赤と青に分けてはいません。
- 属性ごとの作用は初回の魔法だけです。防御の回、最後の魔法の多段命中と敵が崩れる動きは未作成。
- 音の派手さの段階は、実際のスピーカーで音量を聞いて調整が必要です。
