# はじまりの魔法：60秒

## 手で描いて、声で唱えると、自分だけの魔法になる

![開始画面。左に説明と「魔法をつくる」のボタン、右に遺跡の騎士](images/解説ページ/01-開始画面.jpg)

このゲームでは、あなたが魔法使いです。
カメラの前で手を動かすと、その動きが光の線になります。
線を描きながら「雷よ、七つに分かれろ」のように声で唱えると、線と言葉から魔法ができあがります。
できた魔法は、目の前の騎士へ飛んでいきます。

時間は60秒。その間に魔法を3回作って放ち、最後に騎士を倒します。
終わると、あなたの3つの魔法が「魔導書」にまとまって表示されます。

## このゲームの目的

目の前にいる「遺跡の騎士」を倒すことです。
ただし、うまく描けなくても、うまく言えなくても、負けることはありません。
魔法は必ず放たれ、騎士の攻撃は必ず防げます。
目的は勝ち負けではなく、「自分の動きと言葉から、自分の魔法が生まれるのを見ること」です。

## 遊ぶ前に

- カメラの前に座ります。片手が動けば大丈夫です。立たなくても、大きく振らなくてもかまいません。
- マイクは口の近くに置きます。声を出しにくいときは、声なしでも遊べます。
- 「魔法をつくる」を押すと、3秒の合図が出ます。この間に、描き始めたい場所へ手を動かしておきます。

![「詠唱の準備を始めよ」の3秒の合図](images/解説ページ/02-合図.jpg)

## 60秒の流れ

60秒は3つの場面に分かれています。

| 場面 | 時間 | やること |
| --- | --- | --- |
| 1回目：最初の魔法 | 0秒から24秒 | 自由に描いて、唱えて、放つ |
| 2回目：防御 | 24秒から40秒 | 赤い印を囲んで盾を作り、騎士の一撃を止める |
| 3回目：とどめ | 40秒から60秒 | 前の光を集めて、全力で唱えて、騎士を倒す |

### 1回目：最初の魔法（0秒から24秒）

**描く。** 手を動かすと、すぐに白い光の線がついてきます。止まっても、また描き足せます。

![描いている途中。手の動きに白い線がついてくる](images/解説ページ/03-描く.jpg)

**言葉を添える。** 11秒ごろに「描きながら、言葉を添えて」と出ます。描きながら、好きな言葉を唱えます。「雷」と言えば線が黄色くなり、「氷」と言えば水色になります。言葉は14秒まで受け付けます。

![「描きながら、言葉を添えて」の案内](images/解説ページ/04-言葉を添える.jpg)

**完成する。** 14秒になると受付が終わり、線に光が巡って、中心に集まります。「雷・7つ」のように、聞き取った言葉が小さく表示されます。ここからは手を止めて見ているだけで大丈夫です。

![「あなたの魔法が、完成する」。黄色く光る線の中心に光が集まる](images/解説ページ/05-完成.jpg)

**放つ。** 17秒に魔法が飛び出し、騎士に当たります。魔法の名前が画面の下に出ます。この例では「7つの雷の連弾」です。

![「7つの雷の連弾」が騎士に当たったところ](images/解説ページ/06-一回目の命中.jpg)

### 2回目：防御（24秒から40秒）

**赤い印を囲む。** 24秒になると、騎士が剣を構え、画面の中ほどに赤い印が出ます。ここに騎士の一撃が来ます。印のまわりをぐるっと囲むように描きます。

![「赤い印を囲って、守る形を描け」。騎士の足元に赤い輪](images/解説ページ/07-赤い印.jpg)

**囲めると色が変わる。** 囲めた瞬間に、印が赤から魔法の色に変わります。囲んだ形が、そのまま盾になります。
囲めなくても大丈夫です。一番近い線が、自動で印の前へ動いて盾になります。何も描かなくても、小さな光の玉が守ってくれます。

![印を囲めたところ。赤い印が白い輪に囲まれ、色が変わっている](images/解説ページ/08-囲めた.jpg)

**言葉で止め方が変わる。** 描きながら「氷よ、壁となれ、弾き返せ」のように唱えます。「弾き返せ」と言えば騎士の一撃をはね返し、「かき消せ」と言えば消し、何も言わなければ受け止めます。

**騎士の一撃を止める。** 35秒ごろ、騎士が剣を振り下ろします。あなたの盾がそれを止めます。

![「氷の壁」が騎士の斬撃を弾き返したところ](images/解説ページ/09-盾で止める.jpg)

**弱点が出る。** 一撃を止められた騎士は、よろけて胸当てが外れ、胸の光る核が見えます。これが弱点です。

![騎士が前かがみになり、胸の核が白く光っている](images/解説ページ/10-弱点.jpg)

### 3回目：とどめ（40秒から60秒）

**光が集まる。** 40秒になると、1回目と2回目の光の点が、左右の端から真ん中に集まってきます。そこへ新しい線を描き足します。

**全力で唱える。** 44秒から約5秒、「全力で詠唱せよ」と出ます。ここが一番長く唱えられる場面です。

![「全力で詠唱せよ」。白い光の線が騎士の胸を囲む](images/解説ページ/11-全力で詠唱.jpg)

**ためて、放つ。** 49秒で受付が終わると、光が中心に吸い込まれ、画面が暗くなります。一瞬すべてが止まり、52秒に魔法が飛び出します。

![放つ直前。黄色い輪が何重にも重なり、中心が光る](images/解説ページ/12-放つ直前.jpg)

**とどめの一撃。** 魔法は騎士の肩、盾、兜、胸当てに次々と当たり、最後に胸の核へ大きな一撃が入ります。

![核への一撃。画面全体が白く光る](images/解説ページ/13-とどめ.jpg)

**騎士が倒れる。** 核が砕け、騎士は剣を落とし、膝をつき、手前へ倒れてきます。あなたの魔法の名前が画面に浮かびます。

![騎士が手前へ倒れ、「炎の光線」の名前が出ている](images/解説ページ/14-倒れる.jpg)

### 結果：魔導書

60秒になると、魔導書が開きます。
左に最後の魔法の形、右に魔法の名前と「炎」「攻撃」「光線」のような札、唱えた言葉、確認番号が並びます。
下には3つの魔法が絵つきで並びます。

![魔導書。「炎の光線」と3つの魔法](images/解説ページ/15-魔導書.jpg)

## 楽しいところ

- **動かした瞬間に光る。** 手を動かすと、遅れずに光の線がついてきます。
- **描いた形がそのまま残る。** きれいな円に直されたりしません。あなたが描いた形のまま、光の点と線が足されて魔法になります。
- **言った言葉が色と形になる。** 「雷」と言えば黄色い稲妻に、「氷」と言えば水色の結晶になります。
- **自分の盾で攻撃を止める。** 2回目に囲んだ形が、そのまま盾になって騎士の一撃を受けます。
- **3回分の光が最後に集まる。** とどめの回では、前の2回の光が戻ってきて、最後の大きな魔法になります。
- **魔法に名前がつく。** 「7つの雷の連弾」「氷の壁」のように、言葉と形から名前が決まります。

## もっと面白くする工夫

失敗はありませんが、工夫すると魔法がはっきり変わります。

### 言葉の工夫

| 言うこと | 変わるもの | 例 |
| --- | --- | --- |
| 属性の言葉 | 色と見た目 | 炎、氷、雷、風、光、闇 |
| 形の言葉 | 魔法の形 | 壁、結界、波、光線、球、連弾 |
| 数 | 弾の数（8つまで） | 「七つに分かれろ」「三本」 |
| 動きの言葉 | 飛び方 | 「追え」で追いかける、「螺旋」で回りながら飛ぶ |
| 使い方の言葉 | 攻める、守る、縛る、強める | 「貫け」「守れ」「縛れ」「我に力を」 |

- 属性を2つ言うと、先に言った方が主な色、後に言った方が飾りの色になります。「炎と氷」なら赤に水色が混じります。
- 「雷ではなく氷」のように言い直すと、後の方が使われます。
- かっこいい言葉も通じます。「紅蓮」は炎、「雷霆」は雷、「氷晶」は氷、「常闇」は闇です。開始画面の「詠唱の言葉を見る」に110の言葉があります。
- 魔法の名前は「数＋属性＋形」でできます。「七つ」「雷」「分かれろ」と言えば「7つの雷の連弾」になります。

### 描き方の工夫

- **1回目。** 閉じた形（円や輪）を描くと「球」に、横に長い線を描くと「波」に、それ以外は「光線」になります。大きく描くほど、当たったときの光も大きくなります。
- **2回目。** 印を囲んだ回数だけ、盾が重なります（5枚まで）。「三枚」のように数を言っても同じです。横に長く囲めば壁、縦に長く囲めば柱、小さく囲めば玉の形の盾になります。
- **3回目。** 前の2回の光が集まってくる場所に、線を描き足します。「言葉を重ねるほど、最後の魔法が大きくなります」と画面にも出ます。

### 声の工夫

- マイクに近づいて、はっきり、ふつうの速さで話します。大きな声は要りません。
- 「雷よ、七つに分かれろ」のように、短く区切ると聞き取りやすくなります。
- 言葉は途中で言い直せます。最後に言ったことが使われます。

## よくある質問

**声を出すのが恥ずかしい。** 声なしでも遊べます。線だけで魔法ができます。「マイクで唱える」を選ばなければ、文字で言葉を入れる欄が出ます。

**手がうまく映らない。** 「マウスで試す」を選べば、マウスを押したまま動かして描けます。

**赤い印を囲めなかった。** 一番近い線が自動で印の前へ動いて、必ず守ってくれます。

**途中で手を止めてしまった。** 受付が終わる時間までは、いつでも描き足せます。止まっても魔法は消えません。

**光が強いのが苦手。** 画面の右上の「演出を控えめにする」で、光や揺れを弱くできます。

## 安心してほしいこと

カメラの映像と声は、このパソコンの外へ送りません。録画も録音もしません。
残るのは、描いた線の形と、聞き取った言葉の文字だけです。

## 作った人向けの覚え書き

### このページをどこに置くか

| 置き場所 | 使い方 | 載せる量 |
| --- | --- | --- |
| QRの先の公開ページ | 遊んだ後に、自分の魔導書と一緒に読む | 本文をそのまま |
| 会場の入口の案内 | 並んでいる間に読む | 「60秒の流れ」の表と「もっと面白くする工夫」の言葉の表だけ |
| 配るプリント | 持ち帰って家で読む | 本文から画像を5枚ほどに減らす |

公開ページは設計仕様の「第五段階」で、まだ作っていません（[文書の一覧](README.md)の「段階ごとの進み具合」を参照）。ページを作るときは、この文章をそのまま元にできます。

### 本文で気をつけたこと

- 一文を短くし、秒数は場面の区切りだけに絞った。細かい秒数（14秒で受付終了、16秒で確定など）は本文に入れていない。仕様の時刻を変えないため、書くときは[動きの詳細](動きの詳細.md)の表をそのまま使う。
- 「負けない」「必ず守れる」ことを先に伝えた。中学生は失敗を怖がりやすいため。
- 「工夫」は、コードで実際に変わることだけを書いた。属性と形の言葉は `src/game/spell-words.ts`、数と飛び方は `src/game/recipe.ts`、盾の決め方は `src/game/guard.ts` に合わせてある。
- 「言葉を重ねるほど、最後の魔法が大きくなります」は、ゲームの画面に出ている案内文をそのまま引いた。言葉の数で演出がどれだけ変わるかは、実機で確かめていない。

### 差し替えたい画像

今の15枚は、マウスと文字入力で動かした画面を、仮の時計で撮ったものです。マイクで遊ぶときに出ない文字入力の欄は、写らないようにして撮っています。会場で使う前に、人の手で描いた画面に差し替えるのがよいと思います。人の手で描いた線の方が、遊ぶ人の想像に近いためです。カメラの前で遊んでいる様子の写真（手と画面が一緒に写ったもの）も1枚あると分かりやすくなります。

撮り直すときは、Macで `npm run dev` を起動してから `node scripts/capture-60s.mjs` を走らせると、同じ場面の写真が `test-results/capture/` に出ます。マイクで遊んだ画面は、実際に遊びながら画面撮影で残します。

### まだ確認していないこと

- 中学生に読んでもらって、分からない言葉がないか。
- 人の手と声で遊んだときに、本文どおりに見えるか（人による確認は未実施。[実装と確認の記録](実装と確認の記録.md)）。
- 「もっと面白くする工夫」を読んだ人が、実際に魔法を変えられるか。
