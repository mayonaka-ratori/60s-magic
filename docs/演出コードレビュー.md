## 問題なしと確認できたこと

- 画面全体の効果（`screen.ts`）は時刻だけで決まる純粋な計算で、控えめモードで残る効果はなく、停止は二重にかからない。

- 音の時刻は最初から一文字も変わっていない。音量は圧縮器を通るので派手さ最大でも歪まない。
- `speech-book.ts` の `live()` は `snapshot()` と `freeze()` に触れていない。

- 合成に切り替わる瞬間に1〜2コマ真っ暗にならないか。術式の加算とscreenの見た目の差。
