# 画面の整理案（重なり・余分な文字・余分なUI）

2026年9月20日。遊ぶ人の目から見て、読めない文字、要らない文字、要らないボタンを洗い出し、直した記録です。
1920×1080、1440×900、1280×800、1024×768、390×844の5つの大きさで、開始前から結果、説明の小窓まで画面を撮って位置を測りました。

## 今どうなっているか（2026年9月23日）

この文書の案は、見送った2つを除いて作り終えています。見送った1つ（音の設定をたたむ）も、そのあと[大型タイトルのUIの改善案](大型タイトルのUIを調べた結果と改善案.md)のFで作りました。
調べたのは60秒の作り（一回目が24秒）だったころの画面で、そのあと体力の表示を右端の縦の帯へ移し、結果画面を魔導書に作り替えています。開始画面には「遊び方を選ぶ」（順番に、同時に）が加わりました。
下に残したのは、何を見つけて、どう決めたかの要点だけです。細かい位置の実測値と、当時の行番号つきの場所は削りました。

重なりの見張りは`tests/browser/screen-text.spec.ts`にあります。開始前の画面をいくつかの大きさで、プレイ中から結果までを横長と縦長で見て、親子でない文字どうしが重なっていないか、確認用の表示がふだんの画面に出ていないかを確かめます。この試験は「同時に」の画面で見ています。「順番に」の合図と受付は`tests/browser/sequential.spec.ts`で見ています。試験がどこまで通ったかは[実装と確認の記録](実装と確認の記録.md)にあります。

## 見つけたことと、どうしたか

| 見つけたこと | どうしたか |
| --- | --- |
| 右上の残り時間に「中止する」がかぶり、残り秒が読めない（全部の大きさで起きていた） | 右上を、上から残り時間、中止する、音を消すの順に並べ直した。縦長の画面では「音を消す」と「中止する」を横に並べる。そのあと「音を消す」の隣に「演出を控えめにする」が加わった |
| 表示領域の高さが低いと、開始画面の見出しとキャッチコピー、説明文とフッターが重なる（普通のノートPCではほぼ必ず起きていた） | 高さが足りないときは真ん中揃えをやめ、ヘッダーの下から順に並べる。フッターは無くした |
| 「見本の再生」の札が敵の名前にかぶる | 札を左上へ移した |
| 作った人のための文字（試作の札、接続の確認、見た目の確認へのリンク、記録の書き出し、感想の聞き取り、Jevの説明など）が遊ぶ人の画面に出ている | `?dev=1`のときだけ出す「確認用の表示」にまとめた。ふだんの結果画面のボタンは「もう一度つくる」と「最初へ戻る」だけ |
| 文字入力の案内が二か所にあり、受付が終わっても残る | 右の入力欄の見出しに一本化し、締め切りで閉じる。マイクを使う回だけ「声を受け付けています」を出す。文字入力の欄が出るのは、マイクを使わない「同時に」だけ |
| 通信の知らせが遊び方の案内を上書きする | 専用の場所（中止するの下）に出す |
| 下の案内が4段で、同じことを繰り返している | 見出しとひとことの2段にした |
| 10px以下の文字が多い | 11〜13pxへ上げた。そのあと[UIの改善案](大型タイトルのUIを調べた結果と改善案.md)のAでさらに大きくした |
| 経過秒の表示（「03 / 24秒」） | 「のこり◯秒」にした |
| 説明の小窓の「閉じる」が画面の外へ出る | 見出しと「閉じる」を上に固定し、外側を押しても閉じる |

言葉も、遊ぶ人に向けて直しました。たとえば、マイクが使えないときは「マイクで唱える（いまは使えません）」、手の認識の準備ができていないときは「いまは手で描けません。「マウスで試す」で遊べます。」、準備中は「準備しています…」です。進み具合の三段は「線を描く」「形になる」「放つ」にしました（回と遊び方によって言葉が変わります。今の言葉は[UIの改善案](大型タイトルのUIを調べた結果と改善案.md)の「今どうなっているか」にあります）。

## 見送ったこと

- 詠唱の言葉の一覧は、量を減らさずに残した。読み方を調べる使い方があり、試験も中の語を見ているため。末尾の注意書きだけ1行に縮めた。
- 効果音の音量と「音を試す」をたたむ案は、このときは見送った。そのあとUIの改善案で「音と演出の設定」にたたんだ。
