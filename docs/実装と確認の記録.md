# 第一段階の実装と確認

確認日：2026年9月20日。対象は最初の24秒だけです。

## 実施した確認

| 確認 | 結果 |
| --- | --- |
| 入力時刻、元の線の保持、魔法の決定、Jevへの要求、音の取り込み | 26項目すべて通過 |
| 実際のブラウザーで24秒を通して遊ぶ | 通過。途中の描き足し、11秒以降の最後の線、七つの雷、感想の記録を確認 |
| Jevの返事が3秒遅れる場合 | 通過。返事を使わず氷の壁で予定どおり発動 |
| カメラの認識処理を別の場所で起動し、中止する | 通過。ブラウザーが生成した映像を使用 |
| 見本の再生の明示と中止 | 通過 |
| Jevの期限内の回答 | 試験用の回答で通過。曖昧な言葉が氷の壁になり、17秒より前には発動しない |
| 配布用の画面の生成 | 通過。上のブラウザー5項目はこの画面でも確認 |
| 日本語表示 | 1440×900の開始・描画・完成・発動・終了画面を画像で確認。見出しの不自然な折り返しを修正 |
| 依存するソフトの既知の問題の検査 | `npm audit` で報告0件 |

ブラウザーはChrome for Testing、描画はこのPCのDirect3D 11で確認しました。最初の自動確認で使ったソフトウェア描画では操作の送信が遅かったため、実機の画像処理を使う設定へ変更しています。実機の手の追跡が目標性能を満たしたという意味ではありません。

## まだ確認していないこと

- Jevとの実通信。接続情報が未設定です。要求の形式、回答の読み取り、期限、回答の採用は試験用の返事で確認しました。
- Google Cloudとの実通信。接続情報が未設定です。マイクの44.1kHz・48kHzから16kHzへの変換、短い無音の扱い、14秒での録音終了は生成した音で確認しました。
- 実際の人の手の認識精度と、動いてから線が出るまでの遅れ。
- 実際の人の詠唱と描画を同時に受け付けたときの認識精度、待ち時間、表示速度。
- 初見の5人による「自分の魔法を放った」という実感の確認。

次に人へ試してもらうときは [最初の24秒の確認手順](最初の24秒_確認手順.md) を使います。外部サービスの接続前でも、マウスと文字で線・完成・発動の見え方を確認できます。
