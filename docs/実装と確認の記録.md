## 90秒へ作り直した（2026年9月21日）

三回目（とどめ）が一番大事な場面なのに、描いて唱えられる時間が9秒しかなく急ぎ足でした。全体を60秒から90秒へ広げ、一回目30秒・防御26秒・とどめ34秒にしました。

| | 前（60秒） | 後（90秒） |

| 一回目 | 0〜24秒（描いて唱えるのは14秒） | 0〜30秒（18秒） |
| 防御 | 24〜40秒（7秒） | 30〜56秒（15秒） |
| とどめ | 40〜60秒（9秒） | 56〜90秒（16秒） |

| とどめの後 | 一撃から5.5秒で魔導書 | 一撃から11.5秒。崩れ落ちをゆっくりにし、余韻も伸ばした |

- とどめの後は、剣を落とす・膝をつく・倒れるをゆっくりにし、自分の術式が残る時間を2.25秒から4.4秒へ伸ばしました。

## とどめの回と魔導書（2026年9月20日に追加）

魔導書は、左に最後の術式、右に魔法名（ふりがな付き）、属性と用途の札、詠唱の一文、持ち帰りの場所、確認番号、保存の状態の一行、下に三つの魔法を絵つきで並べる形にしました。縦長の画面では上から順に積みます。並べる三件は保存する記録から作るので、画面に出るものと保存したものが必ず同じになります。

持ち帰りは下ごしらえだけです。公開ページがまだ無いので、QRの場所には「持ち帰りの準備中」と出し、嘘のQRは出しません。保存の状態の一行は「この画面でだけ見られます」です。届いていないものを「登録しました」とは書きません。遊んだ記録（確認番号、三件のレシピ、術式の点列、詠唱の文字、引き継いだ形）は、魔法が確定するたびにこのPCのブラウザーの中へ残します。カメラの映像と声そのものは残しません。保存先を使えない環境では、保存できなかったことを覚えておくだけで、画面は止まりません。

確認番号は6桁の数字です。遊んだ人が持ち帰るものではなく、係員がどの回の記録かを探すための番号です。保存済みの番号と重ならないよう作り直します。

とどめの見せ方（視界を通る術式、輪、多段、直撃、スロー）、騎士の崩れ落ち、体力を0にする段、とどめの音は別途作っています。

**実機で最初に見てほしいところ。**

1. 魔法名が大きすぎず小さすぎないか。ふりがなが読めるか。
2. 下の三件の絵で、一回目・防御・とどめの違いが分かるか。
3. 確認番号が、離れた場所から読めるか。
4. 90秒の魔導書が出るまでに、画面のエラーが出ないか。

## 2026年9月20日に足した演出（大型バトル演出の全面更新）

- 描いている最中に言葉と動きへ反応する。属性の言葉でその色の粒、確定前は候補の色、個数の言葉で光点。筆を置いた輪、速い線の火花、閉じた線の一周、声の脈動。線と言葉の量で蓄積が濃くなる。二つ目の属性語は飾り色になる。
