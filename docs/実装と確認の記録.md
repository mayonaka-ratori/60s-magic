### 二つの遊び方の選び方と「順番に」の合図

- 作ってあるもの：開始画面で選ぶと、URLを変えて読み込み直します。指定が無ければ「順番に」です。マイクを使わない設定にすると「同時に」へ読み込み直し、「順番に」は選べなくなります。声が使えないと分かって自動でマイクを外したときは、使えるようになったら戻します（人が自分で外したときは戻しません）。一度でも状態を確かめられた後は、確認が一度失敗しただけでは外しません。「順番に」では、各回の始まりと、とどめの描く締め切りに大きな文を出します。「同時に」は今までの幕の表示のままです。
- Macで確かめたこと：ブラウザーの試験で、切り替えると読み込み直すこと、マイクを外すと「同時に」へ戻ることが通りました（9月23日）。マイクの自動の外しと戻しは、そのあとの直しなのでMacでは未実行です。
- 試験とWindowsで確かめたこと：単体の試験で、文の出る時刻と消える時刻、文が出ている間も受付が続くこと。Windowsのブラウザーの試験で、遊び方の切り替え（9月23日）。
- まだ確かめていないこと：文を読めるか、手を動かしながら見て分かるか。開始画面の収まり。マイクを外したときの画面の分かりやすさ。

### 一回目の魔法

- 作ってあるもの
  - 順番に：声だけの回です。手の光点は見せますが、線は受け付けません。下寄りの円が時間とともに育ち、聞き取った言葉ごとに部品を足します（壁、球、波、鎖の形。螺旋、追尾、分裂、個数の動き。攻める、守るの指示で線の太さと速さ。呼び掛けと飾りの言葉で光）。同じ言葉は重ねず、言い直した部品は薄くし、締め切りの後は増やしません。部品は最大32個です。確定で中心へ集まり、発動で決まった魔法の色と形で放ちます。控えめ表示では回転を止めます。聞き取った属性の色を三つまで円の縁の光点として次の回へ渡し、無言なら淡い青を一つ渡します。
  - 同時に：線を描いて唱え、締め切り、確定、発動、命中と進みます。流れは[動きの詳細](動きの詳細.md)の「一回目の進行（同時に）」にあります。
- Macで確かめたこと
  - 同時に：24秒だったころ、マウスと合成音声で通して17.0秒に発動しました。60秒だったころもマウスと合成音声で通しました（2026年9月21日）。90秒版は、ブラウザーの試験で七つの雷が記録されるところまで通りました（9月22日）。
  - 順番に：ブラウザーの試験の通しで、一回目に線が残らず、声だけで進むことが通りました（9月23日。認識の返事は試験用）。
- 試験で確かめたこと（順番に）：無言でも円が育つこと、音量で円の描き方が変わらないこと、同じ部品を重ねないこと、締め切りの後に部品を足さないこと、線なしの結果、色の引き継ぎ。
- まだ確かめていないこと
  - 順番に：人の声で部品が言った順に出るか。円と放つ魔法の見え方。声だけの受付が長すぎないか。
  - 同時に：90秒版を人が遊ぶこと。描きながら唱える受付が長すぎないか。

### 記録の保存

- 作ってあるもの：魔法が確定するたびに、確認番号、三件のレシピ、術式の点列、詠唱の文字、引き継いだ形、遊び方（`flow`。値は`sequential`か`together`）を、このPCのブラウザーの中へ保存します。遊び方の名前が無い古い記録は、一回目の円の記録があれば「順番に」、無ければ「同時に」として読み戻します。最新200件まで残し、古いものは遊び始めに消します。保存できないときは、そのことを結果画面に出し、画面は止めません。カメラの映像と声そのものは残しません。サーバー側の確認用の記録（`speechSessions`）には、聞き取った言葉を残さず文字数だけを残します。画面側で保存するJSONの記録には、聞き取った文字が入ります（見方は[確認用の記録の見方](確認用の記録の見方.md)）。

### 音声認識

- 作ってあるもの：このPCの中で聞き取ります。MacはGPUで`kotoba-v2.0-mlx`、Windowsは`kotoba-v2.0`です。声を受け付ける回と長さは遊び方の表から作ります（「順番に」は一回目と、とどめの唱える時間だけ。防御ではつながない）。受付の締め切りちょうどまで録り、締め切りの後は最後の声を2秒待ちます。Python側の音の上限はゲーム側から渡し、単独で動かすときは両方の遊び方でいちばん長い受付の分を受け付けます。MacのGPUでは認識の手掛かりの語を渡しません。「かみなり」の聞き違い（カメナリ、亀なり、かめなり、カメラリなど）は雷として受け付けます。遊んでいる途中で声の接続が切れたら文字入力に切り替えます。一回の認識が時間内に終わらなくても止めず、続けて3回のときだけ止めます。中身は[動きの詳細](動きの詳細.md)の「このPCでの音声認識」と[詠唱の言葉と読み方](詠唱辞書と認識の確認.md)にあります。

  - `npm run test:chants`：9月20日に最後まで動きました。合成音声14件の結果と、手掛かりを渡すと悪くなった比べ方は[詠唱の言葉と読み方](詠唱辞書と認識の確認.md)の「ローカル音声認識で分かったこと」にあります。難しい言葉（雷霆、氷晶、霹靂、紅蓮）は聞き取れていません。

  - 「同時に」のブラウザーの試験で、PC内の認識が最後の声を取り込んで発動しました（9月22日。9月23日も同じ手順で全部通った）。この試験の前に`node scripts/prepare-browser-audio.mjs`で試験用の音を作り直します。
