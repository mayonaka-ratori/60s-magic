# noteへの入れ方

このフォルダーには、noteの記事にそのまま使える本文と画像が入っています。

| ファイル | 中身 |
| --- | --- |
| `本文.md` | 記事の本文。見出し、画像を入れる場所、キャプションの指示つき |
| `画像/01-開始画面.jpg` から `15-魔導書.jpg` | 本文に入れる画面写真15枚。横1280ピクセル |
| `画像/見出し画像_案A_とどめ.jpg` ほか3枚 | 記事の一番上に出る見出し画像の候補。横1280、縦670ピクセル |

## 手順

1. noteで「新しく記事を書く」を開き、タイトルに「はじまりの魔法：60秒」と入れます。副題の「手で描いて、声で唱えると、自分だけの魔法になる」は本文の一行目にしても、タイトルに続けてもかまいません。
2. 見出し画像に、`画像/見出し画像_案A_とどめ.jpg` を入れます。開始画面の雰囲気を出したければ案B、光の線を見せたければ案Cにします。
3. `本文.md` を開き、「---」より下を上から順に貼ります。
4. 「■」で始まる行は、その行を選んで「大見出し」にし、「■」を消します。「▼」で始まる行は「小見出し」にし、「▼」を消します。
5. 「【画像：ファイル名】」の行は、その行を消して「画像」を挿入し、`画像/` フォルダーの同じ名前のファイルを選びます。すぐ下のかっこ内の文をキャプションに入れて、かっこの行は消します。
6. 「**」で囲んだ言葉は、太字にして「**」を消します。noteの編集画面では、言葉を選んで太字のボタンを押します。
7. 「・」で始まる行は、noteの箇条書きにしてもよいですし、「・」のままでもかまいません。
8. 一番下のかっこの文（画面写真の断り書き）は、そのまま残すか、消してもかまいません。

## 画像について

- 15枚は、横1280ピクセルに縮めてあります。noteの本文の幅に合う大きさです。
- 見出し画像はnoteの推奨（横1280、縦670）に切り出してあります。
- 写真は、作っている途中の試作をマウスと文字入力で動かして撮ったものです。マイクで遊ぶときに出ない文字入力の欄は、写らないようにしてあります。右上の「中止する」「音を消す」などのボタンは実際の画面と同じです。
- 人の手で遊んでいる写真や、手と画面が一緒に写った写真は、まだありません。撮れたら、03-描く.jpg のあたりに1枚足すと分かりやすくなります。

## 直すときは

本文を直したいときは `本文.md` を直し、[遊び方の解説ページ：案](../遊び方の解説ページ_案.md) の本文も同じように直します。二つの文章は同じ内容です。
