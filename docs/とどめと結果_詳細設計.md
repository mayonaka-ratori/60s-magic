## 0. この回でやりたいこと

**「自分が作った一番大きい魔法で、目の前の騎士を倒した」を、主観視点のまま見せきる。** 三回目なので、同じ手を大きくしただけでは弱く見えます。とどめだけに使う段取りを別に用意します。難しさは作らず、入力がどうであれ必ず倒れます。

作る範囲は次の四つです。

1. とどめの回（40〜60秒）の進行と演出
2. 騎士が崩れ落ちる動きと、体力が必ず0になること
3. 結果画面（魔導書）の見た目と、三つの魔法の並べ方
4. 持ち帰りの下ごしらえ（このPCの中への保存と確認番号まで。公開ページと本物のQRは、ほかが全部できた後）

## 2. 世界の時計に「遅くする」を足す

今の世界の時計は「命中で止める」だけを持っています。とどめでは、止めるのが2回あり、さらにスローモーションが入ります。時計の計算をひとつにまとめ直します。

### 二つの時計

この回からは、時計が二つあることをはっきり分けて書きます。

- **実際の時刻**：開始からの本当の経過。画面の残り時間、魔導書を出す60.0秒、録音の締め切りはこちら。
- **世界の時刻**：止めとスローを入れたあとの時刻。騎士、術式、魔法、粒、体力はこちらで動きます。

止めもスローも**世界の時刻で置きます**。長さは実際の秒数で指定します。こうすると、描く側（世界の時刻）と、置いた時刻がぴたりと合います。

### 形

```
ゆがみ = {
  stops: [{ at: 世界の時刻, hold: 実際に止める秒数 }, ...],   // 時刻の順に並べる
  slow:  { from: 世界の時刻, seconds: 実際の長さ, rate: 速さの倍率 } | null
}

世界の時刻(t) を出す手順：
  遅れ = 0
  出来事を順に見る：
    その出来事が始まる実際の時刻 = at + 遅れ
    t がそこへ届いていなければ、そこで終わり
    止めなら   遅れ += min(hold, t - 始まる実際の時刻)
    スローなら 遅れ += (1 - rate) × min(seconds, t - 始まる実際の時刻)
  返す値 = t - 遅れ
```

- 止めている間は、遅れが t と同じ速さで増えるので、世界の時刻はぴたりと止まります。
- スローの間は、世界の時刻が rate 倍の速さで進みます。
- 時刻だけで決まる計算なので、今までどおり試験できます。時計が戻ることはありません。
- **ゆがみの中身は、本人の魔法（弾の数や属性）で変えません。** 止める時刻と長さは回の表から決めます。こうすると遅れの合計がいつも同じになり、余韻の長さも試験で固定できます。

### 今までと同じになること

一回目と防御は `stops` が一つ（命中の時刻に、今と同じ長さ）、`slow` は `null` です。式に入れると今の `effectTime` とまったく同じ値になります。**ここは総当たりの試験で確かめてから進めます。**

### とどめのゆがみと、二つの時計のずれ

止めるのは、一発目の命中と、とどめの一撃の2回だけです。仕様の1.7にある「命中時に約0.1秒止める」を一発目で守り、とどめの一撃だけ0.25秒まで伸ばします。間の小さい命中では止めません（揺れと光だけ）。

| 世界の時刻 | 何を | 長さ（実際） | 実際の時刻 | ここまでの遅れ |
| --- | --- | --- | --- | --- |
| 53.60 | 一発目の命中で止める | 0.10秒 | 53.60〜53.70 | 0.10秒 |
| 54.50 | とどめの一撃で止める | 0.25秒 | 54.60〜54.85 | 0.35秒 |
| 54.80 | 0.25倍のスロー | 0.50秒 | 55.15〜55.65 | 0.725秒 |

合計の遅れは0.725秒です。つまり**実際の60.0秒のとき、世界の時刻は59.275秒**です。この0.725秒を使い切らないよう、崩れ落ちと余韻は世界の時刻で59.25秒までに終わらせます。

止める回数を増やすほど遅れが増え、余韻が削られます。**止めるのは3回まで、遅れの合計は0.8秒まで**と決めておきます。試験でこれを超えたら止めます。

最初の案では、間の小さい命中でも0.06秒ずつ止めていました。仕様の「約0.1秒」より短く、しかも止める回数が入力で変わるのでやめました。

## 4. とどめだけの見せ方（作る部品）

新しく `src/render/effects/finish.ts` を作り、次の五つを入れます。ほかの回からは呼びません。

### 4.1 術式が視界を通り抜ける（52.00〜52.25秒）

完成した術式の形（本人が描いた線）を、中心から外へ一気に広げます。広がりきる手前で線が薄くなり、画面の外へ抜けます。

- 拡大は1倍から8倍へ、0.25秒。最初の0.1秒で6倍まで行き、残りでゆっくり抜ける（速く始めて遅く終わる）。
- 濃さは最初の0.06秒で1.0、そこから0へ。
- 同時に全画面の白が0.85まで上がり、0.17秒で戻る（既にある閃光の層を使う）。
- 線の色は属性の色、芯は白。今の術式の描き方をそのまま拡大して使います。

**これがカットインの代わりです。** 自分を外から見る絵は使いません。

### 4.2 輪をくぐって奥へ伸びる（52.30〜53.50秒）

術式から騎士の核までの道筋に、術式の輪を5枚並べます。手前ほど大きく、奥ほど小さく置きます。

- 輪の大きさは、手前が画面の高さの0.42倍、奥が0.08倍。等間隔ではなく、奥ほど詰めて置くと遠く見えます。
- 魔法の本体がくぐるたびに、その輪が0.12秒だけ強く光り、輪から火花が外へ散ります。
- くぐるたびに本体を1.15倍にし、速さを1.1倍にします。5枚で約2倍になります。
- 本体そのものは、今ある飛翔の部品（`drawTravel`）をそのまま使います。属性、形、個数、軌道は本人の魔法のままです。

### 4.3 多段命中（53.60〜54.10秒）

当たる時刻は**固定で4回**です。53.60、53.76、53.92、54.10秒（世界の時刻）。一回目の連弾は「80ms間隔で数発、最後だけ200ms空ける」なので弾の数で時刻が変わりますが、とどめでは時刻を固定します。理由は、部品が飛ぶ時刻と体力の減り方と世界の時計のゆがみを、入力によらず同じにするためです。

- 本人の魔法の弾の数（1〜5）は、この4回へ散らします。1発なら53.60秒に当たったあと、破裂が広がって残りの3回で部品が飛ぶ形にします。5発なら53.60秒に2発当て、あとは1発ずつです。
- 当たるたびに、火の粉と破片を**手前へ**飛ばします。下向きに強く、画面の外へ抜けるまで大きくします。
- 当たるたびに騎士の部品が一つ飛びます（4.5を見てください）。
- 停止は一発目だけ。あとの3回は揺れと、騎士の上だけの白にします。全画面の白は一発目だけです。

### 4.4 とどめの一撃（54.50秒）

- 停止0.25秒。世界の時計が止まるので、破片も粒も空中で静止します。
- 白→属性色→白の三段。合計0.15秒。騎士の形の上だけで、全画面には出しません。全画面の白は1回だけ（0.34秒の間隔の決まりを守るため）。
- 傾き2度、寄り1.2倍、端ほど強い色のずれ。
- 核の位置から衝撃波の輪が3枚、手前へ向かって広がります。
- 0.25秒後からスロー。

**倒れる向きは手前です（決定済み）。** 足元を軸に手前へ1.2ラジアン回し、同時に視点へ0.6だけ近づけます。近づくので画面の中で大きくなり、迫って見えます。倒れきったら動かしません。画面いっぱいに来ますが、59.4秒からは魔導書の枠が上に重なるので、結果画面の邪魔にはなりません。

騎士は今、50ほどの部品でできています（作り直した剣と盾、表面の傷と汚れの絵も入っています）。落とすときは次のようにします。

- 盾は面、縁、鋲、帯、飾りの5種類の部品の集まり、剣は握り、柄頭、鍔、刃、切っ先の集まりです。**それぞれ親の節ごと**外して落とし、ばらばらにしません。表面の絵はそのままなので、落ちた部品も同じ見た目です。
- 兜の角は37.5秒に1本折れているので、残りの1本を落とします。胸当ては39秒に外れて開いているので、その残りを飛ばします。
- 当たった場所には、今ある「属性の色の傷あと」を付けます。今は一回目の命中だけに付いていて、位置は胸に固定です。とどめでは4回の命中それぞれの部品の位置に付け、とどめの一撃で核にも付けます。倒れ始めたら（56.2秒）傷あとは0.5秒で消します。傷あとは騎士の絵の上に描く印なので、倒れる体と一緒には動かないためです。

**砕け散らせて終わりにしません。** 崩れ落ちて動かなくなる形です。

## 5. 体力を必ず0にする

体力の段は、世界の時計で動かします（既にそうなっています。一回目の段は弾が届く時刻から作られ、防御の段は37.5秒に固定です）。とどめの段を足すだけです。

| 時刻 | 残り |
| --- | --- |
| 開始 | 100% |
| 18.5秒（一回目の命中） | 入力の量に応じて20〜45%減る |
| 37.5秒（防御で受け止めきったとき） | 10%減る |
| 53.60、53.76、53.92、54.10秒（多段命中） | そのとき残っている量の9割を、4回に等分して減らす |
| **54.50秒（とどめの一撃）** | **必ず0%** |
| 55.40秒以降 | 枠が割れて薄れ、消える |

この表の時刻は世界の時刻です。

最後の段は「残りを全部」と書くのではなく、`left: 0` と直に書きます。前の二回でどれだけ減っていても、必ず0になります。0になったあとに点滅はさせません。

**0になったあとは、枠を消します（決定済み）。** 55.40秒から0.8秒かけて枠と「遺跡の騎士」の名前を一緒に薄くし、消したら戻しません。画面には自分の術式だけが残ります。

今は当たった瞬間に体力の枠が0.45秒ゆれる仕組みがあり、ゆらす時刻は「一回目の命中」と「37.5秒」の一覧で決めています。とどめでは、この一覧に53.60秒と54.50秒を足します。間の3回ではゆらしません（0.16秒おきにゆらすと震えっぱなしに見えるため）。控えめモードではゆれを出さない今の決まりのままです。

## 6. 前の二回から引き継ぐもの

- 一回目から光点2〜3個（今もやっています）、防御から光点2〜3個を、とどめの回へ渡します。合わせて最大6個です。
- 40.0〜44.0秒のあいだに、視界の左右の端から中央へゆっくり寄ってきて、術式のまわりを回ります。
- 引き継ぐ量は全体の20〜30%までという決まりを守り、新しく描く線の邪魔をしない薄さにします。
- 属性を変える言葉があれば新しい属性を優先し、前の属性は小さな残光だけ残します。
- 記録では、引き継いだ形と今回描いた形を別々に残します。

## 7. 結果画面（魔導書）

60.0秒に出します。次の人が始めるまで出したままにします。今の結果画面と同じく、まず魔法名だけを出し、0.9秒おいてから残り（術式、三件、QR、ボタン）を出します。位置は動かさず、濃さだけ変えます。

### 置き方

横長の画面を左右に分けます。

- **左（およそ6割）**：最終術式。本人が描いた線の形のまま、枠に収めて大きく見せます。戦闘中の線で背後を埋めません。枠の外は暗く沈めます。
- **右（およそ4割）**：上から順に、魔法名（大きく、明朝、ふりがな付き）、属性と用途の札、詠唱の一文、QR、確認番号、保存の状態の一行。
- **下（横いっぱい）**：一回目・防御・とどめの三件を並べます。**三件とも術式の絵を出します（決定済み）。** 各件は、左に術式の小さい絵、右に「回の名前・魔法名・ひとこと」の三行です。代表は最終魔法です。

三件の絵は、保存してある術式の点列（表示用の線）から描き直します。戦闘中の画面を写真に撮って使うのではなく、線だけを黒地に描きます。防御の回は盾の形です。

絵を三つ足すぶん、下の帯は高くなります。1920×1080では、下の帯を画面の高さの22%（約240px）取り、絵はその中で正方形（一辺およそ190px）、文字は絵の右に置きます。左の大きい術式は残りの高さに収めます。文字が小さくなりすぎたら、三件の「ひとこと」を省いて二行にします。

縦長の画面（スマートフォンでの確認用）では、上から術式、魔法名、三件（絵と文字を横並びのまま縦に積む）、QRの順に積みます。

### 文字

- 魔法名だけ明朝、ほかはゴシック。どちらも日本語用の字形。
- 1920×1080で、魔法名は72〜96px相当、三件の行は20〜24px相当から確かめます。
- 難しい言葉には小さいふりがなを付けます。ふりがなは画面の直しの中でまだ手を付けていない唯一の項目なので、魔導書で最初に入れます。
- Jevの確信度、開発用の評価値、内部の番号は出しません。
- 結果画面の見出し「二つの魔法を放った」は「三つの魔法を放った」にします。

### QRと確認番号

- QRは320px程度から確かめ、白地と余白を取ります。**背後で粒や騎士を動かしません。**
- 確認番号は6桁の数字です。何のためにあるかは次の項で説明します。QRの真下に、離れた場所の係員が読めるよう36px相当以上の大きさで出します。
- 公開ページができるまでは、QRの場所に「持ち帰りの準備中」と出し、確認番号だけ表示します。嘘のQRは出しません。

### 確認番号とは何か

遊んだ一回ごとに付ける6桁の番号です。**その人が持ち帰るものではなく、係員が「どの回の記録か」を探すための番号です。** 使い方はこうです。

- 遊んだ人が「さっきの魔法をもう一度見たい」「QRが読めなかった」と言ってきたとき、係員が結果画面や記録の一覧からこの番号で探せます。
- 公開ページができたあと、送れていない記録を係員の画面に並べるときも、この番号で見分けます。
- 公開ページの住所（URL）に使う番号とは別です。URLの番号は推測しにくい長いもの、確認番号は人が読み上げられる短いものです。

作り方は、開始のときに乱数で6桁を作り、このPCに保存済みの番号と同じなら作り直します。日付や通し番号は入れません（順番から人数が分かってしまうため）。

### 保存の状態

QRの下に一行だけ出します。

| 状態 | 表示 |
| --- | --- |
| 届いている | 持ち帰れます |
| 送信中 | 保存中。QRの先でお待ちください |
| まだ送れていない | まだ届いていません |
| 公開ページ未対応（今） | この画面でだけ見られます |

**届いていないものを「登録しました」と書きません。**

### 操作

- 空中で押すボタンは作りません。持ち帰りはQRだけです。
- 画面に残すのは「もう一度つくる」「最初へ戻る」の二つ（今と同じ）。`?dev=1` のときだけ記録の保存も出します。
- 誰も触らないまま3分たつと、今と同じくタイトルへ戻ります（秒数はURLで変えられます）。QRを読む時間としては足ります。自動で流れた見本の結果は8秒でタイトルへ戻ります。この二つは今の仕組みのままで、変えません。

## 8. 保存と持ち帰りの段取り

三段に分けます。**今回作るのは一段目までです。二段目（公開ページのサーバー）は、14章の1〜7が全部終わってから着手します（決定済み）。**

**一段目（今回）。** 魔法が確定するたびに、このPCのブラウザーの中（IndexedDB）へ保存します。16秒、33秒、51秒の三回です。確認番号を開始時に作ります。結果画面はこの保存から作ります。回線が無くても動きます。一段目だけでも展示は回せますが、持ち帰りはできません。

**二段目（公開ページができたら）。** 開始前に、推測しにくい公開用の番号と結果ページを予約します。確定のたびにサーバーへ送り、最後の魔法は51秒の確定後に送る準備を始め、発動の演出中に送ります。60秒を待ちません。届いていれば60秒の時点でQRの先が開きます。

**三段目（会場の運用）。** 送信待ちの一覧を係員の画面に出す、回線が戻ったら同じ番号で送り直す、二重登録を番号で防ぐ、結果ページから削除できるようにする。

保存するのは、三件のレシピ、術式の点列（本人の線と表示用の線）、詠唱の文字、引き継いだ形、時刻付きの手のひらの位置です。**カメラの映像と音声そのものは保存しません。**

## 9. 音

- 44〜49秒は主旋律を足し、音を厚くしていきます。
- 51.6秒で一度音を抜き、51.92〜52.0秒は無音にします。
- 52.0秒の発動、53.6秒からの多段、54.5秒の直撃を別の音にします。直撃の直前に短く音を弱めます。
- 崩れる音（剣が落ちる、膝をつく、倒れる）を衝撃の音と分けます。
- 57秒からは残響だけ。60秒の魔導書で静かな一音を鳴らします。
- マイクを使う回は、その回の録音中（49.75秒まで）効果音を鳴らしません。今までと同じ決まりです。

## 10. 安全と控えめモード

- 全画面の白は、発動（52.0秒）、一発目の命中（53.6秒）、直撃（54.5秒）の3回だけ。いちばん近い間隔でも0.9秒あるので、1秒に3回の決まりを守れます。間の3回の命中では全画面を光らせません。
- 白→属性色→白の三段の点滅は、騎士の形の上だけに限ります。全画面ではやりません。
- 飽和した赤の明滅は使いません。
- 控えめモードでは、揺れ、傾き、寄り、停止、色のずれを止め、閃光は3分の1にします。**スローと崩れ落ちる動きは残します**（動きが減る方向のため）。術式が視界を通り抜ける演出も残しますが、拡大を8倍から4倍に抑えます。
- 光に弱い人への配慮として、入口に注意書きを置き、係員が控えめモードへ切り替えられるようにします（今もボタンがあります）。

## 11. 負荷の見積もりと退避

1コマ10〜12msの中に収めます。重いのは52〜57秒の5秒間だけです。

| 処理 | 見積もり |
| --- | --- |
| 輪5枚（線だけ） | 0.3〜0.6ms |
| 多段命中の粒（1発あたり最大240個、合計で上限内） | 2〜5ms |
| 崩れ落ちの破片と塵 | 1〜3ms |
| 重い後処理（にじみ、色収差、歪み） | 2〜5ms |
| 騎士の立体の描き直し | 1〜3ms |

- 重い後処理は実際の時刻で51.9〜58.5秒だけにします（世界の時刻では51.9〜57.8秒あたり）。今の時間帯は「命中の2.5秒後まで」で決まっており、とどめの回では56.1秒で切れてしまうので、回の表から終わりの時刻を取るように直します。弱点が光る40〜52秒には常時のにじみだけをかけます。
- 粒は今の上限（派手な設定で700個）を超えません。超えそうなら古いものから使い回します。
- 毎秒の表示回数を測り、55を下回ったらにじみを切り、24を下回り続けたら合成そのものを止めて元の層へ戻します。この退避は既に入っているので、時間帯だけ足します。
- 騎士の板を貼り直す時間帯は、回の表から作ります（締め切りの0.5秒前から）。

- 結果画面は3分触られないとタイトルへ戻り、自動で流れた見本の結果は8秒で戻る。魔導書でもそのままにする（7章）。
- 騎士が50ほどの部品になり、剣と盾が複数の部品の集まりになった。落とすときは親の節ごと外す（4.5）。
- 書体はゴシックが基本で明朝は題字と魔法名だけ、と画面全体で整えられた。魔導書の文字の決まりはそれと同じ。ふりがなだけが未着手なので、魔導書で最初に入れる（7章）。
- 見本の自動再生が60秒になるので、展示の試験の待ち時間を伸ばす（12章、13章）。
