## 0. この回でやりたいこと

**「自分が作った一番大きい魔法で、目の前の騎士を倒した」を、主観視点のまま見せきる。** 三回目なので、同じ手を大きくしただけでは弱く見えます。とどめだけに使う段取りを別に用意します。難しさは作らず、入力がどうであれ必ず倒れます。

作る範囲は次の四つです。

1. とどめの回（40〜60秒）の進行と演出
2. 騎士が崩れ落ちる動きと、体力が必ず0になること
3. 結果画面（魔導書）の見た目と、三つの魔法の並べ方
4. 持ち帰りの下ごしらえ（このPCの中への保存と確認番号まで。公開ページと本物のQRは後日）

## 2. 世界の時計に「遅くする」を足す

今の世界の時計は「命中で止める」だけを持っています。とどめでは、止めるのが何回かあり、さらにスローモーションが入ります。時計の計算をひとつにまとめ直します。

### 二つの時計

この回からは、時計が二つあることをはっきり分けて書きます。

- **実際の時刻**：開始からの本当の経過。画面の残り時間、魔導書を出す60.0秒、録音の締め切りはこちら。
- **世界の時刻**：止めとスローを入れたあとの時刻。騎士、術式、魔法、粒、体力はこちらで動きます。

止めもスローも**世界の時刻で置きます**。長さは実際の秒数で指定します。こうすると、描く側（世界の時刻）と、置いた時刻がぴたりと合います。

### 形

```
ゆがみ = {
  stops: [{ at: 世界の時刻, hold: 実際に止める秒数 }, ...],   // 時刻の順に並べる
  slow:  { from: 世界の時刻, seconds: 実際の長さ, rate: 速さの倍率 } | null
}

世界の時刻(t) を出す手順：
  遅れ = 0
  出来事を順に見る：
    その出来事が始まる実際の時刻 = at + 遅れ
    t がそこへ届いていなければ、そこで終わり
    止めなら   遅れ += min(hold, t - 始まる実際の時刻)
    スローなら 遅れ += (1 - rate) × min(seconds, t - 始まる実際の時刻)
  返す値 = t - 遅れ
```

- 止めている間は、遅れが t と同じ速さで増えるので、世界の時刻はぴたりと止まります。
- スローの間は、世界の時刻が rate 倍の速さで進みます。
- 時刻だけで決まる計算なので、今までどおり試験できます。時計が戻ることはありません。

### 今までと同じになること

一回目と防御は `stops` が一つ（命中の時刻に、今と同じ長さ）、`slow` は `null` です。式に入れると今の `effectTime` とまったく同じ値になります。**ここは総当たりの試験で確かめてから進めます。**

### とどめのゆがみと、二つの時計のずれ

| 世界の時刻 | 何を | 長さ（実際） | 実際の時刻 | ここまでの遅れ |
| --- | --- | --- | --- | --- |
| 53.60 | 一発目の命中で止める | 0.06秒 | 53.60〜53.66 | 0.06秒 |
| 54.10 | 最後の小さい命中で止める | 0.06秒 | 54.16〜54.22 | 0.12秒 |
| 54.50 | とどめの一撃で止める | 0.25秒 | 54.62〜54.87 | 0.37秒 |
| 54.80 | 0.25倍のスロー | 0.50秒 | 55.17〜55.67 | 0.745秒 |

合計の遅れは0.745秒です。つまり**実際の60.0秒のとき、世界の時刻は59.26秒**です。この0.745秒を使い切らないよう、崩れ落ちと余韻は世界の時刻で59.25秒までに終わらせます。

止める回数を増やすほど遅れが増え、余韻が削られます。**止めるのは3回まで、遅れの合計は0.8秒まで**と決めておきます。試験でこれを超えたら止めます。

小さい命中の停止は0.06秒で、仕様の「約0.1秒」より短くしてあります。連続して当たるので、0.1秒ずつ止めると遅れが増えすぎ、余韻が削られるためです。仕様の0.1秒はとどめの一撃で守り、そこだけ0.25秒まで伸ばします。

## 4. とどめだけの見せ方（作る部品）

新しく `src/render/effects/finish.ts` を作り、次の五つを入れます。ほかの回からは呼びません。

### 4.1 術式が視界を通り抜ける（52.00〜52.25秒）

完成した術式の形（本人が描いた線）を、中心から外へ一気に広げます。広がりきる手前で線が薄くなり、画面の外へ抜けます。

- 拡大は1倍から8倍へ、0.25秒。最初の0.1秒で6倍まで行き、残りでゆっくり抜ける（速く始めて遅く終わる）。
- 濃さは最初の0.06秒で1.0、そこから0へ。
- 同時に全画面の白が0.85まで上がり、0.17秒で戻る（既にある閃光の層を使う）。
- 線の色は属性の色、芯は白。今の術式の描き方をそのまま拡大して使います。

**これがカットインの代わりです。** 自分を外から見る絵は使いません。

### 4.2 輪をくぐって奥へ伸びる（52.30〜53.50秒）

術式から騎士の核までの道筋に、術式の輪を5枚並べます。手前ほど大きく、奥ほど小さく置きます。

- 輪の大きさは、手前が画面の高さの0.42倍、奥が0.08倍。等間隔ではなく、奥ほど詰めて置くと遠く見えます。
- 魔法の本体がくぐるたびに、その輪が0.12秒だけ強く光り、輪から火花が外へ散ります。
- くぐるたびに本体を1.15倍にし、速さを1.1倍にします。5枚で約2倍になります。
- 本体そのものは、今ある飛翔の部品（`drawTravel`）をそのまま使います。属性、形、個数、軌道は本人の魔法のままです。

### 4.3 多段命中（53.60〜54.10秒）

今ある連弾の間隔（80ms間隔、最後だけ200ms空ける）をそのまま使います。違うのは次の点です。

- 当たるたびに、火の粉と破片を**手前へ**飛ばします。下向きに強く、画面の外へ抜けるまで大きくします。
- 当たるたびに騎士の部品が一つ飛びます（4.5を見てください）。
- 停止は一発目と最後の一発だけ。中の発は揺れと白だけにします。

### 4.4 とどめの一撃（54.50秒）

- 停止0.25秒。世界の時計が止まるので、破片も粒も空中で静止します。
- 白→属性色→白の三段。合計0.15秒。全画面の白は1回だけ（0.34秒の間隔の決まりを守るため）。
- 傾き2度、寄り1.2倍、端ほど強い色のずれ。
- 核の位置から衝撃波の輪が3枚、手前へ向かって広がります。
- 0.25秒後からスロー。

## 5. 体力を必ず0にする

体力の段は、世界の時計で動かします（今は実際の時計です。止めとスローを入れると見た目とずれるため、切り替えます）。

| 時刻 | 残り |
| --- | --- |
| 開始 | 100% |
| 18.5秒（一回目の命中） | 入力の量に応じて20〜45%減る |
| 37.5秒（防御で受け止めきったとき） | 10%減る |
| 53.60〜54.10秒（多段命中） | そのとき残っている量の9割を、命中の数で割って減らす |
| **54.50秒（とどめの一撃）** | **必ず0%** |
| 55.40秒以降 | 枠が割れて薄れ、消える |

この表の時刻は世界の時刻です。

最後の段は「残りを全部」と書くのではなく、`left: 0` と直に書きます。前の二回でどれだけ減っていても、必ず0になります。0になったあとに点滅はさせません。

## 6. 前の二回から引き継ぐもの

- 一回目から光点2〜3個（今もやっています）、防御から光点2〜3個を、とどめの回へ渡します。合わせて最大6個です。
- 40.0〜44.0秒のあいだに、視界の左右の端から中央へゆっくり寄ってきて、術式のまわりを回ります。
- 引き継ぐ量は全体の20〜30%までという決まりを守り、新しく描く線の邪魔をしない薄さにします。
- 属性を変える言葉があれば新しい属性を優先し、前の属性は小さな残光だけ残します。
- 記録では、引き継いだ形と今回描いた形を別々に残します。

## 7. 結果画面（魔導書）

60.0秒に出します。次の人が始めるまで出したままにします。

### 置き方

- **左（およそ6割）**：最終術式。本人が描いた線の形のまま、枠に収めて大きく見せます。戦闘中の線で背後を埋めません。枠の外は暗く沈めます。
- **右（およそ4割）**：上から順に、魔法名（大きく、明朝、ふりがな付き）、属性と用途の札、詠唱の一文、QR、確認番号、保存の状態の一行。
- **下（横いっぱい）**：一回目・防御・とどめの三件を小さく並べます。各件は「回の名前・魔法名・ひとこと」の三つだけ。代表は最終魔法です。

縦長の画面（スマートフォンでの確認用）では、上から術式、魔法名、三件、QRの順に積みます。

### 文字

- 魔法名だけ明朝、ほかはゴシック。どちらも日本語用の字形。
- 1920×1080で、魔法名は72〜96px相当、三件の行は20〜24px相当から確かめます。
- 難しい言葉には小さいふりがなを付けます。
- Jevの確信度、開発用の評価値、内部の番号は出しません。

### QRと確認番号

- QRは320px程度から確かめ、白地と余白を取ります。**背後で粒や騎士を動かしません。**
- 確認番号は6桁。係員が「どの回の記録か」を突き合わせるために使います。
- 公開ページができるまでは、QRの場所に「持ち帰りの準備中」と出し、確認番号だけ表示します。嘘のQRは出しません。

### 操作

- 空中で押すボタンは作りません。持ち帰りはQRだけです。
- 画面に残すのは「もう一度つくる」「最初へ戻る」の二つ（今と同じ）。`?dev=1` のときだけ記録の保存も出します。

## 8. 保存と持ち帰りの段取り

三段に分けます。**今回作るのは一段目までです。**

**一段目（今回）。** 魔法が確定するたびに、このPCのブラウザーの中（IndexedDB）へ保存します。16秒、33秒、51秒の三回です。確認番号を開始時に作ります。結果画面はこの保存から作ります。回線が無くても動きます。

**二段目（公開ページができたら）。** 開始前に、推測しにくい公開用の番号と結果ページを予約します。確定のたびにサーバーへ送り、最後の魔法は51秒の確定後に送る準備を始め、発動の演出中に送ります。60秒を待ちません。届いていれば60秒の時点でQRの先が開きます。

**三段目（会場の運用）。** 送信待ちの一覧を係員の画面に出す、回線が戻ったら同じ番号で送り直す、二重登録を番号で防ぐ、結果ページから削除できるようにする。

保存するのは、三件のレシピ、術式の点列（本人の線と表示用の線）、詠唱の文字、引き継いだ形、時刻付きの手のひらの位置です。**カメラの映像と音声そのものは保存しません。**

## 9. 音

- 44〜49秒は主旋律を足し、音を厚くしていきます。
- 51.6秒で一度音を抜き、51.92〜52.0秒は無音にします。
- 52.0秒の発動、53.6秒からの多段、54.5秒の直撃を別の音にします。直撃の直前に短く音を弱めます。
- 崩れる音（剣が落ちる、膝をつく、倒れる）を衝撃の音と分けます。
- 57秒からは残響だけ。60秒の魔導書で静かな一音を鳴らします。
- マイクを使う回は、その回の録音中（49.75秒まで）効果音を鳴らしません。今までと同じ決まりです。

## 10. 安全と控えめモード

- 全画面の白は、発動（52.0秒）と直撃（54.5秒）の2回だけ。間隔は2.5秒あるので、1秒に3回の決まりを余裕で守ります。
- 白→属性色→白の三段の点滅は、騎士の形の上だけに限ります。全画面ではやりません。
- 飽和した赤の明滅は使いません。
- 控えめモードでは、揺れ、傾き、寄り、停止、色のずれを止め、閃光は3分の1にします。**スローと崩れ落ちる動きは残します**（動きが減る方向のため）。術式が視界を通り抜ける演出も残しますが、拡大を8倍から4倍に抑えます。
- 光に弱い人への配慮として、入口に注意書きを置き、係員が控えめモードへ切り替えられるようにします（今もボタンがあります）。

## 11. 負荷の見積もりと退避

1コマ10〜12msの中に収めます。重いのは52〜57秒の5秒間だけです。

| 処理 | 見積もり |
| --- | --- |
| 輪5枚（線だけ） | 0.3〜0.6ms |
| 多段命中の粒（1発あたり最大240個、合計で上限内） | 2〜5ms |
| 崩れ落ちの破片と塵 | 1〜3ms |
| 重い後処理（にじみ、色収差、歪み） | 2〜5ms |
| 騎士の立体の描き直し | 1〜3ms |

- 重い後処理は実際の時刻で51.9〜58.5秒だけにします（世界の時刻では51.9〜57.8秒あたり）。弱点が光る40〜52秒には常時のにじみだけをかけます。
- 粒は今の上限（派手な設定で700個）を超えません。超えそうなら古いものから使い回します。
- 毎秒の表示回数を測り、55を下回ったらにじみを切り、24を下回り続けたら合成そのものを止めて元の層へ戻します。この退避は既に入っているので、時間帯だけ足します。
- 騎士の板を貼り直す時間帯は、回の表から作ります（締め切りの0.5秒前から）。

## 13. 試験の計画

単体の試験で先に守るもの。

- 世界の時計：止めが重なっても時刻が戻らないこと、遅くした分だけ遅れること、**一回目と防御の値が今までと完全に同じであること**（総当たりで比べる）。
- 世界の時計が、実際の時刻に対して増えるだけで減らないこと（0〜60秒を細かく刻んで確かめる）。
- 上の表の「実際の時刻」が計算と合っていること（53.66、54.22、54.87、55.67、60.0で世界の時刻が59.255）。
- 遅れの合計が0.8秒を超えないこと。超えると余韻が削られるため、試験で止めます。
- 体力：どんな入力でも54.5秒でちょうど0になること。前の二回の減り方によらないこと。
- 回の表：三回目の場面の境目、締め切りと確定の間隔、`finish` が `impact` より後にあること。
- 引き継ぎ：光点が6個を超えないこと。
- 結果画面に渡す三件が、実際に確定した魔法と一致すること。

ブラウザーの試験で守るもの。

- 60秒を通して遊び、画面のエラーが出ないこと。
- 54.5秒に体力が0になり、結果画面に三件が並ぶこと。
- 結果画面が次の開始操作まで消えないこと。
- 確認番号が6桁で出ていること。

## 15. 決めてほしいこと

1. **倒れる向きを手前でよいか。** 手前へ倒れると近づくので迫力が出ますが、画面いっぱいに騎士が来ます。奥へ倒れる方が静かです。手前を勧めます。
2. **体力の枠を、0になったあと消すか残すか。** 消すと画面が静かになり、術式だけが残ります。残すと「倒した」が数字で分かります。消す方を勧めます。
3. **結果画面に、三件それぞれの術式の絵を出すか。** 今の案は最終術式だけ大きく、ほかは名前だけです。三つとも小さく絵を出すこともできますが、文字が小さくなります。
4. **確認番号を画面のどこに出すか。** QRの下が素直ですが、係員が離れた場所から読めるよう大きく出す手もあります。
5. **公開ページのサーバーをいつ用意するか。** 一段目（このPCの中だけ）で展示を回すこともできます。その場合、持ち帰りはできません。
