# 騎士の動きと効果音

2026年9月20日作成、9月21日に90秒へ直しました。一回目の魔法と防御の回（0〜56秒）の分です。演出の全面更新で命中の反応と体力の表示を作り直しました。とどめの回（56〜90秒）で騎士が崩れ落ちるところは [とどめと結果の詳細設計](とどめと結果_詳細設計.md) の3章と4章にあります。

## 今回の範囲

騎士と背景を別にしました。背景は一枚絵のまま、騎士はアプリ内で組み立てた立体のモデルです。作り方は2通りです。丸みのある部品は、横から見た輪郭の線を1本描いて、それを回して立体にしています（兜、胸、喉当て、肩当て、腰の板、腰布）。輪郭の線に段を付けると、1つの部品で重ね板になります。残りは角柱、円錐、半球です（腿、丸い膝当て、脛当て、先のとがった具足、帯、腹、金のV字、胸の核、背中のマント、とがった面、後ろへ寝た角、光る目、肩の棘、上腕、肘当て、前腕、剣、五角形の盾、足元の影）。全部で50ほどの部品です。指と布の揺れは作っていません。

回して作った部品は、面ごとに平らに塗っています。輪郭は丸いまま、板を張り合わせた鎧に見えます。角柱の面の数も6から12〜20へ増やしました。

形は元絵の騎士へ寄せています。腰は板を3枚重ねてから布が長く広がり、肩は板を重ね、盾は上が広く下がとがった五角形で体の横へ下げています。頭は小さめにし、金は帯、盾の縁と鋲、胸のV字だけに使って、広い面には置いていません。盾側の肩当てだけ少し大きくしています。

剣と盾は後から作り直しました。剣は刃が細くて画面の中で線に見えていたので、幅を広げ、先の三角を別の部品にして、柄を両手で握れる長さにし、鍔も横へ伸ばしました。盾は平らな板だったので、手前の面を一回り小さくして縁に斜めの面を作り、中央の帯を角の立った隆起に変え、五つの角へ鋲を置いています。隆起は左右で明るさが変わるため、正面から見ても平らに見えません。

金属に見せるため、空と床の色を塗った小さな絵を6面ぶんアプリの中で作り、鎧、金の縁、刃へ映り込ませています。正面より縁のほうが強く映ります。画像のファイルは持たず、起動時に描いています。あわせて、面が視線に対して寝ているほど明るくなる設定で、逆光の縁を起こしています。この明かりは以前は面の広い範囲へ回っていましたが、本当に縁の部分だけへ絞りました。胸の核と兜の目はにじませ、命中の瞬間だけ胸の前の光源を強めます。この光源の色は魔法の属性の色を白へ寄せたものです。

腕は肩と肘の2段にして、肘を少し前へ曲げています。立ち方は左右で変えています。足の位置を前後にずらし、つま先を外へ開き、膝から下を少し内へ向けています。待機は、剣を肩の後ろへ振りかぶり、盾を前へ出し、膝を沈めた構えです。上半身だけを少しひねって半身にし、兜はこちらを向いたままにしています。そのうえで5.6秒に一度、剣をゆっくり上げ下げします。体がごく小さく上下し、上半身がゆっくり揺れ、首が左右へ振れ、腕も少し動きます。兜の目はゆっくり明滅します。控えめモードでは、これらをすべて止めます。

背景の一枚絵と同じ大きさに見えるよう、足元が画面の高さの71.4%に来る視点を固定しています。2026年9月21日に見上げる視点へ変えました。視点の高さは0.5m、距離は4m、5度ほど上を向き、兜の先は画面の上端から2%に来ます（前は真正面の高さ0.95m、距離6.9m、兜の先5.2%）。足元と兜の先の位置から視野の角度を計算するので、視点を変えてもこの二点は守られます。足元と兜の先を両方守ると縦の大きさは1.05倍までしか大きくならず、大きく見えるのは主に低い視点の遠近です。横長の画面では背景が広がる分だけ視野を狭め、騎士も同じだけ大きくします。命中（18.5秒）で視点が後ろへ0.35m引いて1.5度上を向き、床を打つ一撃（33.55秒）で下へ沈み、とどめの一撃で大きく引きます。控えめモードと「動きを減らす」では視点は動きません。光は空からの弱い光、奥からの逆光、手前からの光の3つです。手前の光だけが影を落とし、肩当てや剣、帯の影が体に掛かります。足元の丸い影は、今までどおり濃淡を描いた一枚の面です。

## 表面の傷と汚れ

面がのっぺりしていたので、絵を3枚、起動時にその場で描いて全身へ貼りました。外部のファイルは増えません。

- 汚れ：しみと、縦に流れた跡。材質の色に掛けて暗くします。
- てかりむら：磨けた所と曇った所。光り方の強弱を場所ごとに変えます。
- でこぼこ：打ち傷のへこみ、擦り傷、鋳物のざらつき。白黒で高さを描いてから隣との差で面の向きに直し、光の当たる向きを面の中で変えます。

いちばん効いたのはでこぼこです。色を掛けるだけの絵は、離れて見るとほとんど変わりませんでした。面の中の明暗の幅を測っても増えていません。明るい所も暗い所も同じ割合で暗くなるため、かえって幅が狭まります。光の当たり方を変えるでこぼこの絵を足してから、板が金属らしく見えるようになりました。

絵は部品ごとに1枚ぶんを貼っています。大きい部品ほど傷の粒も大きくなりますが、そろえようとして貼り方の目盛りをいじると、丸い部品で一周したところに絵の端どうしの合わない縦線が出ます。粒の大きさをそろえる案は試して取りやめました。

実寸に合わせて目盛りを変えた版も作って見比べましたが、部品が絵のごく一部だけを使うようになり、面の中の変化がかえって減りました。今の形がいちばん素直で、継ぎ目も出ません。

盾の面だけは刃と同じ磨いた鋼にしました。見本でも盾は体より明るく見えます。

場所を決めた模様も3つ入れました。盾の面には、術式と同じ丸と三角の紋章を彫っています。丸い面を持つ部品は絵の真ん中がそのまま面の真ん中に来るので、位置合わせで迷いません。ただし絵は上下が入れ替わって貼られるので、三角は絵の中では下向きに描いてあります。色を暗くする絵と、へこみを付ける絵の両方に同じ形を描いて、彫った線に見えるようにしています。帯には同じ飾りを一周に8つ並べました。腰布の裾は、布の絵の端を欠けさせて、ぎざぎざの裾にしています。透かすのではなく、薄い所を描かない設定なので、重なりの順番で困ることはありません。裾にあった金の輪は外しました。布の裾が終わりになるほうが、見本に近くなります。

## 場面へなじませる

背景の中で浮いて見えたため、明るさと色を場面へ寄せました。見本の一枚絵を測ると、騎士の体は255段階で35〜90、すぐ後ろの背景は117〜133で、体のほうがずっと暗く沈んでいます。こちらも同じくらいになるまで光を落とし、鎧の青みを抜いて無彩色に近づけ、金と刃の明るさも下げました。上を向いた面へ空の白が映って光っていたので、映り込みに使う絵の上の面も暗くしています。

遠い面ほど空気の色を混ぜ、背中側と裾が背景へ溶けるようにしました。足元の丸い影にだけは混ぜません。混ぜると影が灰色に浮きます。

騎士の描画面は、背景の一枚絵より少し粗く描いてから画面の大きさへ広げ、さらに表示の設定でわずかににじませています。背景の絵は輪郭が柔らかいので、騎士の線だけくっきりしていると貼り付けたように見えます。粗く描くぶん、描く点は減ります。

見本の一枚絵と同じ見た目ではありません。鎧の細部は省き、輪郭と姿勢が分かることを優先しています。歩行、攻撃、倒れる動き、視点を回す表示は含みません。

## 姿勢

姿勢は10です。一回目で使う待機、ひるむ、構えを戻すの3つに、防御の回で使う構え、溜め、振り下ろし、弾かれる、前屈（弱点を晒す）の5つ、とどめの回の崩れ落ちる、待機の息づかいに使う「剣を上げた構え」を足しています。画像を切り替えるのではなく、10の角度の表を重みで混ぜ、胴、首、体のひねり、剣の腕、盾の腕の5か所を動かします。待機は剣を振りかぶった構えで、5.6秒に一度ゆっくり剣が上下します。防御の回の溜めは、待機のどこよりも剣を高く上げるので、見分けが付きます。

| 時刻 | 姿勢 |
| --- | --- |
| 23.5秒 | 魔法が届く。0.1秒ほどでひるむ姿勢に入る |
| 23.5〜24.1秒 | ひるんだまま。下に書く命中の反応はこの間に出る |
| 24.1〜24.3秒 | 構えを戻す姿勢へ移る |
| 24.3〜25.2秒 | 盾を寄せて構えを戻した姿勢 |
| 25.2〜25.8秒 | 待機の姿勢へ戻る |
| 29秒 | 剣を引いて構える |
| 30.2秒から15秒 | 剣を頭上へ上げ、溜める |
| 48秒 | 0.55秒で振り下ろす |
| 50.4秒 | 盾に弾かれて後ろへ反る |
| 51.2秒 | 「返せ」と唱えていたときだけ、戻ってきた一撃を受けて短く白く光る |
| 52.5秒 | 兜の角が1本折れて消える。52.6秒から構えを戻す |
| 55秒 | 0.7秒かけて胸当てが前へ外れ、胸の線が左右へ開き、胸の核が2倍になって明滅する |

命中位置は決め打ちの点ではなく、そのときの胸の核の位置を画面上の座標へ直して使います。吹き飛びと回転の分も足すので、崩れている間も胸を狙います。背景だけが動いたり元の騎士が二重に残ったりしないよう、背景は騎士を除いた一枚絵を使っています。

`?view=look` の確認画面では姿勢を止めて見られます。「被弾」は23.7秒、「構えを戻す」は24.9秒で止めた姿勢です。

## 命中の反応

23.5秒に魔法が届いた瞬間から、次の5つが重なります。いちばん長いものでも0.6秒で終わります。

- 白飛び：騎士の形の上だけを、白、属性の色、白の順に0.05秒ずつ塗ります。合計0.15秒です。その間はずっと塗るので、点滅ではなく一続きの白に見えます。
- 吹き飛びと回転：奥へ押されて少し縮み、打たれた向きへ傾きます。強いほど戻りが遅く、いちばん強いときは沈み込んで転倒に近い崩れになります。
- 残像：直前の何コマかの騎士の形を、白に近い色で後ろへ重ねます。0.3秒で消えます。
- 輪郭の発光：騎士の形を属性の色で少しずらして後ろへ重ね、縁を光らせます。0.6秒で消えます。
- 胸の光：命中の瞬間だけ胸の前の光源と胸の核を強めます。核は18秒からの蓄積でも少しずつ明るくなります。

反応の強さは魔法で決まります。個数が多く、範囲が広く、線が一点に集まっているほど大きく崩れ、拘束と強化では小さくなります。同じ魔法でも、たくさん描いてたくさん唱えたほど強くなります。

控えめモードでは、待機の息づかいと、吹き飛び、回転、沈み込みを止め、白飛びを出さず、残像と輪郭の光を弱めます。このPCの「動きを減らす」設定と `?calm=1` は、控えめモードの始めの値を決めるだけです。「演出を派手にする」ボタンはいつでも押せて、押せば騎士の動きも一緒に戻ります。選んだほうは次回も覚えています。

## 体力の表示

画面の右端に、騎士の体力を縦の帯で出します。名前は帯の左へ縦書きで添えます。騎士の顔や背景と重ならない場所です。本体の帯は下端を固定して上から減り、その下の薄い赤が0.3秒待ってから0.5秒かけて追いつきます。減る量は魔法の個数、範囲、収束で決まります。連弾は弾が届くたびに一段ずつ減らすので、最後の特大の1発でも減ります。体力は演出のための数値で、勝ち負けの計算には使いません。残りが少なくても点滅させません。

## 効果音

ブラウザー内で短い音と雑音を合成します。外部の効果音ファイルは使っていません。

| 時刻 | 音 |
| --- | --- |
| 3.5秒・9.5秒 | 騎士が足を踏み替える低い足音と、剣で盾を打ち鳴らす金属の音。マイクを使う回は録音中なので鳴らない（マウスのときだけ） |
| 7秒・14秒 | 描き足しと詠唱の案内を示す小さい音 |
| 18.75秒 | 蓄積 |
| 21秒 | 完成 |
| 22秒 | 放出 |
| 23.5秒 | 命中。低い音と短い金属音。雷や氷では高い音も追加 |
| 27秒 | 終わりの小さい音 |
| 30.2〜48秒 | 騎士が剣を振り上げて溜める間、低いうなりが少しずつ大きくなる。曲と同じ経路を通すので、録音中は曲と一緒に下がる |
| 40・45.75・48・49秒 | 防御の回の、詠唱の案内、蓄積、完成、盾が立つ音 |
| 48秒・48.55秒 | 剣を振り下ろす風切りと、剣が床を打つ重い衝撃（石が割れる音と低い残り） |
| 50.4秒 | 敵の一撃を受け止めた音。低い衝撃、金属の鳴り、砕けた破片の三層 |
| 53.9秒 | 防御の回の終わりの小さい音 |

音の厚みは魔法の派手さと入力の量で変わります。鳴る時刻は変えていません。

マイクを使う回は、その回の録音と最後の文字を待つ間（一回目は18.75秒、防御は45.75秒まで）鳴らしません。印を囲めた合図の音もこの決まりに合わせています。最初の画面の「音を試す」で音量を確認できます。初期音量は25%。効果音のチェック、音量調整、プレイ中の「音を消す」で変更します。中止、画面を隠す、終了、再開では前の音を止めます。音が使えないブラウザーでもゲームは続けます。

音は開始操作後に用意します。録音用の接続とは別で、合成した音を音声認識へ直接渡す処理はありません。実際の会場のスピーカー音量は人が聞いて調整する必要があります。

## 確認と残り

ここから下は作ったときの記録です。速さの測定と「17.010秒に発動」は、60秒だったころ（一回目の発動が17秒）のものです。今の発動は22秒です。

単体の試験で確かめたのは、命中の前にひるまないこと、命中の後に構えを戻すこと、白飛びが白、属性の色、白の三段になること、残像と輪郭の光が消える時刻、控えめモードで白飛びが出ず残像と輪郭が弱くなること、「動きを減らす」設定で吹き飛びと回転が止まること、入力の量が多いほど反応が強いこと、連弾で弾が届くたびに体力が一段ずつ減ること、防御の回の姿勢の順と受け止めの音の時刻、録音中の無音、同じ音の重複です。試験の件数と最新の結果は[実装と確認の記録](実装と確認の記録.md)にあります。

ブラウザーでは実際の音の出力、消音、途中中止、音声認識と同時に使った発動を確認しました。画像は1440×900と390×844で見直しています。防御の回と見た目の作り込みを合流した後のブラウザー試験25件も、Macで通っています（2026年9月20日）。

初期音量25%で測った出力の最大振幅は約0.393で、測定した回では振幅の上限に達していません。消音と中止後の無音、終了時に音の生成処理が残っていないことも確認しました。再プレイの短い音を一度テストが取り逃がしたため、出力を20ms間隔で測り、その最大値を見る方法に直して再確認しました。

このPCのローカル認識とマウスを使った一回の測定では平均56.63fps、フレーム間隔の99パーセンタイル18.5msで、17.010秒に発動しました。カメラは同時使用していません。音声は合成音声で、人の声や実際の会場での聞こえ方は未確認です。立体の騎士へ置き換えた回は開発用の環境（ソフトウェア描画で毎秒1.6画面）で目視しました。画像の騎士は毎秒1.7画面だったので、立体にして重くなった分はわずかです。
