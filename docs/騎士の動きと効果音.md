# 騎士の動きと効果音

2026年9月20日。最初の24秒に追加し、演出の全面更新で命中の反応と体力の表示を作り直しました。

## 今回の範囲

騎士と背景を別にしました。背景は一枚絵のまま、騎士はアプリ内で組み立てた立体のモデルです。角柱、円錐、半球だけを使い、腿、膝当て、脛当て、具足、腰布と金の裾、帯、腹、胸、胸当て、金のV字、胸の核、喉当て、背中のマント、兜、兜の角、光る目、半球の肩当てと棘、上腕、肘当て、前腕、剣（握り、柄頭、鍔、刃）、凧形の盾（面、金の縁、飾り）、足元の影で40ほどの部品になります。鎧の模様、指、布の揺れは作っていません。

暗い鎧のまま輪郭を見せるため、面が視線に対して寝ているほど明るくなる設定を使い、逆光の縁だけを起こしています。胸の核と兜の目はにじませ、命中の瞬間だけ胸の前の光源を強めます。この光源の色は魔法の属性の色を白へ寄せたものです。

背景の一枚絵と同じ大きさに見えるよう、足元が画面の高さの71.4%、兜の先が5.2%に来る視点を固定しています。横長の画面では背景が広がる分だけ視野を狭め、騎士も同じだけ大きくします。光は空からの弱い光、奥からの逆光、床からの照り返しの3つだけです。影は足元に置いた一枚の面で、光源からの影の計算は使いません。

見本の一枚絵と同じ見た目ではありません。鎧の細部は省き、輪郭と姿勢が分かることを優先しています。歩行、攻撃、倒れる動き、視点を回す表示は含みません。

## 姿勢

姿勢は待機、ひるむ、構えを戻すの3つです。画像を切り替えるのではなく、3つの角度の表を重みで混ぜ、胴、首、剣の腕、盾の腕の4か所を曲げます。待機中はごく小さく体が上下します。

| 時刻 | 姿勢 |
| --- | --- |
| 18.5秒 | 魔法が届く。0.1秒ほどでひるむ姿勢に入る |
| 18.5〜19.1秒 | ひるんだまま。下に書く命中の反応はこの間に出る |
| 19.1〜19.3秒 | 構えを戻す姿勢へ移る |
| 19.3〜20.2秒 | 盾を寄せて構えを戻した姿勢 |
| 20.2〜20.8秒 | 待機の姿勢へ戻る |

命中位置は決め打ちの点ではなく、そのときの胸の核の位置を画面上の座標へ直して使います。吹き飛びと回転の分も足すので、崩れている間も胸を狙います。背景だけが動いたり元の騎士が二重に残ったりしないよう、背景は騎士を除いた一枚絵を使っています。

`?view=look` の確認画面では姿勢を止めて見られます。「被弾」は18.7秒、「構えを戻す」は19.9秒で止めた姿勢です。

## 命中の反応

18.5秒に魔法が届いた瞬間から、次の5つが重なります。いちばん長いものでも0.6秒で終わります。

- 白飛び：騎士の形の上だけを、白、属性の色、白の順に0.05秒ずつ塗ります。合計0.15秒です。その間はずっと塗るので、点滅ではなく一続きの白に見えます。
- 吹き飛びと回転：奥へ押されて少し縮み、打たれた向きへ傾きます。強いほど戻りが遅く、いちばん強いときは沈み込んで転倒に近い崩れになります。
- 残像：直前の何コマかの騎士の形を、白に近い色で後ろへ重ねます。0.3秒で消えます。
- 輪郭の発光：騎士の形を属性の色で少しずらして後ろへ重ね、縁を光らせます。0.6秒で消えます。
- 胸の光：命中の瞬間だけ胸の前の光源と胸の核を強めます。核は14秒からの蓄積でも少しずつ明るくなります。

反応の強さは魔法で決まります。個数が多く、範囲が広く、線が一点に集まっているほど大きく崩れ、拘束と強化では小さくなります。同じ魔法でも、たくさん描いてたくさん唱えたほど強くなります。

端末の「動きを減らす」設定では、待機の上下と、吹き飛び、回転、沈み込みを止めます。この設定のときは控えめモードにもなります。控えめモード（「演出を控えめにする」ボタン、`?calm=1`、「動きを減らす」設定）では白飛びを出さず、残像と輪郭の光を弱めます。

## 体力の表示

画面の上に騎士の体力を出します。本体の帯はすぐ減り、その下の薄い赤が0.3秒待ってから0.5秒かけて追いつきます。減る量は魔法の個数、範囲、収束で決まります。連弾は弾が届くたびに一段ずつ減らすので、最後の特大の1発でも減ります。体力は演出のための数値で、勝ち負けの計算には使いません。残りが少なくても点滅させません。

## 効果音

ブラウザー内で短い音と雑音を合成します。外部の効果音ファイルは使っていません。

| 時刻 | 音 |
| --- | --- |
| 6秒・11秒 | 描き足しと詠唱の案内を示す小さい音 |
| 14.75秒 | 蓄積 |
| 16秒 | 完成 |
| 17秒 | 放出 |
| 18.5秒 | 命中。低い音と短い金属音。雷や氷では高い音も追加 |
| 22秒 | 終わりの小さい音 |

音の厚みは魔法の派手さと入力の量で変わります。鳴る時刻は変えていません。

マイクを使う回は、録音と最後の文字を待つ14.75秒まで鳴らしません。最初の画面の「音を試す」で音量を確認できます。初期音量は25%。効果音のチェック、音量調整、プレイ中の「音を消す」で変更します。中止、画面を隠す、終了、再開では前の音を止めます。音が使えないブラウザーでもゲームは続けます。

音は開始操作後に用意します。録音用の接続とは別で、合成した音を音声認識へ直接渡す処理はありません。実際の会場のスピーカー音量は人が聞いて調整する必要があります。

## 確認と残り

単体の試験で確かめたのは、命中の前にひるまないこと、命中の後に構えを戻すこと、白飛びが白、属性の色、白の三段になること、残像と輪郭の光が消える時刻、控えめモードで白飛びが出ず残像と輪郭が弱くなること、「動きを減らす」設定で吹き飛びと回転が止まること、入力の量が多いほど反応が強いこと、連弾で弾が届くたびに体力が一段ずつ減ること、音の時刻、録音中の無音、同じ音の重複です。試験の件数と最新の結果は[実装と確認の記録](実装と確認の記録.md)にあります。

ブラウザーでは実際の音の出力、消音、途中中止、音声認識と同時に使った発動を確認しました。画像は1440×900と390×844で見直しています。

初期音量25%で測った出力の最大振幅は約0.393で、測定した回では振幅の上限に達していません。消音と中止後の無音、終了時に音の生成処理が残っていないことも確認しました。再プレイの短い音を一度テストが取り逃がしたため、出力を20ms間隔で測り、その最大値を見る方法に直して再確認しました。

このPCのローカル認識とマウスを使った一回の測定では平均56.63fps、フレーム間隔の99パーセンタイル18.5msで、17.010秒に発動しました。カメラは同時使用していません。音声は合成音声で、人の声や実際の会場での聞こえ方は未確認です。立体の騎士へ置き換えた回は開発用の環境（ソフトウェア描画で毎秒1.6画面）で目視しました。画像の騎士は毎秒1.7画面だったので、立体にして重くなった分はわずかです。

確認記録は `.local-speech/knight-audio-report.json`、実際のアプリ出力から作った試聴用の音は `.local-speech/knight-audio-preview.webm` に保存しています。後者は試聴ボタンと一回のプレイを含み、途中には無音があります。マイクの録音ではありません。どちらもGitには含めません。

まだ見ていないのは、命中の反応（白飛び、吹き飛び、残像、輪郭の光）と体力の減り方の実機での見え方、控えめモードでの騎士の見え方です。画面が遅いと0.6秒しかない反応を飛ばすので、この確認はGPUのあるPCで行ってください。今後も残るものは、床や鎧へ届く照明、攻撃・弱点・倒れる動き、音楽、60秒全体の防御と最後の魔法、実際の人の手と声による確認です。
