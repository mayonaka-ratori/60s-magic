# 騎士の動きと効果音

一回目の魔法と防御の回の、騎士の形と動き、命中の反応、体力の表示、効果音の説明です。とどめの回で騎士が崩れ落ちるところは [とどめと結果の詳細設計](とどめと結果_詳細設計.md) の3章と4章にあります。

秒数はすべて `src/game/rounds.ts` の表から作っています。遊び方で時刻が変わる所は「同時に」と「順番に」を並べて書きます。二つの遊び方の流れは[順番に入力する遊び方](順番に入力する遊び方_設計.md)の5章にあります。

## 騎士の形

騎士と背景は別です。背景は騎士を除いた一枚絵（`public/art/ruins-empty-v1.png`）、騎士はアプリの中で組み立てた立体のモデルです。外部のモデルファイルは読み込みません。

作り方は2通りです。丸みのある部品は、横から見た輪郭の線を1本描いて、それを回して立体にしています（兜、胸、喉当て、肩当て、腰の板、腰布）。輪郭の線に段を付けると、1つの部品で重ね板になります。残りは角柱、円錐、半球です（腿、丸い膝当て、脛当て、先のとがった具足、帯、腹、金のV字、胸の核、背中のマント、とがった面、後ろへ寝た角、光る目、肩の棘、上腕、肘当て、前腕、剣、五角形の盾、足元の影）。足元の影を含めて54の部品です（2026年9月23日に `src/render/knight.ts` で数えた数）。指と布の揺れは作っていません。

回して作った部品は面ごとに平らに塗り、輪郭は丸いまま、板を張り合わせた鎧に見せています。面の数は、回して作る部品が16〜20、角柱の多くが12です（とがった部品は4〜6）。

形は元絵の騎士へ寄せています。腰は板を3枚重ねてから布が長く広がり、肩は板を重ね、盾は上が広く下がとがった五角形で体の横へ下げています。頭は小さめにし、金は帯、盾の縁と鋲、胸のV字だけに使っています。盾側の肩当てだけ少し大きくしています。

剣は刃の幅を広げて先の三角を別の部品にし、柄を両手で握れる長さにして、鍔も横へ伸ばしています。画面の中で線に見えないようにするためです。盾は手前の面を一回り小さくして縁に斜めの面を作り、中央の帯を角の立った隆起にし、五つの角へ鋲を置いています。隆起は左右で明るさが変わるので、正面から見ても平らに見えません。

金属に見せるため、空と床の色を塗った小さな絵を6面ぶん起動時に描き、鎧、金の縁、刃へ映り込ませています。正面より縁のほうが強く映ります。面が視線に対して寝ているほど明るくなる設定で、逆光の縁を縁の部分だけに起こしています。胸の核と兜の目はにじませ、命中の瞬間だけ胸の前の光源を強めます。この光源の色は魔法の属性の色を白へ寄せたものです。

### 表面の傷と汚れ

絵を起動時にその場で描いて全身へ貼っています。外部のファイルは増えません。

- 汚れ：しみと、縦に流れた跡。材質の色に掛けて暗くします。
- てかりむら：磨けた所と曇った所。光り方の強弱を場所ごとに変えます。
- でこぼこ：打ち傷のへこみ、擦り傷、鋳物のざらつき。白黒で高さを描いてから面の向きに直し、光の当たる向きを面の中で変えます。

いちばん効いたのはでこぼこです。色を掛けるだけの絵は、離れて見るとほとんど変わりませんでした。明るい所も暗い所も同じ割合で暗くなるため、面の中の明暗の幅は増えません。光の当たり方を変えるでこぼこの絵で、板が金属らしく見えるようになりました。

絵は部品ごとに1枚ぶんを貼っています。大きい部品ほど傷の粒も大きくなります。粒の大きさをそろえる案と、実寸に合わせて目盛りを変える案も試しましたが、丸い部品に絵の端の継ぎ目が縦線で出たり、面の中の変化が減ったりしたので、今の貼り方にしています。

盾の面だけは刃と同じ磨いた鋼にしています。見本でも盾は体より明るく見えます。

場所を決めた模様が3つあります。

- 盾の面に、術式と同じ丸と三角の紋章を彫っています。絵は上下が入れ替わって貼られるので、三角は絵の中では下向きに描いてあります。色を暗くする絵とへこみを付ける絵の両方に同じ形を描いて、彫った線に見せています。
- 帯に同じ飾りを一周に8つ並べています。
- 腰布の裾は、布の絵の端を欠けさせて、ぎざぎざにしています。透かすのではなく薄い所を描かない設定なので、重なりの順番で困ることはありません。

### 場面へなじませる

見本の一枚絵を測ると、騎士の体は255段階で35〜90、すぐ後ろの背景は117〜133で、体のほうがずっと暗く沈んでいます。こちらも同じくらいになるまで光を落とし、鎧の青みを抜いて無彩色に近づけ、金と刃の明るさも下げています。映り込みに使う絵の上の面も暗くしてあります。上を向いた面へ空の白が映って光るのを防ぐためです。

遠い面ほど空気の色を混ぜ、背中側と裾が背景へ溶けるようにしています。足元の丸い影にだけは混ぜません。混ぜると影が灰色に浮きます。

騎士の描画面は、背景の一枚絵より少し粗く描いてから画面の大きさへ広げ、さらに表示の設定（`src/knight-canvas.css`）でわずかににじませています。背景の絵は輪郭が柔らかいので、騎士の線だけくっきりしていると貼り付けたように見えます。

見本の一枚絵と同じ見た目ではありません。鎧の細部は省き、輪郭と姿勢が分かることを優先しています。

### 視点と光

背景の一枚絵と同じ大きさに見えるよう、足元が画面の高さの71.4%、兜の先が上端から2%に来るように視点を決めています。視点の高さは0.5m、騎士までの距離は4mで、5度ほど上を向いた見上げる視点です。足元と兜の先の位置から視野の角度を計算するので、視点を変えてもこの二点は守られます。大きく見えるのは主に低い視点の遠近です。横長の画面では背景が広がる分だけ視野を狭め、騎士も同じだけ大きくします。

視点そのものも動きます。一回目の命中で後ろへ0.35m引いて1.5度上を向き0.25秒で戻り、床を打つ一撃で下へ0.12m沈み、とどめの一撃で後ろへ0.6m引いて2.5度上を向きます。時刻は下の「姿勢」の表と同じです。控えめモードと「動きを減らす」では視点は動きません。

光は空からの弱い光、奥からの逆光、手前からの光の3つです。手前の光だけが影を落とし、肩当てや剣、帯の影が体に掛かります。足元の丸い影は、濃淡を描いた一枚の面です。

## 姿勢

姿勢は10です。一回目で使う待機、ひるむ、構えを戻すの3つ、防御の回で使う構え、溜め、振り下ろし、弾かれる、前屈（弱点を晒す）の5つ、とどめの回の崩れ落ちる、待機の息づかいに使う「剣を上げた構え」です。画像を切り替えるのではなく、10の角度の表を重みで混ぜ、胴、首、体のひねり、剣の腕、盾の腕の5か所を動かします。

腕は肩と肘の2段で、肘を少し前へ曲げています。立ち方は左右で変え、足の位置を前後にずらし、つま先を外へ開き、膝から下を少し内へ向けています。待機は、剣を肩の後ろへ振りかぶり、盾を前へ出し、膝を沈めた構えです。上半身だけを少しひねって半身にし、兜はこちらを向いたままです。そのうえで5.6秒に一度、剣をゆっくり上げ下げします。体がごく小さく上下し、上半身がゆっくり揺れ、首が左右へ振れ、兜の目はゆっくり明滅します。防御の回の溜めは待機のどこよりも剣を高く上げるので、見分けが付きます。控えめモードでは、この待機の動きをすべて止めます。

一回目の受付中には、騎士が自分から動きます。3.5秒に盾側の脚を上げて足を踏み替え、9.5秒に盾を胸の前へ上げて剣で打ち鳴らします（打った瞬間に盾の面が0.08秒光る）。この二つの時刻は二つの遊び方で同じです。「順番に」では一回目が声だけの回なので、唱えている最中に起きます。画面の揺れと音も同じ時刻です（[画面全体を使う演出と、敵の圧](画面全体と敵の圧_実装.md)）。

一回目の命中のあとは、命中の時刻（「同時に」は23.5秒、「順番に」は19.5秒）から数えて次のように動きます。

| 命中からの時間 | 姿勢 |
| --- | --- |
| 0秒 | 魔法が届く。0.1秒ほどでひるむ姿勢に入る |
| 0〜0.6秒 | ひるんだまま。下に書く命中の反応はこの間に出る |
| 0.6〜0.8秒 | 構えを戻す姿勢へ移る |
| 0.8〜1.65秒 | 盾を寄せて構えを戻した姿勢 |
| 1.65〜2.3秒 | 待機の姿勢へ戻る |

防御の回の姿勢は、回の表の時刻から作ります。

| 何が起きるか | 表のどこから作るか | 同時に | 順番に |
| --- | --- | --- | --- |
| 剣を引いて構える | 一回目の受け渡し | 29秒 | 24秒 |
| 剣を頭上へ上げて溜める（上げきるまで「同時に」は15秒、「順番に」は11秒）。掲げた剣の腕が溜まるほど震え、振り下ろしまで続く | 防御の回の始まりの0.2秒後 | 30.2秒から | 26.2秒から |
| 0.55秒で振り下ろす | 防御の回の確定 | 48秒 | 40秒 |
| 剣が床を打つ | 確定の0.55秒後 | 48.55秒 | 40.55秒 |
| 盾に弾かれて後ろへ反る | 敵の一撃が盾に当たる時刻 | 50.4秒 | 42.4秒 |
| 「返せ」と唱えていたときだけ、戻ってきた一撃を受けて短く白く光る | 盾に当たってから0.8秒後 | 51.2秒 | 43.2秒 |
| 兜の角が1本折れて消え、0.1秒後から構えを戻す | 盾に当たってから2.1秒後 | 52.5秒 | 44.5秒 |
| 0.7秒かけて胸当てが前へ外れ、胸の線が左右へ開き、胸の核が2倍ほどになって明滅する | 防御の回の受け渡し | 55秒 | 46秒 |

命中位置は決め打ちの点ではなく、そのときの胸の核の位置を画面上の座標へ直して使います。吹き飛びと回転の分も足すので、崩れている間も胸を狙います。

`?view=look` の確認画面では姿勢を止めて見られます。「被弾」は命中の0.2秒後、「構えを戻す」は命中の1.4秒後で止めた姿勢です（[背景・騎士・完成した術式の確認](見た目の確認画面.md)）。

## 命中の反応

一回目の魔法が届いた瞬間から、次の5つが重なります。いちばん長いものでも0.6秒で終わります。

- 白飛び：騎士の形の上だけを、白、属性の色、白の順に0.05秒ずつ塗ります。合計0.15秒です。その間はずっと塗るので、点滅ではなく一続きの白に見えます。
- 吹き飛びと回転：奥へ押されて少し縮み、打たれた向きへ傾きます。強いほど戻りが遅く、いちばん強いときは沈み込んで転倒に近い崩れになります。
- 残像：直前の何コマかの騎士の形を、白に近い色で後ろへ重ねます。0.3秒で消えます。
- 輪郭の発光：騎士の形を属性の色で少しずらして後ろへ重ね、縁を光らせます。0.6秒で消えます。
- 胸の光：命中の瞬間だけ胸の前の光源と胸の核を強めます。核は一回目の締め切りから少しずつ明るくなり、命中でちょうど満ちます。

このほか、胸に属性の跡（炎は焦げ、氷は霜の棘、雷は帯電）が一回目の終わりまで残り、最後の1秒で消えます。防御の回では「返せ」で弾き返したときだけ、戻ってきた一撃を受けた時刻から防御の回の終わりまで同じ跡が付きます。

反応の強さは魔法で決まります。個数が多く、範囲が広く、線が一点に集まっているほど大きく崩れ、拘束と強化では小さくなります。同じ魔法でも、たくさん描いてたくさん唱えたほど強くなり、見た目の設定（控えめ、派手、最大）でも変わります。

控えめモードでは、待機の息づかいと、吹き飛び、回転、沈み込みを止め、白飛びを出さず、残像と輪郭の光を3分の1にします。このPCの「動きを減らす」設定と `?calm=1` は、控えめモードの始めの値を決めるだけです。「演出を派手にする」ボタンはいつでも押せて、押せば騎士の動きも一緒に戻ります。選んだほうは次回も覚えています。

## 体力の表示

画面の右端に、騎士の体力を縦の帯で出します。名前は帯の左へ縦書きで添えます。騎士の顔や背景と重ならない場所です。本体の帯は下端を固定して上から減り、その下の薄い赤が0.3秒待ってから0.5秒かけて追いつきます。

- 一回目の命中で、魔法の個数、範囲、収束に応じて20〜45%減ります。連弾は弾が届くたびに一段ずつ減らすので、最後の特大の1発でも減ります。
- 防御の回で一撃を受け止めきった時刻（兜の角が折れる時刻と同じ）に、止め方によらず10減ります。
- とどめの回で残りを減らし、とどめの一撃で必ず0にします（[とどめと結果の詳細設計](とどめと結果_詳細設計.md) の5章）。

体力の時刻は命中の停止を含む演出の時刻で見るので、停止の間は帯も止まります。体力は演出のための数値で、勝ち負けの計算には使いません。残りが少なくても点滅させません。

## 効果音

ブラウザーの中で短い音と雑音を合成して鳴らします。音素材のファイルを置けば、その音も重ねて鳴らせます（[音素材の入れ方](音素材の入れ方.md)）。鳴らす時刻は `src/audio/cues.ts` が回の表から作っています。

| 音 | 同時に | 順番に |
| --- | --- | --- |
| 騎士が足を踏み替える低い足音と、剣で盾を打ち鳴らす金属の音 | 3.5秒・9.5秒 | 3.5秒・9.5秒 |
| 線が残り始める案内の小さい音 | 7秒 | 26秒（防御の始まり）、50秒（とどめの始まり） |
| 詠唱の案内の小さい音 | 14秒、40秒、64秒 | 62秒 |
| 一回目の蓄積、完成、放出 | 18秒、21秒、22秒 | 14秒、17秒、18秒 |
| 一回目の命中。低い音と短い金属音。雷や氷では高い音も足す | 23.5秒 | 19.5秒 |
| 一回目の終わりの小さい音 | 27秒 | 23秒 |
| 騎士が剣を振り上げて溜める間の低いうなり。少しずつ大きくなる | 30.2〜48秒 | 26.2〜40秒 |
| 防御の回の蓄積、完成、放出（盾が立つ） | 45秒、48秒、49秒 | 38秒、40秒、41秒 |
| 剣を振り下ろす風切りと、剣が床を打つ重い衝撃（石が割れる音と低い残り） | 48秒・48.55秒 | 40秒・40.55秒 |
| 敵の一撃を受け止めた音。低い衝撃、金属の鳴り、砕けた破片の三層 | 50.4秒 | 42.4秒 |
| 防御の回の終わりの小さい音 | 53.9秒 | 45.9秒 |

とどめの回の音（とどめの一撃、崩れ落ちる三つの音、魔導書の音）は [とどめと結果の詳細設計](とどめと結果_詳細設計.md) の9章にあります。とどめの回の蓄積から後の時刻は二つの遊び方で同じです。

防御の回で狙いの印を囲めたときは、時刻ではなく囲めた瞬間に合図の音を鳴らします。囲めた数が増えるたびに鳴ります。

音の厚みは魔法の派手さと入力の量で変わります。鳴る時刻は変わりません。

口元のマイク（ヘッドセット）で遊ぶ前提なので、録音中も効果音と囲めた合図の音を鳴らします。マイクを使うときは、声を受け付ける間だけ曲と効果音を8dB下げ、受付の締め切りから戻します。下げる間は次のとおりです。

- 「同時に」：0〜18秒、30〜45秒、56〜72秒。溜めのうなりは曲と同じ経路を通るので、30〜45秒は曲と一緒に下がります。
- 「順番に」：0〜14秒と62〜72秒。防御の回は手だけの回なので下げません。

最初の画面の「音を試す」で音量を確かめられます。初期音量は25%です。効果音のチェック、音量のつまみ、プレイ中の「音を消す」で変えられます。中止、画面を隠す、終了、再開では前の音を止めます。音が使えないブラウザーでもゲームは続けます。

音は開始の操作の後に用意します。録音用の接続とは別で、合成した音を音声認識へ直接渡す処理はありません。実際の会場のスピーカー音量は、人が聞いて合わせる必要があります。

## ファイル

- `src/render/knight.ts`：立体の騎士、10の姿勢、命中の反応、視点、命中位置、命中の跡。
- `src/render/health-bar.ts`：体力が減る段と、二層の表示。
- `src/render/cast-scene.ts`：本編の時刻で騎士と術式を更新し、控えめモードと入力の量を渡す。
- `src/audio/cues.ts`：音を鳴らす時刻と、曲と効果音を下げる間。
- `src/audio/cast-audio.ts`：音の生成、音量、停止、重複の防止、溜めのうなり、囲めた合図。
- `src/knight-canvas.css`：騎士の描画面をにじませる設定。ゲーム画面、確認画面、演出の見比べ画面の3つから読み込みます。
- `src/look.ts`：確認画面。「待機」「被弾」「構えを戻す」で姿勢を止めて見られます。
- `public/art/ruins-empty-v1.png`：騎士を除いた背景。[生成時の指示](references/騎士と背景の分離_生成の指示.md)。
- 前に使っていた画像の騎士（`public/art/knight-poses-v1.png`）は削除しました。必要ならGitの履歴から戻せます。

単体の試験で見ているのは、命中の前にひるまないこと、命中の後に構えを戻すこと、白飛びが白、属性の色、白の三段になること、残像と輪郭の光が消える時刻、控えめモードで白飛びが出ず残像と輪郭が弱くなること、「動きを減らす」設定で吹き飛び、回転、命中の震えが止まり胸の光は残ること、入力の量が多いほど反応が強いこと、連弾で弾が届くたびに体力が一段ずつ減ること、防御の回の姿勢の順と受け止めの音の時刻、録音中も音が鳴ることと曲を下げる間、同じ音の重複です。騎士の姿勢、防御の回、敵の音の試験は「同時に」の秒数を前提にしているので、「同時に」の表でだけ走ります。録音中も音が鳴ることと曲を下げる間、体力の段は、二つの遊び方の表の両方で見ています。

ブラウザーの試験（`tests/browser/knight-audio.spec.ts`）は「同時に」の90秒を通して、効果音が決めた順に鳴ること、消音と中止で音が止まること、終わったときに音の生成処理が残っていないことを見ます。その結果を `.local-speech/knight-audio-report.json` に、実際のアプリの出力を録った試聴用の音を `.local-speech/knight-audio-preview.webm` に保存します。後者は試聴ボタンと一回のプレイを含み、途中に無音があります。マイクの録音ではありません。どちらもGitには含めません。

2026年9月20日から21日の記録（すべて「同時に」だけのころ）：

- ブラウザーで、実際の音の出力、消音、途中中止、音声認識と同時に使った発動を確認しました。画面は1440×900と390×844で見ています。初期音量25%で測った出力の最大振幅は約0.393で、振幅の上限には達していません。
- 防御の回と見た目の作り込みを合流した後、そのときのブラウザーの試験25件がMacで通りました（2026年9月20日）。
- 形の作り込み、表面の絵、場面へのなじませは、開発用の環境（ソフトウェア描画）で、確認画面の3姿勢、開始画面、見本との並べ、1440×900と390×844を目で見て確かめました。命中位置が胸の核に付いてくることは、確認画面の照準で確かめました。見本と同じ場所の明るさは、兜47・肩56・胸57・腰47で、見本の56・53・50・45に近づいています。
- 同じ環境での画面数は、作り込む前が毎秒3.6画面ほど、なじませた後が毎秒2.67画面、模様と裾を足した後が毎秒2.33画面でした。下がった分の多くは、にじませる処理とでこぼこの絵の計算です。ソフトウェア描画の数字で、GPUのあるPCの数値ではありません。Macで遅ければ、にじみを外して粗く描くだけにすれば戻せます。
- コードの見直しで、影がまったく出ていなかったこと（どの部品も影を出す側と受ける側に登録していなかった）、兜の面覆いとつま先が45度ずれていたこと、「動きを減らす」で命中の震えが残っていたこと、盾の紋章の三角の向き、でこぼこの向きの逆転、裾の欠け方、術が終わるときに騎士だけ一段で切り替わっていたことなどを直しました。命中の震えは毎秒10回に落としています。

## まだ確かめていないこと

- 命中の反応（白飛び、吹き飛び、残像、輪郭の光、胸の跡）と体力の減り方が、実機で狙いどおりに見えるか。弾が胸に当たるか。画面が遅いと0.6秒しかない反応を飛ばすので、GPUのあるPCで確かめてください。
- 控えめモードでの騎士の見え方。
- 「順番に」の時刻での騎士の動き。溜めが11秒と短くなり、構え（24〜26秒）と前屈（46〜50秒）の保持が長くなった所の見え方。
- ヘッドセットで、唱えている間に鳴る足踏みと盾打ちの音が聞き取りに入り込まないか。
- 人の声や実際の会場での音の聞こえ方と音量。
- 床や鎧へ魔法の光が届く照明は作っていません。
