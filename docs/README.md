## 段階ごとの進み具合

段階の区切りは設計仕様の「5.3 作業の順序と途中の合格条件」に合わせています。

| 段階 | 内容 | 今の状態 |
| --- | --- | --- |
| 第一段階 | 手の軌跡と蓄積から発動まで | 実装済み。マウスと合成音声では確認済み。5人に遊んでもらう確認は未実施 |
| 第二段階 | 同時の描画・詠唱とJevの12問 | 実装済み。試験用の返事では確認済み。Jevとの実通信と、人の声での精度は未確認 |
| 第三段階 | 3回とも成功する60秒 | 未着手。防御の16秒と最後の20秒 |
| 第四段階 | 魔法部品と最後の演出 | 未着手。四つの本体、六属性、24問、立体の敵 |
| 第五段階 | 記録と持ち帰り | 未着手。三件の保存、魔導書、QR、静止画保存 |
| 第六段階 | 会場条件で調整 | 未着手。実機での確認と4時間の連続運転 |

未確認のことの詳しい一覧は [第一段階の実装と確認](実装と確認の記録.md) にあります。

## 文書を足すとき

- 段階が進んだら、この表の状態を直し、`第二段階の実装と確認.md` のように段階ごとの記録を足します。
- 作った部分の説明は `docs/` の直下、画像を作った指示文は `docs/references/` に置きます。
- 新しい文書を足したら、この一覧にも行を足してください。
